# PicoCalc: постоянный загрузчик M3 и BIOSUPD

Этот комплект BIOS KEY25 установлен и проверен на PicoCalc с Pico H 10 ноября 2026 года.
BIOS сохраняет асинхронный PMU и актуальное расширение сопроцессора Spectrum.

Для последующих обновлений скопируйте `sd/Apps/BIOS` на microSD, откройте
`BIOSUPD.APP` в проводнике и нажмите Enter. Рядом находится `BIOS.M3U`.
DIP и переподключение кабелей больше не нужны. На проверенном устройстве
загрузчик уже установлен, повторная первоначальная установка не требуется.

| Файл | Назначение |
|---|---|
| `bootstrap.bin` | Только первая установка: загрузчик, BIOS и метаданные |
| `boot.bin` | Постоянный загрузчик, 3248 байт; резерв 8 КиБ |
| `bios.bin` | BIOS с базой `08002000`, 29844 байта |
| `BIOS.M3U` | BIOS с заголовком и CRC для обновления через Pico H |
| `source.zip` | Полные исходники M3 и рецепт побайтного воспроизведения |
| `manifest.json` | Хеши образов, исходников, зависимостей и APP |
| `sd/Apps/BIOS` | Готовый каталог для карты: APP, образ и значок |

BIOS использует асинхронный PMU, протокол завершённых M3-ответов и индекс
клавиш на стеке: все 152 чтения GPIO и порядок событий сохранены, повторные
поиски по десяти слотам удалены. Постоянная RAM не увеличилась.
На штатных Pico 125 / STM32 72 МГц прошли четыре коротких сочетания AY/YM,
ABC/ACB и 30 000 кадров Cosmic Payback: 0 поздних ответов из 130 166,
0 опустошений PWM и 0 задержек кадров больше 1 мс. Максимальный ответ —
4588 мкс при прежнем пределе 4720 мкс. Точный образ BIOS считан обратно
полностью; CRC загрузчика не изменился.
[Результаты KEY25/KEY26](../../doc/measurements/picocalc-spectrum-stock-stereo-20261110.json).

Статус `BUILT_NOT_INSTALLED` в манифесте относится к операции сборки:
сборщик не открывает устройства. Установка актуального BIOS и точные SHA256 зафиксированы в результатах
KEY25/KEY26 выше. Первоначальная установка неизменённого загрузчика и
границы восстановления — в
[испытаниях 8 ноября](../../doc/measurements/picocalc-m3-boot-20261108.json).

При испытаниях загрузчика 8 ноября прошли обычное обновление и восстановление после намеренной
записи только первых 240 байт BIOS. В обоих случаях APP сравнил весь BIOS
чтением Flash, проверил сохранность загрузчика и получил ACK запуска;
отдельный сеанс затем подтвердил HELLO работающего BIOS. Экран 320×320,
Tab/Esc, клавиатура, SD, PSRAM и телеметрия питания прошли итоговую проверку.
Настройки M3 вне области стирания; option bytes не изменялись.

Физическое отключение питания во время записи не испытывалось. HOST-тест
проверяет 2226 прерываний операций Flash; Thumb-модель исполняет реальный
загрузчик, включая холодный запуск и переход из BIOS. При неполном BIOS
клавиатура корпуса недоступна: повторный запуск APP выполняется через USB
Pico. Автоматического восстановления без компьютера пока нет.

Для воспроизведения M3 распакуйте `source.zip` в пустой каталог и запустите
`python3 rebuild.py --drivers /path/to/pinned-southbridge/Drivers
--toolchain /path/to/arm-none-eabi/bin`. Нужны закреплённые в `expected.json`
CMSIS/HAL и GNU Arm GCC 14.2.1. Рецепт проверит все четыре BIN/M3U побайтно.
Полный комплект вместе с APP пересобирает
`tools/firmware/picocalc/build_boot_bios.py` из репозитория.

Схема памяти, протокол, первоначальная установка и восстановление:
[документация загрузчика](../../ports/picocalc/bios/boot/README.md).
