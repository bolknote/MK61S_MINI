# Игры для проверки Spectrum APP

Для аппаратной проверки используем набор из
готового образа `programs/spectrum/GAMES.img`.
Материалы сборки: [`third_party/spectrum-games/`](../../../third_party/spectrum-games/README.md).
В распространяемом комплекте игры без найденного разрешения не сохраняются.
Для Snow Trap Dizzy пользователь явно разрешил временную внутреннюю копию.
Проверенные источники и причины исключения записаны в
[`LICENSE-AUDIT.md`](../../../third_party/spectrum-games/LICENSE-AUDIT.md).

## The Sword of Ianna 1.1

- Оригинальная ESXDOS-версия на английском и испанском.
- ZX Spectrum 128K и совместимые машины, AY.
- Apache 2.0, с сохранением лицензии, авторства и исходных уведомлений.
- Исходный архив: `third_party/spectrum-games/ianna/Ianna-esxdos-1.1.zip`.
- SHA-256: `e7e2c3579b8a9c53bf6906fb94e75cb6986bba2486360065c87d5edad915d9f2`.
- Исходники и лицензия: [авторский репозиторий](https://github.com/fjpena/sword-of-ianna-zx).

В подготовленном `games/GAMES.img` файлы находятся в `IANNA/`.
Штатный способ запуска — NMI-браузер esxDOS → `IANNA/LOADER` либо
`LOAD *"LOADER"` из этого каталога. Проверить загрузку, музыку AY,
управление, начало уровня, паузу и возврат в APP.

## ULAplus 10th Anniversary Collection

Сохранены 337 TAP-файлов из раздела games, 20 демо, 50 палитр,
документация и все разрешения по издателям. Это число файлов,
а не уникальных названий. Игровые данные не изменены.

- [Страница составителя](https://sourcesolutions.itch.io/ulaplus10).
- Исходный архив: `third_party/spectrum-games/ulaplus/ULAplus-games.zip`.
- Разрешения: `games/*/legal.txt` внутри архива.
- Общий набор предназначен для бесплатного некоммерческого распространения;
  для Mojon Twins действует CC BY-NC-SA 3.0.

В образе DivMMC игры находятся в `ULAPLUS/GAMES/`, демо — в
`ULAPLUS/DEMOS/`, палитры — в `ULAPLUS/PALETTES/`. Соответствие имён 8.3
исходным названиям хранится на компьютере в `.build/spectrum-library/image-index.json`.
Для TAP используются NMI-браузер или `.tapein` и `LOAD ""` в esxDOS.
ULAplus должен быть включён в Options APP. Демо с Timex/HAM и эффектами
внутри строки могут требовать ещё не реализованных возможностей.

Игра Джона Коннолли / PROSM Software для 48/128K с явным разрешением

## Snow Trap Dizzy: временная внутренняя копия

По указанию пользователя образ возвращён для внутренней проверки с
последующим удалением. Локальный файл:
`.build/spectrum-hardware-tests/snow-trap-dizzy.trd`.
Размер — 655360 байт; SHA-256:
`5556e547ca8933a8acf637239a47cc39dfca73c439bf8151f9e50d2687a4cf35`.
Источник — [авторская статья](https://habr.com/ru/companies/timeweb/articles/1061328/).

Для внутреннего запуска используется каталог microSD
`/MK61S-SPECTRUM-HIL-20261105/SPECTRUM/`. После переноса подключить TRD
через Beta Disk, оставить защиту записи, запустить машину и войти в TR-DOS.
После внутренней проверки удалить TRD и с microSD, и из локального
игнорируемого каталога. Статус переноса и чтения файла обратно с карты
фиксируется в `internal-install.json` рядом с локальным образом.

Копия отсутствует во входных файлах сборщика и в распространяемых ZIP.

На PicoCalc/Pico H 125 МГц игра уже прошла загрузку с этого TRD через
Beta Disk: показаны заставка, меню и игровая комната; пользователь
проверил управление и вышел. Вход через Beta Disk оставляет 48K ROM
с разблокированным `7FFD`, чтобы загрузчик мог включить 128K RAM.
Исходная скорость в комнате — 13,6 эмулируемого кадра/с; этот образ
используется для сравнения версий при оптимизации.

## Подготовка и проверка

`tools/apps/spectrum/build_spectrum_library.py` готовит образ для SD и, при
передаче закреплённого `esxdos089.zip`, FAT16-образ `GAMES.img` на 32 МиБ.
`tests/spectrum_library_self_test.py` проверяет контрольные суммы,
уведомления и чтение каждого файла обратно из образа.

Остальные игры набора на PicoCalc пока не запускались. При аппаратной
проверке записывать версии APP/UF2, частоту Pico, наличие PSRAM,
скорость игры, звук и задержки управления.
