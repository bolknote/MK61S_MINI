# SHEET.APP

Рабочая электронная таблица для графического МК-61s/USB-экрана 192×64.
Обычный пользовательский APP ABI 6, обработчик файлов **S1 / `.mks`**.
Основной экран: 3 столбца × 5 строк, штатный шрифт 5×8. Обзор: 4 × 7, 3×5.

## Установка

Нужна прошивка из этого состояния исходников: в ней добавлен тип S1.
Прежняя прошивка ABI 6 не знает расширения `.mks`; один новый APP это
соответствие не регистрирует. Для F401 также обновите `USBDISK.APP` и
`EXPLORER.APP` вместе с прошивкой.

Скопируйте `programs/app/SHEET.APP` в `/app` на USB-диске прибора,
а `programs/sheets/*.mks` — в любой удобный каталог. Безопасно извлеките
USB-диск. Проводник открывает `.mks` через обработчик S1; прямой запуск
`SHEET.APP` создаёт пустой лист. APP можно переименовать или переместить.

Нужны публичные сервисы MATH, NUMBER_IO, FONT, EDITOR, MEMORY, FILES и
DIALOGS. В штатных графических сборках с FOCAL/TinyBASIC они доступны.
На символьном дисплее нужен активный USB-экран; без графики APP возвращает
`MK61_APP_UNSUPPORTED_DISPLAY`.

## Управление

| Клавиши | Таблица | Ввод формулы |
| --- | --- | --- |
| ← / → | столбец | точка вставки в последовательности |
| ШГ− / ШГ+ | строка | начало / конец последовательности |
| OK | открыть ячейку | записать черновик |
| USER | меню действий | выбрать ячейку-ссылку |
| Цифры | заменить значение новым черновиком | ввод числа |
| В↑ | — | отделить операнды |
| F / K | — | префиксы функций калькулятора |
| Cx | очистка через меню | удалить цифру или предыдущую операцию |
| С/П | пересчитать весь лист | — |
| ESC | выйти; изменённый лист предлагает сохранение | отменить черновик |

В выборе ссылки ←/→ и ШГ перемещаются по таблице, **USER** переключает
`B2 → $B2 → B$2 → $B$2 → B2`, **OK** вставляет ссылку. Знак `$` появляется
автоматически. Фиксация столбца/строки относится к копированию формулы.

Пример: A2=2, B2=125. В C2 откройте ввод, USER выберите A2, нажмите В↑,
USER выберите B2, нажмите × и OK. Получится `A2 ENT B2 *`, значение 250.
На экране `ENT`, `*`, `/` показаны знаком В↑, × и ÷.

В меню действий есть отмена, копирование, заполнение вниз, очистка,
тип ячейки, детали и меню листа. Копирование выбирает одну цель;
заполнение — нижнюю строку того же столбца. Формулы сдвигают относительные
ссылки. Весь диапазон заполняется одной отменяемой операцией; если не хватает
места, изменения диапазона откатываются.

Для подписи: USER → Тип ячейки → Подпись. Работает штатный редактор M8:
цифры, K/SMS-буквы, F-символы, Cx и перемещение курсора. OK записывает,
ESC сохраняет прежнюю ячейку. Одиночное число сохраняется как число;
ссылка или операция образует формулу. Отдельная клавиша `=` не нужна.

В меню листа: Сохранить, Сохранить как, Открыть, Новый лист, плотность,
угловой режим, Пересчитать, Справка. ESC/Открыть/Новый при изменениях
предлагают сохранить, продолжить без сохранения или отменить действие.
Отказ записи или отмена файлового диалога сохраняют текущий лист в памяти.

## Вычисления и границы

Лист **A1:P32**, до **64 заполненных ячеек**, суммарно **1536 байт** содержимого.
Каждая подпись/формула/число — до 95 байт, формула — до 48 операций/операндов.
Исчерпание любого лимита даёт `#ЛИМИТ` и не повреждает прежнее содержимое.

Формула исполняется с отдельным начальным стеком X/Y/Z/T, заполненным
нулями, и обычным подъёмом стека после операций; В↑ дублирует X и
подавляет подъём при следующем вводе числа/ссылки. Пустая ссылка даёт 0,
подпись в числовой формуле — `#ТИП`. Угол DEG/RAD/GRD сохраняется в листе.

Чистые операции: `ENT + - * / NEG SWAP ROLL SIN COS TAN ASIN ACOS ATAN`
`LN LG EXP SQRT POW INV SQR TEN ABS INT FRAC PI`. На клавиатуре:
F0=10^x, F1=exp, F2=lg, F3=ln, F4/F5/F6=обратная тригонометрия,
F7/F8/F9=sin/cos/tg, F−=√, F÷=1/x, F+=π, F×=x², F↔=степень;
K4=ABS, K7=INT, K8=FRAC. ВП вводит `E`, /−/ меняет знак мантиссы/порядка.
Стрелки стека/обмен представлены `ROLL`/`SWAP`.
**F → USER** (или K → USER) открывает список всех поддержанных операций,
включая ROLL. Стрелки выбирают, OK вставляет операцию, ESC возвращает
к черновику. В обычном вводе USER по-прежнему выбирает ссылку.
Степень сохраняет порядок МК-61: X — основание, Y — показатель;
`2 В↑ 3 F↔` даёт 9.

Трансцендентные функции вызывает настроенное математическое ядро прошивки
через публичный API; обычная арифметика использует `double`, как штатные
языки. Это калькуляторные выражения, не запуск произвольной программы
МК-61: переходы, ввод-вывод, регистры пользователя и случайные числа в формулах
не допускаются.

Изменение ячейки помечает только её зависимые ячейки. Пересчёт использует
итеративный обход с тремя цветами, ограниченный числом ячеек и длиной
источников. Рекурсии нет. Цикл и его зависимые ячейки получают `#ЦИКЛ`;
независимые значения остаются доступными. Ошибки числа/области определения,
ссылки и типа локальны. В длительном обходе и перед операциями обслуживается
фоновый API прибора.

## Формат S1

C6 type=12, magic=`S1`, расширение `.mks`, непрозрачные бинарные байты.
Квота C6/USB — 2048 байт; максимальный валидный документ этой версии — 1812.
Прозрачное сжатие и преобразование UTF-8 для этого типа выключены.

20-байтовый little-endian заголовок:

| Смещение | Данные |
| --- | --- |
| 0 | ASCII `MKSH` |
| 4 | версия 1 |
| 5, 6 | 16 столбцов, 32 строки |
| 7 | угол: 0 DEG, 1 RAD, 2 GRD |
| 8 | плотность: 0 обычная, 1 обзор |
| 9 | число записей |
| 10 | два нулевых байта |
| 12 | длина тела, u16 |
| 14 | два нулевых байта |
| 16 | IEEE CRC32 заголовка 0…15 и тела |

Запись: позиция u16 (`row*16+column`, отсчёт от нуля), тип u8
(1 число, 2 подпись M8, 3 формула ASCII), длина u8, затем содержимое без NUL.
Дубли позиций, неизвестные версии/типы, выход за границы, неверные формулы,
лишние байты и CRC отвергаются до изменения текущего листа. Значения и ошибки
не записываются: при открытии всё пересчитывается заново.

## Сборка и проверка

```sh
python3 tools/build_sheet_app.py --copy-to-programs
MK61_TEST_SANITIZERS=1 bash tests/run_sheet_app_tests.sh
```

Если ARM GCC отсутствует в PATH и штатном каталоге Arduino macOS, задайте
`--arm-toolchain-bin`. Сборка использует SDK, общий runtime и обработчик S1;
лимит загруженного APP не повышается. Кадр арендуется в SCRATCH только на
время отрисовки и освобождается до математики, диалогов и дисковых операций.

ARM-проверка с Unicorn использует настоящие функции прошивки, три адреса
загрузки и производственный декодер контейнера:

```sh
python3 tests/run_sheet_app_arm_tests.py \
  --resident-elf binary/mk61s-M-classic-v3-uc1609-f411/mk61s-M-classic-v3-uc1609-f411.elf \
  --app programs/app/SHEET.APP
```

Для этой проверки нужен ELF с LIBM, как для остальных ARM-тестов. Сам APP
работает и с CORE; аппаратную точность CORE покрывает отдельная серия
`tests/run_mk_math_tests.sh`. `BUDGET.mks` демонстрирует расчёт суммы и налога,
`CYCLE.mks` — обработку цикла рядом с независимой числовой ячейкой.
