# Обновление BIOS M3 через Pico H

Сборка: `python3 tools/firmware/picocalc/build_boot_bios.py`. Скопируйте
полученный `sd/Apps/BIOS` на карту, откройте `BIOSUPD.APP`, нажмите Enter.
Esc отменяет операцию до её начала. Образ `BIOS.M3U` лежит рядом с APP.

Сначала на M3 один раз устанавливается постоянный загрузчик. Старый BIOS
без его поддержки APP распознаёт и отказывает в записи. Во время записи
клавиатура корпуса временно недоступна. На стороне Pico образ заранее
проверяется и помещается в общий буфер, а записанный BIOS читается целиком
для сравнения. Прерывание установки допускает повторный запуск APP через USB
того же Pico; DIP для штатного обновления не нужен.

Полный протокол, схема памяти, восстановление и первоначальная установка:
[документация загрузчика](../../../ports/picocalc/bios/boot/README.md).
