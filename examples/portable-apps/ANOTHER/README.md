# Another World для PicoCalc

`ANOTHER.APP` — порт интерпретатора оригинальной DOS-версии Another World.
Файлы игры не входят в исходный код и сборку: нужны `MEMLIST.BIN` и `BANK01`–
`BANK0D` рядом с APP. Их можно подготовить с помощью `tools/games.cmd`.
Результирующий каталог `apps/ANOTHER` нужно целиком скопировать на microSD.

Требуются PicoCalc с Pico H/RP2040, PSRAM и прошивка MK61S с сервисами
цветного экрана, блочной PSRAM, клавиатуры и аудиопотока. Экран игры 320×200
расположен по центру дисплея 320×320. Стрелки — движение, пробел или Enter —
действие, C — ввод кода уровня, Esc/F10 — выход. При запуске показывается
оригинальный экран защиты, если он предусмотрен игровыми данными.

Звук моно, 25 кГц; текущая реализация микширует PCM на Pico. Перенос на M3
ещё не подключён. Отдельный
экспериментальный M3-модуль можно собрать командой
`python3 tools/apps/another/build_another_m3.py`; он пока не подключён к APP.

На компьютере проверены распаковка всех 140 ресурсов скачанной DOS-версии,
сравнение 5044 кадров с Raw, а также побайтовое сравнение 508 кадров
движущегося эпизода, моно-микшер и переход к первой игровой части. Проверки
и протокол M3 запускаются командой
`sh tests/run_another_world_tests.sh`; чтобы включить прогон с локальными
файлами игры, задайте `ANOTHER_WORLD_DATA=.build/game-library/sd/apps/ANOTHER`.
При установленном Unicorn ARM-код делителя и сохранение его состояния
проверяются после сборки командой:
`python3 tests/another_world_divider_arm_self_test.py .build/another-app/ANOTHER.elf`.
На физическом PicoCalc с прошивкой 0.8.16 проверены запуск, ввод кода уровня,
переход к первому игровому уровню и выход по Esc. Уменьшенные обновления
экрана и сжатый кеш часто копируемой видеостраницы сокращают передачу данных.
Если страница не помещается в 8 КБ кеша, используется её полная копия в PSRAM.

В парном замере на прошивке `9A000DF9` 240 шагов движущегося эпизода заняли
20,142 с без кеша страницы и 20,140 с с ним при заданных игрой 20,1 с —
около 99,8% среднего темпа. Чтение PSRAM сократилось с 10,73 до 6,25 МБ,
максимальное отставание таймера — с 1,34 до 1,17 с. К последнему ожиданию
таймер догнал график; оставшиеся 42 мс ушли на завершение шага и вывод кадра.
В замере с кешем 94 из 245 ожиданий начались с опозданием. Контрольные кадры
совпали, намеренного пропуска кадров и пропусков PCM-буфера не было. Во время
обоих прогонов запросы подробного USB-статуса не отправлялись.

Аппаратный делитель используется для беззнаковых 32-битных делений
приложения. Установленная релизная сборка прошла обычный запуск и выход.
Скорость может отличаться в других сценах; полное прохождение и звук на слух
ещё не проверены.
