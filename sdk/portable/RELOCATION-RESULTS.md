# APP ABI 4: релокации, память и запас F401

Замер 06.09.2026: исходная точка `ba34cf65` (прошивка `a1a3b23`), текущие
изменения ABI 4. ARM GCC 14.2.1; resident `-Os -flto`, System APP
`-Oz -flto -fipa-pta -mword-relocations`. Сравниваются те же восемь
профилей и ключей из `tools/release-contract.json`. Числа — байты.

## Стоимость изменения

На самом тесном профиле `f401-capability-ws-usb-graphics`:

| Этап | Resident BIN | Свободная Flash |
| --- | ---: | ---: |
| До изменения | 261608 | 536 |
| SETUP и справка перенесены в C5 | 256980 | 5164 |
| Добавлены релокации и разделение пула | 257864 | 4280 |

Вынос освобождает **4628 байт** (цель ≥4096). Загрузчик и диспетчер памяти
вместе добавляют **884 байта** (цель ≤2048). Чистый выигрыш — **3744 байта**.
Максимальный кадр resident-стека — 2032 байта при лимите 2048; статическая
RAM наиболее тесного профиля — 54084 байта. Резерв heap/stack 1536 байт,
после него остаётся 9916 байт SRAM. Это бюджет линковки, не измерение
максимального стека на устройстве.

интеграционную проверку; GitHub workflow требует ABI 4, SETUP и оба HELP-файла.

## Размеры APP

| Модуль | ABI 3 файл | ABI 4 файл | Прирост | Image + BSS | Остаток пула |
| --- | ---: | ---: | ---: | ---: | ---: |
| FOCAL | 13620 | 13932 | 312 | 20140 | 336 |
| BASIC | 11522 | 11772 | 250 | 17252 | 3224 |
| WBMP | 1616 | 1631 | 15 | 1924 | 18552 |
| Markdown с графикой | 12080 | 12156 | 76 | 15324 | 5152 |
| Markdown текст | 3812 | 3834 | 22 | 4652 | 15824 |
| CHIP-8 | 2563 | 2582 | 19 | 3356 | 17120 |
| SETUP (новый) | — | 6756 | — | 9216 | 11264 |

Файл включает 64-байтовый заголовок, BCJ + ZX0 и таблицу релокаций.
У прежних шести вариантов образ/BSS не изменились; прирост файла равен
размеру таблицы. Для SETUP исходная реализация была частью resident.

Раньше любой APP занимал аренду всех 20480 байт. Сейчас аренда равна
`align8(image + BSS)` и располагается в конце общего пула. Например, BASIC
оставляет 3224 байта для других клиентов; индекс C5 staging требует 1536.
Физический пул по-прежнему зарезервирован в BSS; дополнительный heap или
второй буфер не создаётся. Одновременно исполняется один APP, его блок
закреплён до возврата. Старые ABI 2/3 сохраняют аренду всего пула.

## Проверки

- Полный `run_all_tests.sh` с ASan/UBSan; дополнительно новые проверки
  справки, C-layout SETUP и граничных релокаций.
- Продукционный декодер: CRC, испорченные и усечённые таблицы, поддельные
  CRC, выходы за границы, неканонический LEB128, указатель после 16 КиБ.
- ARM Unicorn 2.1.4: HELLO, WBMP и C-проба указателей по трём адресам
  с двумя настоящими API-таблицами; повторный запуск, BSS, `.data`,
  невыровненные указатели, указатели функций, неизменность целых чисел.
- Все шесть System APP, оба Markdown по трём адресам на Classic/Mini;
  FOCAL → BASIC → FOCAL с перемещением кода и возвратом состояния.
  Реальная ARM-арифметика LIBM, шрифты и клавиши редактора; C5/периферия
  заменены макетами. Проверяются пиксели, регистры, аренды и границы блока.
- SETUP: информация о плате, отмена/запись даты, отрицательная калибровка,
  оба режима настройки шрифта, корректный и повреждённый FMK, восстановление
  предпросмотра/символов. UI-тесты используют настоящий resident-код применения
  профиля и проверяют постановку сохранения настроек.
- Справка: UTF-8 на границе файлов, подписи всех восьми комплектов, отсутствие
  ресурса во Flash, отсутствие/устаревание файла, занятое C5 и ошибка чтения.

На физическое устройство эта версия не устанавливалась. Предыдущие
[HIL-испытания](HIL-2026-09-06.md) относятся к ABI 3.

## Установка и воспроизведение

Установите прошивку с ABI 4 и весь новый `/System`, включая `SETUP.APP`,
`HELP0.TXT`, `HELP1.TXT`. При отсутствии SETUP его служебные экраны недоступны;
при отсутствии подходящей справки терминал выводит имена команд и синтаксис
`fsput` для восстановления. Формат C5 и программы FOCAL/BASIC не меняются.

```sh
MK61_TEST_SANITIZERS=1 bash tests/run_all_tests.sh
bash tests/run_f401_release_matrix.sh
```

Подробные размеры, SHA256 и параметры сравнения — в
[RELOCATION-RESULTS.json](RELOCATION-RESULTS.json). Формат и команды ARM-тестов —
в [SDK](README.md); инструкция для автора C/C++ приложения — в
[руководстве](../../doc/src/MK61s-mini-APP-Programming.md).
