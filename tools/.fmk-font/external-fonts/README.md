# Готовые внешние шрифты интерфейса UC1609

Это документация репозитория; она намеренно находится вне `programs`, чтобы
не попадать на USB-диск MK61S. На диск следует копировать только выбранные
файлы `programs/Fonts/*.FMK`. В меню `Настройки` → `Шрифты…` каждый такой
файл появится отдельным вариантом под именем файла без расширения. Например,
`DejaVu-14.FMK` показывается как `DejaVu-14`; размер уже содержится внутри
файла и отдельно для него не переключается.

Готовый набор:

| Файл | Растр | Для чего удобен |
| --- | ---: | --- |
| `DejaVu-12.FMK` | 12 px, интервал 1 px | более длинные строки, пять строк UI |
| `DejaVu-14.FMK` | 14 px, интервал 2 px | основной читаемый вариант, четыре строки UI |

Оба файла — пропорциональные растры на основе DejaVu Sans 2.37 без сглаживания и
масштабирования на микроконтроллере. В каждом 181 знак: ASCII, русская
кириллица с Ё/ё, четыре стрелки, ≤/≥ и другие интерфейсные символы.
Все 18 частных знаков M8 записаны непосредственно в FMK. Знак `⊻` вручную
перерисован как калькуляторный XOR в кружке вместо шрифтового подчёркнутого V;
`≤` и `≥` — как зеркальная пара с отдельной нижней чертой. Остальные растры
происходят из DejaVu. После добавления двенадцати знаков и этих трёх правок
166 прежних рисунков и метрики строк остались побитно
неизменными.

Калькуляторный индикатор остаётся на своём неизменяемом шрифте.

Шрифты предназначены только для STM32F411 с графическим UC1609. На F401,
A00/A02 и WS0010 каталог не предлагается в настройках.

## Воспроизведение

Исходник: [DejaVu Sans 2.37](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37),
`DejaVuSans.ttf`, SHA-256
`7da195a74c55bef988d0d48f9508bd5d849425c1770dba5d7bfc6ce9ed848954`.
Полный текст лицензии находится рядом, в `LICENSE-DejaVu.txt`, и включается в
отдельный архив уведомлений релиза, а не в файловую систему устройства.

Проверенные исходные атласы `dejavu-12.json` и `dejavu-14.json` находятся
рядом с этим текстом, вне USB-диска. Они получены программой
`tools/.fmk-font/font_preview.cpp` из указанного TTF; вручную исправлены
растры `⊻`, `≤` и `≥`. Итоговые файлы собираются без изменения пикселей:

```sh
python3 tools/build_fmk_from_ui_atlas.py \
  tools/.fmk-font/external-fonts/dejavu-12.json \
  programs/Fonts/DejaVu-12.FMK
python3 tools/build_fmk_from_ui_atlas.py \
  tools/.fmk-font/external-fonts/dejavu-14.json \
  programs/Fonts/DejaVu-14.FMK
```

Контрольные SHA-256 готовых файлов:

- `DejaVu-12.FMK`: `a465426ca1469904d44608bd362bd35e9add44b3e3d0e4f8d38e6e0ec2599fd7`;
- `DejaVu-14.FMK`: `e166cf0eb552378332259a8f5ba52e9a97387c583890b44555d661e45a59e4ba`.
