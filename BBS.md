# MK61 BBS

BBS исполняется на калькуляторе: BASIC хранит сообщения, выводит меню и
обрабатывает ввод; `autoexec.m61` переключает семь модулей BASIC. Компьютер или
Raspberry Pi служит мостом между USB CDC и одним TCP/Telnet-посетителем.
У моста один вход `tools/bbs.cmd` и две реализации в `tools/.bbs`:
Python для macOS/Linux и PowerShell для Windows. Логика BBS — на BASIC.

## Установка и запуск

1. Собрать прошивку и **весь соответствующий комплект System APP из этой
   ветки** штатным `tools/build_f401_bundle.sh`. Поддерживаются STM32F401/F411
   со штатной Flash VM. Старые BASIC/LANGVM несовместимы с новым байткодом v14.
   PicoCalc и автономный старый интерпретатор в этот комплект BBS не входят.
2. Скопировать `programs/network/BBS` на USB-диск калькулятора, например в
   `/network/BBS`. Сохранить вложенный каталог `Messages` с `welcome.txt`.
   В `Messages` должны находиться только обычные TXT-файлы сообщений, до
   1536 байт M8 каждый. Названия каталогов и модулей можно оставить как есть.
3. В Проводнике открыть каталог BBS (он запускает `autoexec.m61`) либо
   выполнить в терминале калькулятора `open /network/BBS/autoexec.m61`.
   Освободить USB CDC: закрыть программу обычного терминала.
4. Запустить мост. На macOS/Linux нужен Python 3.7 или новее:

   ```sh
   ./tools/bbs.cmd serve --port /dev/cu.usbmodemXXXX --listen 2323
   ```

   В Linux имя обычно имеет вид `/dev/ttyACM0`. На Windows:

   ```powershell
   .\tools\bbs.cmd serve --port COM3 --listen 2323
   ```

   Лаунчер выбирает PowerShell 7, а при его отсутствии — штатный Windows
   PowerShell 5.1. Обе реализации используют стандартные библиотеки:
   Python — POSIX CDC, PowerShell — .NET `SerialPort`; дополнительных
   пакетов не требуется. `serve` принимает одинаковые параметры:
   обязательный `--port`, `--host` (по умолчанию `127.0.0.1`),
   `--listen` (по умолчанию `2323`, допустимо 0…65535; 0 выбирает свободный порт).
5. Подключиться: `nc 127.0.0.1 2323` или `telnet 127.0.0.1 2323`.
   Для доступа с другой машины явно добавить мосту `--host 0.0.0.0`.
   По умолчанию он слушает только localhost. Используется UTF-8, включая
   кириллицу; символы должны представляться в M8.

`L` показывает имена сообщений, `R` читает выбранное имя из списка, `P`
создаёт сообщение, `?` показывает справку, `Q` отключает посетителя. Регистр
команд свободный; имя файла при чтении нужно ввести как в списке.
Имя автора — до 32 символов, тема — до 64, текст — четыре строки по 128.
Сохранение требует `Y`. Номера файлов выбираются без перезаписи существующих
сообщений, до `m999.txt`; после ошибки записи BBS не повторяет её сама.

После отключения BBS снова ждёт посетителя. Ввод имеет тайм-аут 60 секунд.
**ESC на калькуляторе** завершает корневой M61, закрывает канал и освобождает
строки и открытый файл. Остановить мост можно Ctrl+C. Для обычного терминала
снова открыть порт после остановки моста и BBS. USB Screen и USB:TEXT нельзя
использовать одновременно.

## Что хранится на устройстве

Сообщения — обычные TXT в `Messages`, их можно читать, копировать и удалять
штатными средствами. Пользовательских аккаунтов, паролей и личной почты нет.
Резервный каталог `/System/BasicIO` принадлежит текстовой службе: `Owner.txt`
содержит метку `BTX1`, `Snapshot.txt` — временную копию открытого файла.
Копия нужна, чтобы открытый читатель не менялся при замене исходного файла.
Она удаляется при закрытии или завершении корневого сеанса; след после
перезапуска заменяется при следующем открытии. Удалять содержимое рабочего
каталога службы во время исполнения нельзя.

Сформировать архив с каталогом для C6, мостом, кодеком и этой инструкцией:

```sh
./tools/bbs.cmd package --output .build/bbs.zip
```

На Windows та же команда: `.\tools\bbs.cmd package --output .build\bbs.zip`.
Архив включает `C6/network/BBS`, инструкции и каталог `host` с `bbs.cmd`
и обеими реализациями в `.bbs`. После распаковки запускать `bash host/bbs.cmd`
на macOS/Linux или `.\host\bbs.cmd` на Windows с теми же параметрами.
Переносить нужно весь `host`, включая скрытый `.bbs`.
Справка: `bbs.cmd --help`. Ошибка параметров даёт код выхода 2,
ошибка порта или файлов — 1.

## Проверка

```sh
bash tests/run_basic_text_tests.sh
MK61_TEST_SANITIZERS=1 bash tests/run_basic_text_storage_tests.sh
```

Первый набор запускает модули BBS и Python-мост через настоящий локальный TCP
и PTY; при установленном `pwsh` проверяет также PowerShell-мост через .NET
`SerialPort`, совпадение файлов в архивах и тесты протокола PowerShell.
У PTY отсутствуют модемные линии, поэтому только в этом тесте отключён DTR.
Для автономной проверки Windows-реализации:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\run_bbs_powershell_tests.ps1
```

Второй использует резидентную службу, эмулятор NOR с настоящим C9 и Flash VM:
запись, открытая версия файла после замены, чтение по частям, вывод после
изменения хранилища, сохранение строк между модулями, тайм-ауты и ESC.
Аппаратный прогон с USB CDC остаётся отдельной проверкой после установки.
Описание языка и протокола: [BASIC-TEXT.md](BASIC-TEXT.md).
