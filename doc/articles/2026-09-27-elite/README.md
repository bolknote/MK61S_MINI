# Материалы для статьи

`article.md` — текст для редактирования; `article.html` — локальный просмотр с иллюстрациями. Первые два абзаца взяты из сообщения автора, ссылки оформлены внутри текста. На сайт ничего не опубликовано.

`images/` — выбранные иллюстрации. Это полученные от физического Classic V3 кадры USB Screen, а не картинки из эмулятора. Палитра совпадает с режимом «Холодный» приложения: светлые пиксели `#bcecff`, фон `#0b1d25`. Каждый исходный пиксель показан квадратом 4×4; содержимое экрана не ретушировалось. Размер PNG — 768×256, исходного экрана — 192×64.

`captures/` — остальные игровые кадры и сырые буферы по 1536 байт. Формат сырого кадра: восемь страниц высотой восемь пикселей, по 192 байта; младший бит байта — верхний пиксель страницы.

`playthrough.json` — последовательность снимков и эталонные состояния настоящего ядра на ПК. Перед каждым снимком на устройстве проверялись совпадение экранного буфера, регистров R0…RE, адреса остановки и активного банка с эталоном. Поля `pages` в JSON получены от эталона; это не полный дамп банков устройства. Время `elapsed` включает служебные запросы и подтверждение остановки, поэтому не является чистым временем вычисления или появления кадра.

При прохождении использованы обычные команды игры через `cmd`; игровые регистры и генератор случайных чисел не подменялись. Сначала покупка еды, перелёт, продажа и два улучшения лазера, затем перелёты между первыми двумя мирами. Пират встречен на восьмом перелёте, носитель — на пятнадцатом. Для иллюстраций порядок действий сначала проверен на ядре ПК, затем воспроизведён на устройстве.

На устройстве была прошивка `C2387C20`, которая не поддерживает уже согласованную `1F 56 nn`. Установлены те же исходники подготовленной 25 сентября сборки, с включённым `MK61_ENABLE_USB_SCREEN=1`; итоговый build `C35A159E`. Новых команд и изменений правил игры в этой работе нет. Прежние 512 КиБ внутренней Flash сохранены в `/private/tmp/elite-blog-old-firmware.bin`.

Образ игры: 1983 байта; SHA-256 `692c356a90a0b6209180f81cf47893e324248d154abf8c6e284f730c02899d82`. Все пять файлов `/games/ELITE` после записи проверены обратным чтением. Устройство: Classic V3 UC1609, public ID `AEB505B6E0067623`.

В конце прохождения дополнительно прочитаны все 54 значения банков 24…29: совпадают с ядром ПК. Сырая запись чисел может быть ненормализованной, поэтому сравнивались числовые значения. CRC прошивки действительна, `CRASH none`. Корабль оставлен в порту: 896 кредитов, корпус 54, щит 60, бак 25, ракет нет. Подробности — `device-check.txt`.
