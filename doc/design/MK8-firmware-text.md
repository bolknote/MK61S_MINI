# M8: единая внутренняя кодировка текста

M8 — однобайтовая кодировка всего текста внутри MK-61S. В ней хранятся строки
прошивки, имена и текстовые файлы C6, исходники языков после установки и
текстовые аргументы APP ABI 6. У строки нет маркера, префикса или режима:
каждый текстовый API принимает M8 безусловно.

Unicode существует только на внешних границах:

- USB-диск преобразует имена M8 в FAT LFN UTF-16LE и обратно;
- текстовые файлы USB преобразуются M8 <-> UTF-8, бинарные не меняются;
- исходники в Git остаются читаемыми UTF-8 и кодируются при установке;
- терминальный провод всегда CP1251; `mkc` и USB Screen преобразуют его в
  локальный Unicode сами.

ASCII и определённые печатные байты Windows-1251 сохраняют свои позиции.
`09`, `0A` и `0D` остаются TAB, LF и CR. `00` — терминатор C-строки. `7F` и
неопределённый в CP1251 байт `98` недопустимы. Свободные C0-позиции заняты
символами калькулятора:

| Байт | Символ | Байт | Символ |
|---:|:---|---:|:---|
| `0E` | `←` | `17` | `≥` |
| `0F` | `→` | `18` | `×` |
| `10` | `↑` | `19` | `÷` |
| `11` | `↓` | `1A` | `²` |
| `12` | `π` | `1B` | `ʸ` |
| `13` | `√` | `1C` | `ˣ` |
| `14` | `↻` | `1D` | `⊻` |
| `15` | `≠` | `1E` | `⁻` |
| `16` | `≤` | `1F` | `↵` |

Обычные печатные знаки CP1251, в частности `…`, `°`, `№`, кавычки и тире,
остаются на штатных позициях этой кодовой страницы.

Русский диапазон переводится арифметически:

```text
C0..FF -> U+0410 + (byte - C0)       # А..я
C0..EF -> UTF-8 D0, byte - 30
F0..FF -> UTF-8 D1, byte - 70
```

Исключения CP1251 `80..BF` находятся в одной таблице, а частные символы — в
плотной таблице `0E..1F`. Строгий кодек и case-fold находятся в
`code/mk8_codec.hpp`. Хостовая эталонная реализация — `tools/m8_codec.py`.
Непредставимый Unicode при импорте отклоняет весь файл; тихого смешивания
UTF-8 и M8 нет.

В терминал совместимые байты идут непосредственно. Символы из `0E..1F`,
которых нет в CP1251, разворачиваются в читаемые ASCII-последовательности:
`->`, `<-`, `!=`, `<=`, `>=`, `pi`, `sqrt` и т. п. Обратное преобразование
для отображения выполняют только настольные клиенты.

Читаемые UTF-8-строки интерфейса пишутся прямо в C++: `M8("Настройки")`
возвращает указатель на строку M8, а `M8_ARRAY("А\0Б")` создаёт
constexpr-массив точной длины для слитных таблиц и метаданных. Макросы
определены в `code/mk8_literal.hpp`; непредставимые символы и неверный UTF-8
останавливают сборку. В прошивке остаются только однобайтовые данные без
конвертации на устройстве.

`tests/run_utf8_codec_tests.sh` проверяет все допустимые байты и обе внешние
границы UTF-8/UTF-16. `tests/m8_codec_self_test.py` сверяет хостовый кодек,
частные символы и представимость всех поставляемых текстовых программ.

## Шрифты

FMK — бинарный внешний формат и поэтому не подвергается файловой
перекодировке. Его каталог символов должен быть M8-ориентированным: SETUP.APP
один раз проверяет и разворачивает FMK в готовое представление, а резидентный
рендерер ищет глиф по однобайтовому коду M8. Произвольный Unicode внутри
готового шрифта не поддерживается: это осознанная часть единой внутренней
модели, а не эвристика формата.
