# Комплект программ для фактической сборки

`tools/programs/program_bundle.py` подбирает штатные программы из `programs/` по
`program-capabilities.json` согласованного комплекта прошивки. Этот файл создают
сборщики STM32 и PicoCalc. Он содержит конечные возможности, платформу, ABI,
предел памяти APP, идентификатор сборки и SHA-256 файла прошивки. Для старого
комплекта без этих сведений требуется новая сборка; утилита не угадывает
возможности по названию MCU или текущему состоянию меню.

На STM32 учитываются окончательные определения из `build.flags`; в релизной
матрице F411 — препроцессор с реальной командой компиляции. PicoCalc также
использует препроцессор реальной сборки. Windows-сборщик записывает тот же
формат средствами PowerShell, без зависимости сборки от Python.

## Команды

Для выбранной STM32-сборки в `tools/mk61-firmware.cmd` доступны меню и CLI:

```sh
./tools/mk61-firmware.cmd --mcu f401 --profile classic-v2 --preview-programs
./tools/mk61-firmware.cmd --mcu f401 --profile classic-v2 --install-all
./tools/mk61-firmware.cmd --mcu f401 --profile classic-v2 --install-programs --verify-programs
```

`--install-all` сначала проверяет весь состав, затем устанавливает согласованный
`System`, после него — программы. `--install-programs` проверяет наличие
необходимых System APP и не заменяет их. Для нескольких подключённых приборов
можно явно указать `--port`. Новая функция подбора требует Python 3.10+.

Отдельная команда работает также с готовым комплектом PicoCalc:

```sh
python3 tools/programs/program_bundle.py --bundle .build/firmware/picocalc-pico-h
python3 tools/programs/program_bundle.py --bundle .build/firmware/picocalc-pico-h --install --port /dev/cu.usbmodemPORT
python3 tools/programs/program_bundle.py --bundle .build/firmware/picocalc-pico-h --export /tmp/pico-programs
```

Без `--install` выполняется только локальный просмотр; `--json` выводит полный
план. `--export` создаёт новый каталог с программами и manifest для комплекта.
Пути `source` локального плана в распространяемый manifest не попадают.
Релизные архивы STM32 помещают подборку в `Programs/`; упаковщик PicoCalc
использует тот же подбор при формировании содержимого microSD.
Если в готовом комплекте уже есть manifest программ, установщик берёт файлы
из этого комплекта и проверяет их SHA-256. Более новый локальный checkout
не подменяет содержимое ранее выпущенного архива.

## Подбор

Требования находятся в `dev/lib/program-catalog.json`. BASIC/FOCAL-части игры
проверяются как единый пакет. Памятки и картинки включаются по возможностям
просмотра; платформенные ресурсы PicoCalc не предлагаются STM32.

SHEET требует графику, математические сервисы и тип S1. Листы `.mks` включаются
только вместе с совместимым SHEET.APP. У пользовательских APP проверяются
заголовок, CPU, ABI, релокационный флаг, CRC, размер контейнера и памяти.

Учитываются пределы файлов, включая 1536 байт FMK на F401 и 8192 на F411.
Слишком большой файл пропускается с указанием причины. Каталоги, ещё не
описанные в каталоге требований, показываются как неподготовленные и не
устанавливаются автоматически.

## Передача и обновление

За CDC, преобразование UTF-8/M8 и выбор устройства отвечают существующие
клиенты MKC. Частный `--bundle-session` удерживает один сеанс на всю установку.
До операций проверяются профиль и точный идентификатор установленной прошивки.
`fsput` подтверждает размер и CRC; повторное скачивание после записи включается
отдельно через `--verify` / `--verify-programs`. Установка System сохраняет свою
существующую проверку чтением.

Установщик ведёт перечень принадлежащих комплекту файлов с SHA-256. Неизменённый
штатный файл можно обновить или удалить при исключении из состава. Изменённый
файл, постороннее сохранение или конфликтующий пользовательский файл остаётся
на приборе и показывается в отчёте. Чтобы принять это решение при обновлении,
читаются только существующие файлы, которые потребуется обновить или удалить.
Если штатная версия файла не менялась, его содержимое повторно не скачивается.
Это не повторная проверка свежей загрузки.

Учёт хранится в `/System/PROGRAMS.TXT` и `/System/ProgramIndex/`: сжатая таблица
делится на текстовые части до 1200 байт, чтобы укладываться в ограничения F401.
Новый индекс публикуется последним. Старая таблица и пути проверяются до
изменений. Каталоги пользователя не удаляются. Прерванная установка возвращает
ошибку; повторный запуск сверяет реально присутствующие файлы, не принимает
незавершённый сеанс за успешно установленный комплект.

Автотест: `python3 tests/program_bundle_self_test.py`. Он проверяет подбор,
несовместимый CPU, предел шрифтов F401, привязку к образу, сохранность данных,
дополнительное чтение, экспорт и реальные mock-сеансы обоих клиентов MKC.
