# Оставшаяся область pow на RP2040, 2026-11-17

Универсальная практическая граница времени для всех binary64 ещё не
доказана. Этот расчёт сужает область, для которой требуется новое
сравнение или более сильная оценка расстояния. Для одной области уже
доказано завершение на первой 512-битной ступени с ограниченным числом
арифметических операций. Код прошивки не изменён.

## Условия оставшегося случая

Пусть `x` — положительная конечная величина основания, `abs(y)=p/q`
сокращено, `q=2^k`, а `m` — середина между соседними результатами binary64.
Отдельные правила обрабатывают `x=1`, `abs(y)<2^-64` и `abs(y)>=2^63`.
В оставшейся области `k<=116`. При дробном показателе `p<=2^53-1`;
при целом `p<=2^63-1024`.

Если ограждение степеней при точности `P` отказывается выбрать сторону,
то

```
abs(y*ln(x)-ln(m)) < 4*(abs(y)+1)*2^(1-P).
```

При `P=8192` правая часть меньше `2^-8126`. Ранее отдельно покрыты
зависимые основания и точные ничьи. Знак `ln(m)` обязательно совпадает
со знаком `y*ln(x)`: модуль любого ненулевого логарифма середины больше
`2^-54`, а возможное расстояние значительно меньше.

Если нечётные коэффициенты основания и середины имеют соответственно
`a` и `b` бит, вычисление точно при `a*p<=P` и `b*q<=P` для положительного
показателя; для отрицательного достаточно `a*p+b*q<=P`. Поэтому при
8192 битах для любого основания исключены, например, положительные
`p<=154, q<=128`. Для отрицательного показателя при `q=1,2,4,8,16,32,64,128`
достаточные границы `p` равны `153,152,150,146,138,121,89,24`.

Для малых показателей близкие середины ограничены окрестностью единицы.
Пусть `2^e<=abs(y)<2^(e+1)`, `-64<=e<=-12`,
`Y=(2^53-1)*2^(e-52)` и `T=745*Y+4*(Y+1)*2^(1-P)`. Тогда `T<1/2`.
Все возможные середины имеют вид

```
B = floor(ceil(T*2^54)/2), A = floor(ceil(T/(1-T)*2^53)/2);
m = 1-(2*j+1)*2^-54,  0<=j<B;
m = 1+(2*j+1)*2^-53,  0<=j<A.
```

Например, для бинады `e=-64` остаётся только `m=1-2^-54`; для `e=-54`
достаточно рассмотреть 745 середин ниже единицы и 373 выше. Сертификат
вычисляет точные целые границы для всех 53 бинад.

В наиболее глубоком случае `q=2^116` обязательно `y*ln(x)<0` и
`abs(ln(x))>512`. Основания в `[2^-738,2^738]` исключены. Нечётный
числитель должен быть не меньше `6194838499927525` при `x<1` или
`6497320848556799` при `x>1`.

## Полностью исключённая область степеней двойки

Для `x=2^s`, целого `-1074<=s<=1023`, и `100<=k<=116` логарифм
результата по основанию два лежит на сетке `N/2^k` с целым `N`.
Предыдущие границы оставляют 71 520 возможных середин округления
и 143 039 допустимых пар «середина — знаменатель» даже при `P=128`.

Для каждой пары сертификат строит рациональное ограждение
`abs(log2(m))*2^256`. Для логарифма середины достаточно трёх членов
ряда `2*atanh(t)`, для `ln(2)` используются 90 членов и геометрическая
оценка остатка. Расстояние ограждения до целочисленной сетки положительно
во всех случаях. Середины вне этих диапазонов отделены сильнее:
разница между 745 и `1074*ln(2)` даёт расстояние больше `2^-65`.
Таким образом, во всей указанной области получено строгое
`abs(y*ln(x)-ln(m))>2^-121`.
Минимальная нижняя граница расстояния в единицах `2^-256` равна
`87881160243273093583047111011685153480330`.

Это исключает отказ 128-битного ограждения степеней во всей указанной
области, включая все допустимые числители. Вместе с ранее проверенной
шириной интервального вычисления это доказывает, что первая
512-битная ступень уже возвращает правильно округлённый результат.
Её нормализованный логарифм мантиссы равен нулю, индекс редукции равен
нулю, а модуль аргумента экспоненты меньше `2^-37`. Округление вверх
в ряде учтено целой рекурсией; требуется не больше 14 членов для
каждого из двух концов интервала.

Граница работы этой ступени: **60 полноразмерных умножений,
77 760 разрядных умножений с накоплением внутри них и 2 088 разрядных
делений**. Дополнительная работа включает скалярное масштабирование,
упаковку и вызовы. Граница арифметических циклов не является границей
времени полного `pow` для остальных оснований.

## Передача подсказки между ступенями

Сертификат интервального вычисления на 1024 битах гарантирует, что
неразрешённый корректный вход публикует одну пару соседних результатов.
Точная малая ступень и ограждение на 4096 битах сохраняют подсказку при
отказе. Поэтому в обычной цепочке вызовов полный бинарный поиск в
`mk61_m0_pow_round_final` недостижим. Малая точная ступень делает не
больше двух сравнений границ; последующие ступени на 4096 и 8192 битах
и потоковое точное сравнение получают по одной границе. Это убирает
лишний множитель поиска из оценки цепочки, но не ограничивает работу
самого потокового сравнения практическим числом.

## Проверки и воспроизведение

Нативный тест выполнил 5 428 сравнений границ с направленным MPFR 4.2.2
при точностях 128, 256, 4096 и 8192 бита. Неверных решений нет.
Предикат необходимых условий не исключил ни одного неразрешённого
случая. Добавленная точная ничья `x=3^32, y=17/16` действительно требует
больше 256 бит коэффициента и разрешается старшими ступенями.

ARM-тест принудительно вызвал штатную rescue-цепочку на 28 выбранных
входах доказанной области. Все ответы совпали с MPFR и завершились
на 512 битах. Максимумы в этой выборке: 1 212 441 гостевая инструкция,
2 712 байт стека, 56 полноразмерных умножений, 1 944 разрядных деления.
Эти наблюдаемые максимумы относятся к конечной выборке.
Исполнены реальные обёртки памяти и захваченная заводская BootROM;
проверены сохраняемые регистры, SP, допустимые записи и модель делителя.
ELF `5CD0685C/511BE730`, SHA-256
`519a4a4d1867ca45bb89ea45160bcc63f8c5006c03d9094690732bf9610e846f`.
