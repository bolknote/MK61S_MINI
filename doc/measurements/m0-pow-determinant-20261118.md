# Области `pow` с гарантированным завершением на 16 384 битах

Штатная цепочка RP2040 определяет округление до потокового
сравнения для всех **1 610 612 737** положительных binary64
оснований с `abs(x-1) <= 2^-23` и всех `abs(y) <= 16`. В этой
окрестности прежний сертификат покрывал `abs(x-1) <= 2^-27`
при `abs(y) <= 1/2`. [Сертификат логарифмической ступени](m0-pow-log-side-20261118.md)

Радиус можно увеличить для некоторых интервалов показателя.
Каждая строка покрывает все двоичные числа в указанных границах.

| Радиус `abs(x-1)` | Модуль `y` |
| ---: | --- |
| `2^-23` | `[0, 16]` |
| `2^-22` | `[2^-27, 1/2]` |
| `2^-20` | `[2^-18, 1/2]` |
| `2^-18` | `[2^-5, 1/2]` |

## Окрестности степеней двойки

Пусть `x=2^s*u`, где `s` — целое от −1074 до 1023. Если
`s*y` целое, то `m=2^(s*y)*v` даёт точное равенство
`y*ln(x)-ln(m)=y*ln(u)-ln(v)`. Нормализованная середина `v`
сохраняет не более 54 значащих битов, включая границы субнормальных
и переполнения. Для ненулевого `s` сокращённый знаменатель `q`
показателя делит `s`, поэтому `q<=1024`.

| Радиус `abs(u-1)` | Максимум `abs(y)` |
| ---: | ---: |
| `2^-4` | `1/2` |
| `2^-5` | `2` |
| `2^-8` | `16` |
| `2^-14` | `256` |
| `2^-17` | `1024` |

Эти границы также действуют при `s=0`, если `q<=1024`.
Например, для `y=511/512` сертификат покрывает **914 793 674 309 635**
положительных оснований вокруг `2^-1024`, `2^-512` и `2^512`.
В каждой из степенных ступеней на 4096 и 8192 битах при
`q<=1024` и `abs(y)<=1024` требуется не более 31 полноразмерного
и 20 коротких произведений. В интервалах показателя, к которым
применён определитель около единицы, максимумы составляют 137 и 52.

## Доказательство

При зазоре `abs(y*ln(u)-ln(v))<=2^-128` модуль логарифма `v`
ограничен сверху через радиус основания и верхний конец интервала
`abs(y)`. В каждой строке это помещает оба аргумента в `(1/2,2)`.
Их рациональная логарифмическая высота не выше `54*ln(2)`.
При ненулевом логарифме середины оба члена разности должны иметь
одинаковый знак. Для ненулевых логарифмов можно взять обратные
дроби и применить теорему 1 к положительным логарифмам с
коэффициентами `p,q`, где `abs(y)=p/q` сокращено.
[Теорема 1 Лорана, стр. 326](https://www.impan.pl/shop/en/publication/transaction/download/product/82485)

Первое условие мощности множеств в теореме следует из
мультипликативной независимости. Совпадение значений `r*q+s*p`
во второй решётке требует `p<R2` и `q<S2`. В этом случае
полные коэффициенты помещаются в точное сравнение на 8192 битах.
Для всех прочих пар проверяющая программа ограждает логарифмы целых
чисел рядом для `atanh` и проверяет неравенство теоремы рационально.
После учёта множителя перед логарифмической формой самая слабая
из полученных границ для независимых оснований — `2^-16279`.
Этого достаточно для ступени, которая пропускает дальше только
зазоры меньше `2^-16300`. Для зависимых аргументов ненулевой
зазор не меньше `2^-170`. Нулевая форма означает точную ничью,
которую разрешает точное ограждение степеней.
[Оценка для зависимых аргументов и ничьих](m0-pow-power-bounds-20261117.md)

## Проверки

Выборка из 100 пар на границах областей побитно совпала с
направленным MPFR 4.2.2 через публичный ARM-вызов
`mk61_m0_cr_pow`. Нативный компаратор сверил 199 соседних
границ этой выборки. Ещё на пяти парах в связанном ELF
`22BF1BEC/5672DAB8` с заводской BootROM в эмуляторе
принудительно пропустили сравнение на 8192 битах.
Все пять ответов дала логарифмическая ступень. Наблюдавшийся
максимум в этом прогоне — 111 419 692 инструкции и 15 508 байт
стека.

```sh
python3 -B dev/tools/certify_m0_pow_log_side.py --json /tmp/pow-log.json
python3 -B dev/tools/certify_m0_pow_determinant.py --json /tmp/pow-determinant.json
```

Практическая верхняя граница для всех пар binary64 остаётся открытой.
Сертификат исключает потоковую ступень в перечисленных областях.
[Параметры, хеши исходников и результаты проверок](m0-pow-determinant-20261118.json)
