# Гарантированная точность pow в окрестности единицы, 2026-11-17

Для положительного основания и середины округления в
`[1-2^-37,1+2^-37]` доказано, что существующая ступень на 8192 битах
всегда определяет сторону границы. Потоковое сравнение здесь не нужно.
Достаточная точность равна 8032 битам. Отдельное достаточное условие
на сами входы: `abs(x-1)<=2^-37`, `abs(y)<=1/2`.
Практическая универсальная граница для остальных binary64 ещё не
получена; код прошивки не изменён.

## Параметры доказательства

Использована теорема 2 Лорана с настраиваемым параметром, учитывающим
малость логарифмов, вместо общей оценки следствия 2. Формула проверена
по странице 327 первичной статьи.
[Laurent, Acta Arithmetica 133 (2008), стр. 327](https://www.impan.pl/shop/en/publication/transaction/download/product/82485)

Пусть `d=2^-37`, `abs(y)=p/q` сокращено, `q` — степень двойки,
`m` — середина округления. Для любого числа в `[1-d,1+d]`
модуль логарифма не больше `d/(1-d)`. После инвертирования чисел
меньше единицы обе базы больше единицы, их рациональные высоты
не меняются. Числитель и знаменатель каждой базы не больше `2^54`.
Это дополнительно проверено для всех 98 305 кодировок основания
и 98 304 возможных середин в интервале.

При отказе ограждения степеней с `P>=128` расстояние до границы
меньше `2^-62`. Ту же границу обеспечивает подсказка после отказа
1024-битного интервала. Логарифм любой середины по модулю больше
`2^-54`, а логарифм активного основания — больше `2^-53`.
Следовательно, `2^-19<abs(y)<2^17`, откуда `q<=2^71`, `p<2^53`.

Параметры теоремы:

| Параметр | Значение |
| --- | --- |
| `D` | 1 |
| `mu` | 1/3 |
| `rho` | `2^39` |
| `a1`, `a2` | 79 |
| `h` | 50 |

Точный рациональный расчёт даёт верхнюю границу требования на `h`
меньше `49.763`; ограничения на `a1*a2`, `lambda` и высоты также
проверены. Каждый квадратный корень ограничен рациональными числами
с 192 дробными битами; обе стороны проверены целыми квадратами.
При вычислении верхних границ используются нижние положительные
знаменатели, поэтому зависимости между параметрами не сужают интервалы.
Плавающая арифметика в оценке теоремы не используется.

Получена оценка для независимых оснований

```
ln(abs(p*ln(alpha)-q*ln(beta))) > -5466.
```

После деления формы на `q<=2^71` расстояние исходного результата
в логарифмах строго больше `2^-7957`. Отказ существующего ограждения
при точности `P` требует расстояния меньше `2^(66-P)`. Эти условия
несовместимы уже при `P=8032`. Для зависимых оснований ненулевое
расстояние не меньше `2^-170`; при точных ничьях достаточно вычислить
коэффициенты размером до 1728 бит. Эти случаи покрыты прежним
сертификатом. Поэтому 8192-битная ступень разрешает все случаи
в указанной области.

## Условие на входы и граница арифметической работы

При `abs(y)<=1/2` модуль истинного логарифма результата не больше
`d/(2*(1-d))`. У середины вне `[1-d,1+d]` он не меньше `d/(1+d)`.
Разность этих границ больше `d/4=2^-39`, что исключает отказ уже
128-битного ограждения для такой середины. Если поздняя цепочка
вызвана при указанном условии на входы, её граница обязательно
находится в доказанной области.

После корректной подсказки 1024-битного интервала каждый из этапов
на 4096 и 8192 битах делает не больше 124 полноразмерных произведений,
включая квадраты. С учётом рекурсивного квадрата и умножений на исходный
четырёхразрядный коэффициент верхние границы разрядных умножений
с накоплением равны **1 473 752** и **4 433 544** соответственно.
Эти границы относятся к штатной цепочке с подсказкой. Прямой вызов
компаратора с произвольным показателем может иметь другой объём работы.
Работа предыдущих интервалов, малой точной ступени, упаковки и вызовов
считается дополнительно. Это не замер микросекунд и не граница времени
для полного диапазона binary64.

## Проверки

Нативный тест выполнил 5 716 сравнений с направленным MPFR 4.2.2
на точностях 128, 256, 4096 и 8192 бита. Все выданные стороны верны.
При 8192 битах 61 проверка попала в новую область; отказов нет.
Добавлены обе границы интервала, внешние соседи, оба знака показателя
и рабочая нагрузка с 53-битным числителем и знаменателем `2^71`.
Предикат доказанных исключений не отбросил ни одного неразрешённого
случая. Конечный корпус проверяет реализацию; утверждение для всей
области основано на теореме и рациональном сертификате.
