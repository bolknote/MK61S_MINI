# Предел оценок двух и трёх логарифмов для `pow` на RP2040

Выделение `ln(2)` в третье слагаемое не даёт общего доказательства
для штатного порога `2^-16300`. Для одного реального входа
ни одна целочисленная замена трёх рациональных аргументов
не позволяет невырожденной ветви теоремы 2.1 Миньотта и Вутье
гарантировать зазор даже `2^-390544`. Сведение к двум логарифмам
в той же мультипликативной группе с формулами Лорана оставляет
предел `2^-103063`. Доказательство охватывает все параметры этих
формул, а сам вход разрешается с зазором между `2^-57` и `2^-56`.
[Теорема 2.1](https://arxiv.org/pdf/2205.08899v3),
[оценки Лорана](m0-pow-laurent-limit-20261119.md).

## Представление проверяемого входа

Для `x=7fd0000000000001`, `y=3ff0040201008043` берём середину
после `7fe00000000007f5`. Код проверяет её положение направленными
интервалами. Нормализуем `x=2^1022 X`, `m=2^1023 M` и кладём
`z=(ln X,ln M,ln 2)`, `w=(p,-q,E)`, где `y=p/q`, `q=2^52` и
`E=1022p-1023q=2938`. Тогда `w·z=q Delta`, где
`Delta=y ln(x)-ln(m)`. Вектор `w` примитивный, поскольку `p` нечётно.

Пусть строка `v_i=(s_i,t_i,r_i)` задаёт положительный логарифм
`ell_i=v_i·z` рационального аргумента `X^s_i M^t_i 2^r_i`.
Высота `h_i` есть логарифм максимума числителя и знаменателя
после сокращения. У нечётных числителей `X,M` нет общих простых
множителей, и логарифм каждого числителя больше `d=36`.
Поэтому `h_i >= d max(|s_i|,|t_i|)`. Из `ell_i <= h_i`,
`0 < ln(X),ln(M) < ln(2)` следует `|r_i| < 2h_i`.
У любого рационального аргумента больше единицы `h_i >= ln(2)`.

## Три логарифма

Пусть матрица `C` со строками `v_i` невырождена. Замена её
последнего столбца на `ell_i` умножает определитель на `ln(2)`.
Разложение по этому столбцу и высоты дают

```text
ln(2) <= 2/d² * sum_i ell_i h_j h_k ,  {i,j,k} = {1,2,3}.
```

Две строки имеют независимые проекции на первые две координаты,
так что `h_1 h_2 h_3 >= d² ln(2)`. При `a_i >= (rho-1) ell_i+2h_i`
произведение имеет оценку `Omega=a_1 a_2 a_3 >= 2d²(rho+3)ln(2)`.
Она сохраняется при произвольном целом определителе `C`.

Обозначим `H=K L log2(rho)`. Из (2.7), (2.13) следует
`RST > 3K²L`, поэтому `g > 25/108`. Все `R,S,T >= 4`.
В знаменателе `b` из (2.5) взвешенное произведение факториалов
не больше `K²`. Сумма весов отдельных множителей равна двум.
Числитель не меньше `(T-1)*sqrt((R-1)(S-1)) >= sqrt(RST)`,
так что `b > 1/K`.

При `H <= 390625` подстановка этой границы в (2.8) даёт
`K <= 78125` и верхнюю оценку `h_i < 85777`. Если `b_max` —
наибольший модуль коэффициента новой формы, то `b_max >= q/(6 max h_i)`.
Действительно, новые коэффициенты после сокращения, умноженные
на `C`, дают целое ненулевое кратное примитивного `w`.
В (2.5) произведение максимумов числителя и знаменателя двух
сокращённых отношений `b_1/b_3`, `b_2/b_3` не меньше `b_max`.
Это следует из `gcd(b_1,b_2,b_3)=1`: НОК двух сокращённых
знаменателей равен `b_3`, а числители восстанавливают `b_1,b_2`.
Следовательно `b >= 9 b_max/(4 K²) > 3,225`.

При `b>1`, `tau=ln(rho)` неравенство (2.8) и среднее
арифметическое дают

```text
(K+1) tau > 6g (3 Omega K² L)^(1/3).
H > 3(6g)^3 Omega L² / ((1+1/K)^3 tau² ln(2)).
```

Поскольку `exp(tau)/tau² >= e²/4 > 16/9`, подстановка
`K>=3`, `L>=5` и нижней оценки `Omega` даёт `H>390625`.
Это противоречит допущению `H<=390625`.

Для любого `H` то же неравенство (2.8) с `b>1/K` даёт
`h_i < H²`. Если новая форма равна `c q Delta` с целым
`|c|>=1`, присоединённая матрица даёт
`|b_3/(c q)| < 32 H^4`. Поэтому в невырожденном выводе
теоремы `Lambda'=A |Delta| exp(A |Delta|)` с `A>1/(32H^4)`.
При `|Delta|=2^-390544` величина `Lambda'` уже превышает
порог `2^-H`, так как `H-5-4log2(H)` возрастает после 390625.
Если условие малости формы выполнено для проверяемого входа,
оно выполнено и для этого меньшего гипотетического зазора.
Этот вывод теоремы допускает зазор `2^-390544` и поэтому
слишком слаб для штатного сравнения.

## Сведение к двум логарифмам

Пусть два независимых целых вектора строк `u,v` задают
рациональные аргументы, а их плоскость содержит `w`.
Для нормали `n=u×v` имеем
`p(n_1+1022n_3)=q(n_2+1023n_3)`.
Если обе скобки нулевые, это плоскость исходных `ln(x),ln(m)`.
Каждая её целая строка выражается целой комбинацией исходных
двух строк, поэтому применим уже проверенный предел `2^-103063`.

Иначе первая скобка ненулевая и кратна `q`, откуда
`||n||_inf > 2^42`. Для двух высот `8h_1h_2 >= ||n||_inf`.
Кроме того, `||n×z||_2 >= ||n||_2 |w·z|/||w||_2`
и `||w||_2 < 4q`. Так как `|Delta|>=2^-57`, одна
координата `n×z` по модулю больше `2^-18`.
Та же координата выражается через `v (u·z)-u (v·z)`.
Из ограничения на координаты строк следует
`2(h_1 ell_2+h_2 ell_1)>2^-18`.

Для `tau=ln(rho)` и `W=a_1 a_2/tau` произведение высот
даёт `W>2^21` при `tau<=32`. При `tau>32` ту же границу
дают смешанные члены `a_1 a_2`, поскольку
`(exp(tau)-1)/tau` возрастает, а `exp(32)>2^45`.
В обеих областях `W>tau`. Если `B` — наибольшая координата
двух строк по модулю, то `B<=W tau<W²`.

Формулы Лорана дают показатель потери больше `(64/45) W`
до перевода результата на исходный зазор. В теореме 1
множитель `A` при `|Delta|` не меньше `1/(4B)` по ненулевому
минору двух строк и `||w||_inf<2q`. Поэтому после перевода
потеря больше `(64/45)W-ln(4B)>W`. В теореме 2 множитель
перевода не усиливает нижнюю границу. В любой такой плоскости
финальная граница этих формул уже слабее `2^-3028508`.

## Одна дробь в определителе Чудновского

Прямой перенос оценок §11 на одну близкую дробь `p/q` требует
показателя приближения `ν > 8 192` в условии
`abs(ξ-p/q) <= q^-ν`. Это верно даже при допущении, что для
одной дроби удаётся построить ненулевой минор. Сохраняются
радиус Коши и условия сравнения оценок из (11.14)–(11.16).
[Препринт, §11](https://arxiv.org/html/2610.28079v1#S11).

Пусть `d` — число копий одной сокращённой дроби. У каждой
копии одинаковый вес `w`, определяемый `q`. Если интерполяция
сюръективна, она сюръективна и после ограничения на диагональ
`X_1=...=X_d`. Локально это диагональ `u_1=...=u_d`, поскольку
во всех координатах вычитается один и тот же логарифмический
ряд. Подстановка сохраняет вес и отображает локальное пространство
струй на пространство струй в трёх переменных. Число столбцов
после ограничения на диагональ асимптотически равно
`H³/(6 w_0² w)`. Число условий в `K` центрах равно
`K θ H³/(6 v² w)` в главном порядке. Поэтому
`K (w_0/v)² θ <= 1`, включая случай `d=1`.

Условие `g>0` из (11.16) требует `ν>1`, `A>θ` и
`A>1/(ν(1-η))`. Подстановка в (11.14) даёт

$$
  (L w_0)^2 \le \frac{\eta^3\theta^{d-1}}{(d+1)(d+2)A^d}
  \le \frac{\eta^3}{6A}
  < \frac{\nu\eta^3(1-\eta)}{6}.
$$

Максимум `η³(1-η)` на `[0,1]` равен `27/256`. Поэтому с
`c₂²=2 ln²(2)/9` из леммы 11.4 получаем
`(c₂ L w_0)² < ν ln²(2)/256`. Сравнение с положительным
слагаемым `R/w_0` из `E_an` уже требует
`ν > (16R/ln(2))²`. Для рациональных аргументов §11 берёт
`R=4K(1+abs(ln(abs(x)))+abs(ln(m))) >= 4`.

Для проверки `abs(Δ) >= 2^-16300` у границы полосы достаточно
показателя `ν=(16300+log2(abs(ln(abs(x)))))/log2(q)`, где
`Δ=y ln(abs(x))-ln(m)` и `ξ=ln(m)/ln(abs(x))`. При `q>=4`
он меньше 8 155, поскольку `abs(ln(abs(x)))<2^10`.
Для условия `abs(ξ-p/q) >= 2^-15783/q^4` показатель не выше
`4+15783/2`. Оба значения ниже необходимого для этого
переноса. Копирование единственного приближения в несколько
координат сохраняет указанное ограничение объёма струй.

## Подсчёт близких рациональных точек

Для графика `G={(x,y,m): m=x^y}` над замкнутым прямоугольником
с `x>0` алгебраическая часть плотна во всём графике.
При каждом рациональном `y=p/q` сечение по `x`
задаётся полиномиальным уравнением `m^q=x^p` при `p>=0`
или `m^q x^(-p)=1` при `p<0`. Это связная
полуалгебраическая кривая в `G`. Рациональные показатели
плотны, а `x^y` непрерывна. Поэтому расстояние до
алгебраической части совпадает с расстоянием до `G`.

Теорема 2 Хабеггера считает только точки вне окрестности
алгебраической части. Радиус этой окрестности `T^(-theta*lambda)`
не меньше радиуса приближения `T^(-lambda)` при
`T>=1` и `0<theta<=1`. На графике `pow` все близкие точки
уже внутри исключённой окрестности. Эта теорема не ограничивает
число кандидатов на переход к поточному сравнению.
[Хабеггер, теорема 2](https://arxiv.org/html/1608.04547#S1).

## Проверка

```sh
python3 -B -S dev/tools/certify_m0_pow_log_form_limit.py
python3 -B -S tests/m0_pow_laurent_limit_self_test.py
python3 -B -S tests/m0_pow_binary64_proof_self_test.py
```

Скрипт проверяет числовые неравенства рационально и удостоверяет
исходный вход. Результат относится к определённым формулам для
одной и той же группе аргументов. Гибридное доказательство,
которое обходит эти формулы на части входов, требует отдельной
проверки. Недостижимость потока во всём binary64 здесь не доказана.
