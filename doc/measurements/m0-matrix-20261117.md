# PicoCalc — повторный замер `sin`, `cos`, `atan` и `pow(x, −0,5)`

Прогон на Pico H с установленным образом `3FA1B158/B541AD9A` при
125 МГц. Все 4 412 ответов побитно совпали с MPFR 4.2.2. В 59 групп
вошли 48 сохранённых групп `sin/cos` с правильными ответами эталона,
семь групп `atan` и четыре замера `pow(x, −0,5)`. Два из последних
повторяют те же 30 обычных входов с 512 итерациями на раунд. Один из
длинных повторов циклически сдвигает входы на десять позиций.

Эталоном служат функции из factory BootROM v3 этой Pico. Для `atan`
вызван `atan2(x,1)`, для `pow(x, −0,5)` — `ddiv(1,dsqrt(x))`. Время
включает обёртки этих композиций в APP. Обеим сторонам соответствуют
свои контрольные вызовы. Пригодность всех входов проверена заранее на
снятом ПЗУ, точном ELF и направленном MPFR.

| Функция | Группы | Быстрее ПЗУ | Медленнее ПЗУ | Пары с разными знаками |
| --- | ---: | ---: | ---: | ---: |
| `sin` | 22 | 22 | 0 | 0 |
| `cos` | 26 | 26 | 0 | 0 |
| `atan` | 7 | 3 | 1 | 3 |
| `pow(x, −0,5)` | 4 | 0 | 4 | 0 |

Медиана считается по шести соседним парам раундов с противоположным
порядком библиотек. Для устойчивого выигрыша или проигрыша все шесть
разностей должны иметь один знак. Показаны наблюдаемые диапазоны.

| Входы | MK61, мкс | ПЗУ, мкс | Парная разность, мкс |
| --- | ---: | ---: | ---: |
| `sin`, обычные 126 входов | 12,1948 | 12,9361 | −0,9080…−0,7240 |
| `cos`, обычные 128 входов | 12,1548 | 12,9458 | −0,9241…−0,7732 |
| `cos(4073CD3AC0D1C8EC)`, прежний выброс | 12,0154 | 12,9441 | −0,9856…−0,9011 |
| `atan(3FB97996F4E5F9F0)` | 17,5134 | 17,3761 | +0,0078…+0,2034 |
| `pow(x, −0,5)`, обычные 30 входов | 3,1521 | 2,9675 | +0,1745…+0,2044 |
| Те же входы с 512 итерациями | 3,1380 | 2,9677 | +0,1702…+0,1713 |
| Те же входы с 512 итерациями и сдвигом | 3,1381 | 2,9677 | +0,1702…+0,1710 |
| `pow(x, −0,5)`, одиночный пограничный вход | 3,1923 | 3,0398 | +0,1489…+0,1580 |

Три смешанные группы `atan` содержат два трудных одиночных входа и
бывшую проблемную пару. Полный архив содержит исходные биты, обе
серии результатов, 12 раундов, контроль и счётчики XIP для каждой
группы. [Записи и входы](m0-matrix-20261117/records.jsonl.gz)

## Устройство и повторение

Закрытие через 276,3 с подтвердило `E6657CD423721C35`, `BOOTS=3`,
`CALCULATOR/CLOSED/NONE`, `CRASH=NONE`. Данные калькулятора и счётчики
записи настроек совпали до и после. Временный каталог на SD удалён,
CDC закрыт. Использован SD-only прогон без записи Flash или RTC.

Для сборки того же APP и входов из архива используются исходные
ELF/BIN/UF2 и снятый образ ПЗУ.

```sh
python3 -B tests/build_m0_rom_math_compare.py \
  --production "$resident" --bootrom "$bootrom" \
  --records doc/measurements/m0-matrix-20261117/records.jsonl.gz \
  --operations sin cos atan pow --directory /MK61S-M0-REPLAY \
  --output /tmp/m0-matrix-replay
```
