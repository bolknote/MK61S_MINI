# RP2040: закрытие известных nonpow-отставаний на HOST

Исторический отчёт отдельного этапа. Итог физических замеров и возврата
устройства: [nonpow 31 октября](m0-nonpow-20261031.md).

Приоритет пользователя: сначала закончить остальные нужные операции; `pow`
отложен. База — `main` 1a26f35cf7416d2bf7a12569c3b0db88fc2aae84.
Изменения перенесены только в собственное рабочее дерево, без коммита и без
изменения основного checkout. Устройство и SDK в этом этапе не использовались.

## Результат и границы приёмки

В неизменной матрице из 21699 входов / 107 групп устранены все **170** известных
индивидуальных проигрышей корректному Qfplib: преобразования — 110, сложение и
вычитание — 17, sin — 19, cos — 11, exp — 4, ln — 7, atan — 2.
Из 19882 сравнений с правильным эталоном 19252 быстрее, 630 равны, медленнее — 0.
1817 неправильных результатов эталона сохранены и исключены только из
сравнения скорости корректных ответов. Полные raw-результаты также сохранены.

Средние по корректному подмножеству: 104 группы быстрее, 2 равны, 1 без
корректного эталона (`tan/small_medium_remainder`, все128 ответов Qfplib неверны).
Составные эталоны `asin`, `acos`, `log10` помечены как композиции; прямого
Qfplib FMA нет. Эта матрица не доказывает равенство скорости на всех входах.

## Изменения

* RP2040 преобразует double→uint32 без общего C++ пути; отрицательный int64
  с нулевой старшей частью модуля и целые с17/18 значащими битами нормализуются
  короткими точными ветками.
* Сложение разных знаков при разности порядков2..54 использует беззнаковую
  96-битную разность с одним возможным сдвигом и точным RNE. Прежние guards,
  gap0/1 и специальный fallback сохранены.
* `atan` уточняет линейную часть из точного128-битного остатка и добавляет
  девятый член, сохраняя уже вычисленный полином. Неопределённый интервал
  передаётся прежнему независимому уточнению.
* `exp` использует уже вычисленный модуль остатка и три коротких умножения
  для проверки серой ячейки округления. Нормализованный результат при этом
  не пересекает границы binade. Новые таблицы не нужны.
* `sin/cos` сразу используют существующий Q70 проход обычной ячейки.
* `ln` использует более тесную доказанную границу основной ветки. Около1
  прежние4КиБ хранят Q77 вместо Q70: известный старший байт reciprocal
  восстановлен из индекса. Все256 reciprocal и старые Q70 значения
  восстанавливаются точно, что отдельно проверено; `log10` сохраняет результаты.
  Четыре коротких точных деления дают RNE-остаток; куб исправляется двумя
  короткими знаковыми произведениями. При неопределённом округлении остаётся
  прежний fallback.

## Цена обычных входов

Перенос sin/cos сразу на Q70 и дополнительная точность ln замедляют часть
обычных входов относительно нашей прежней быстрой ветки. Все эти ухудшения
сохранены. По полной матрице относительно main: 3542 быстрее, 16278 равны,
1879 медленнее: sin336, cos374, tan675, ln494. Максимумы: sin+299 инструкций
(1.41831×), cos+300 (1.42076×), ln+110 (1.21360×), tan+9 (1.01191×).
Относительно квалифицированного scientific-round-03 родителя сохранена
отдельная полная карта; в ln максимум+111 (1.21596×).

Следующие средние используют одно и то же подмножество входов с правильным
Qfplib, единица — фактически выполненная Thumb-инструкция:

| `sin` / `reduced` | 123 | 818.6 | 1009.3 | 1342.3 |
| `cos` / `reduced` | 128 | 749.3 | 1012.7 | 1338.0 |

Цена выбрана ради устранения повторного вычисления редких серых ячеек;
на каждом ухудшившемся входе, для которого эталон правилен, итог остаётся
быстрее Qfplib. ARM instruction count не заменяет измерение аппаратных циклов RP2040.

## Проверки итогового ELF

* 220461 вызов десяти научных функций с направленными MPFR-интервалами — 0
  ошибок округления; sqrt/sin/cos/tan/atan/asin/acos/ln/log10/exp.
* 349657 вызовов арифметики, преобразований и целочисленных операций — 0
  ошибок; quiet NaN, ABI, стек и контексты делителя проверены.
* FMA: 73990 троек в READY/DIRTY/PENDING =221970 ARM-вызовов, 0 ошибок;
  независимый точный целочисленный oracle, 8030 сверок oracle с MPFR.
* Матрица: 21699 наших +21699 эталонных вызовов, наших ошибок0. Эталонные
  результаты и instruction counts побайтно совпали с исходным replay.
* Дополнительные43 научных случая ×3 контекста =129 вызовов — 0 ошибок.
  Все7 слов DIRTY/PENDING сохранены; READY по прежнему контракту scratch.
* У near77-03 родителя до объединения отдельно проверены9112 входов ln/log10
  на границах256 ячеек, рядом с прежними серыми входами и случайно:54672
  вызова в3 состояниях, 0 ошибок. После объединения полный научный корпус
  и43 контекстных случая выполнены заново на итоговом ELF.
* Рациональные сертификаты: exp<4 или<3 Q62, atan<12 Q70, основная ln<8 Q70,
  новая near-ln<5 Q77 (integer reject radius4), существующая sin/cos<12 Q70;
  все806 Q94 sin/cos строк перепроверены без записи таблиц.
* Генератор воспроизводит упакованную таблицу; `--check` ничего не записывает.

Каждый ARM-вызов проверяет R4–R11/SP и ограниченные записи в стек. ROM bit/memory
helpers выполняются из сохранённых16384 байт ROM v3, без intrinsic-подмен.
Рациональные оценки проверяют математические неравенства и предусловия;
это не машинное доказательство всего C++/компилятора. Конечные тесты не являются
доказательством правильности на всех binary64 входах. Семантика — RNE значения,
gradual underflow, signed zero и quiet NaN; errno/fenv исключения не реализованы.

## Размер и M4

Строгий standalone GNU text:450648→450876 байт (**+228**), data/BSS=0,
статическая RAM+0, объём таблиц+0. Максимальный стек: runtime176, FMA192,
матрица912 байт; это наблюдённые значения, не универсальная оценка стека.
Пять отключённых режимов genericM0/M4soft/M4hard сохранили выделяемые байты,
символы и смысловые релокации. Полная новая M4-прошивка этим не подменяется.
