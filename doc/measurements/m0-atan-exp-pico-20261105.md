# RP2040 atan/exp: аппаратный итог 2026-11-05

На PicoCalc/Pico H выполнены обе полные роли BASE и NEXT: по 48 групп и 10278
проверок с повторами. Ошибок нашей библиотеки 0. Ускорения ещё не закрывают
всё отставание: в NEXT остаются одна группа `atan` и четыре `exp`, в которых
медиана больше времени правильного ответа Qfplib.

Это аппаратная проверка изменений
[`0863702c5`](m0-atan-exp-host-20261105.md), уже находящихся в main.
Новых алгоритмов, таблиц или изменений M4 и `pow` этот отчёт не добавляет.
Проверки конечного набора не заменяют доказательства RNE на всех binary64.

## Результат на правильных ответах

Единица времени — микросекунда TIMERAWL на RP2040 при 125 МГц. Первичная
оценка — медиана шести средних соседних пар раундов с противоположным порядком
библиотек, после вычитания соответствующего контроля с тем же типизированным ABI.
Диапазон парных разностей является эмпирическим, а не доверительным интервалом.

| Показатель | BASE | NEXT |
|---|---:|---:|
| Завершённых групп / проверок с повторами |48 /10278|48 /10278|
| Ошибок нашей библиотеки |0|0|
| Групп с правильным эталоном для первичного сравнения |35|35|
| Медиан быстрее / медленнее Qfplib |23 /12|30 /5|
| Непервичных диагностических групп |13|13|
| Несовпадений Qfplib с MPFR, включая диагностику |500|500|

Из 16 пригодных групп `atan` NEXT быстрее в 15; из 19 групп `exp` — в 15.
Диагностика включает неправильные ответы Qfplib и выход за его документированную
область; эти результаты сохранены целиком и не входят в первичное сравнение.
`atan` сравнивается с настоящей Thumb-обёрткой `Qfplib atan2(x,1)`, включая её
время, а `exp` — непосредственно с `qfp_dexp`.

Для оставшегося `atan` диапазон шести парных разностей равен
+0,006348…+0,036133 мкс. Третья точка `exp` практически равна эталону:
разница медиан всего 0,002808 мкс; её положительная медиана всё равно сохранена.
Не утверждается ни строгий выигрыш на всех входах, ни статистическая значимость
каждой малой разницы. Связь этих четырёх `exp` с индексами старого аппаратного
CSV не восстанавливается по выдуманным битам: здесь опубликованы их текущие
точные входы, а в старом CSV входные биты отсутствовали.

## Регрессии относительно собственной BASE

Все 48 сравнений NEXT/BASE сохранены. В семи группах медиана увеличилась;
шесть из них пригодны для первичного сравнения с Qfplib.

| Индекс | Функция / поток | Увеличение NEXT/BASE |
|---|---|---:|
|4|atan / normal exponents, диагностика|+3,0279%|
|8|exp / small range|+0,0190%|
|11|atan / random ±1|+0,0370%|
|16|atan / random ±64|+0,0017%|
|19|atan / random ±64|+0,0083%|
|27|exp / random ±700|+0,1041%|
|35|exp / correction singleton|+0,0073%|

Самое большое относительное увеличение относится к диагностической группе
с быстрыми предельными ответами `atan`; проигрыш Qfplib на неправильном ответе
из этого не выводится. Малые увеличения не скрыты и требуют отдельного разбора,
но этот отчёт не объявляет их все доказанными систематическими регрессиями.

## Образы, воспроизводимость и проверки

BASE: `8A30D8F5 / DD90215C`; NEXT: `47513813 / 4BFD6A58`.
Оба диагностических BIN имеют 1578660 байт. Qfplib занимает 5796 байт
в `0x10180000..0x101816A4`, строго ниже отдельной области Spectrum.

Собственные Flash/RAM-адреса, математические тела и RAM-initializers каждой
роли сохранены из её production ELF. Независимый postlink добавляет эталон;
в исходном BIN разрешены только два 4-байтных image-extent literals и 40-байтный
integrity footer. Реальный ARM CRC-код принимает весь образ и отвергает
неверный extent и повреждённый эталон.

Использованы GNU Arm GCC 14.2.1, Pico SDK 2.2.0
`a1438dff1d38bd9c65dbd693f0e5db4b9ae91779`, Cortex-M0+, soft ABI, `-Os`.
Обе роли собраны из одного стабильного снимка платформы с тогдашними
незакоммиченными Spectrum-сервисами; это не чистые release-сборки данного
коммита. Между исходными снимками меняются только три ранее квалифицированных
runtime-файла: `native_eabi_m0.cpp`, `native_eabi_m0_atan_correct.inc`,
`native_eabi_m0_atan_fast.inc`. Полный снимок и образы сохранены локально;
публичная сводка фиксирует их хэши и метод сборки.

Статическая RAM обеих production-сборок 125004 байта, BIN1537056 байт;
GNU text NEXT меньше на 128 байт. Это дельта данной SDK-пары, не всего main.
Новых таблиц и RAM0. Изоляция M4 и точность изменённых формул проверены
в [HOST-отчёте](m0-atan-exp-host-20261105.md).

Фабричный Boot ROM v3 прочитан с платы. С ним реальные SDK lookup, ROM bit/memory
helpers и обе SDK math ELF выполнили по 10278 MPFR-проверок без моделей ROM
intrinsics и без ошибок. Максимальная наблюдаемая глубина стека 936 байт.
ARM-приложение проверено на правильный и намеренно неверный ответ, bounded
warmup и формат v5. Это HOST-проверки, отдельно от аппаратных микросекунд.

Одинаковое приложение, входной порядок и ожидаемые биты использованы в обеих
ролях:12 раундов, прогрев 1 с с пределом 32768 пар, XIP counters, interrupts enabled.
Исходный набор содержит 10261 проверку, ещё 17 — фокусные повторы; уникальных
пар «операция/вход»10259. Всего выполнено 8930882 математических вызова обеих
библиотек с учётом прогрева и 4660944 контрольных вызова. Число проверенных
ответов нашей библиотеки 20556; не каждый повторный timed-вызов сверялся с MPFR.
Все 96 строк происходят из шести полностью завершённых PASS-сегментов.

[hardware-groups.csv](m0-atan-exp-pico-20261105/hardware-groups.csv) содержит все 48
пар групп, [hardware-summary.json](m0-atan-exp-pico-20261105/hardware-summary.json)
— точные итоговые числа, пять проигрышей и семь ухудшений к BASE.
[hardware-records.jsonl.gz](m0-atan-exp-pico-20261105/hardware-records.jsonl.gz)
содержит 96 JSONL-записей с только математическими input/wire-v5 пакетами в base64.
Каждый пакет сохранён побайтно с SHA256. Поле `chunk` передаётся существующему
`tests/m0_sincos_timing.py:decode_v5` вместе с декодированными input/wire bytes:
это позволяет воспроизвести округление, первичные оценки и cache counters
без подключения платы. Данные Flash/ROM/settings/SHEET, serial transcripts,
локальные пути и служебные разрешения в публичный пакет не входят.

## Приёмка при передаче устройства из Math

Оставлена production NEXT `47513813 / 387E7B3A`, BIN1537056 байт,
SHA256 `b1c2d7587dafeb83f58e75a0b557ca0a23dce9d882a12395a086d05984941eef`.
Полный программируемый префикс сверен чтением; отдельные 8192 байта settings
и 77824 байта Spectrum ROM сохранены. Регистры, стек, программа, IP, cwd,
неактивные alarm metadata,14 SHEET-файлов и корневой список SD совпали.
Собственные три файла и пустой каталог удалены. Один setter вернул исходную
траекторию RTC по Mach continuous time, включая сон, с тем же host boot UUID
и timebase; readback в пределах 2 с, `RTC_SET=1`, `RTC_PPM=0`.

Первые postguards установок сохранили HOLD: у BASE в ответ попал отдельный
асинхронный KBD banner, у NEXT и final production первый холодный C5 ещё
сообщал `KBD=WAIT/PANEL_INIT=0`. Запись и readback к этому моменту завершились.
Позднейшие строгие fresh native/calculator проверки и CLOCK PASS составляют
отдельное подтверждение приёмки; исходные HOLD не переписаны в PASS.
Математические измерения из них не использованы. Старая прошивка автоматически
не восстанавливалась, полного исходного Flash backup не создавалось.
Все собственные порты закрыты, дочерние процессы завершены; устройство освобождено.

Active image заканчивается в `0x10177420`, erase extent — `0x10178000`.
Диагностические Qfplib bytes `0x10180000..0x101816A4` остаются вне активного
production image без production symbols и установленного TIMING.APP;
этот диапазон не объявлен стёртым. Spectrum ROM `0x101C0000..0x101D3000`
с резервом до `0x101E0000` и settings `0x101FE000..0x10200000` не затронуты.
Это историческое состояние при Math RELEASE, а не утверждение о текущем
владельце или прошивке общей платы после других аппаратных сеансов.
