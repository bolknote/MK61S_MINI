# Точное сравнение `pow` по 32-битным модулям

Прототип определяет знак целой разности шириной до **147 455 бит**.
Массив цифр занимает **18 432 байта**, таблицы констант —
**23 040 байт**. Предыдущая схема с тремя остатками гарантирует
88 415 бит при том же размере рабочих массивов.
[Предыдущая схема](m0-pow-mixed-residue-20261119.md).

## Доказательство

Пусть `N` ограждает двоичный логарифм меньшего из выровненных
целых операндов и `2^k` — знаменатель показателя. После
логарифмического сравнения с `g=16300` имеем
`abs(D) < 2^(N+1+k-g)` для их разности `D`.
Для ширины `W=N+2+k-g` требуется произведение модулей
больше `2^W`. При `W<=1` целая разность равна нулю.
[Вывод ограничения разности](m0-pow-mixed-residue-20261119.md#доказательство-знака-и-ограничения).

Генератор подбирает 4 608 попарно взаимно простых нечётных
модулей `m_i=B-c_i` с `B=2^32` и `0<c_i<2^16`.
Он проверяет каждую обратную величину по модулю `m_i` и
`sum(c_i)<B/2`. Поэтому произведение первых `n` модулей
строго больше `B^n/2`. По порядку модулей хранятся разности
соседних `c_i` по одному байту и обратные произведения
предыдущих модулей по четыре байта.
[Генератор и проверка таблиц](../../research/m0-pow-comparison-20261117/coprime_residue_table.py).

Вычисляем остаток `D` для очередного модуля и сразу получаем
новую цифру смешанной системы счисления. Из остатка вычитаем
значение уже полученных цифр по тому же модулю, затем
умножаем на обратное произведение предшествующих модулей.
Сравниваем цифры с цифрами `(P-1)/2`, где `P` — произведение
всех модулей. У `(P-1)/2` каждая цифра равна `(m_i-1)/2`.
Решение даёт старшая отличающаяся цифра. Нулевые цифры
означают точную ничью. Для отрицательного `y` знак
целой разности обращается, как в штатном компараторе.
[Метод Гарнера](https://bitsavers.computerhistory.org/pdf/afips/1959-03_%2315.pdf),
[прототип](../../research/m0-pow-comparison-20261117/coprime_residue.hpp).

При вычислении по модулю `m_i` предыдущий модуль `m_j`
заменяется на `c_i-c_j<2^16`. Поэтому каждый шаг схемы
Горнера даёт промежуточное целое меньше `2^48`.
Из `B≡c_i (mod m_i)` сворачиваем его старшее слово один
раз. После свёртки значение меньше `2*m_i`, поскольку
`B-1+(2^16-1)^2<2*(B-(2^16-1))`. Достаточно одного вычитания.

При предельной ширине выполняется не более **10 614 528**
шагов Горнера и **90 модульных произведений на модуль**,
отдельно от двух сведений входных коэффициентов. Последняя
граница использует `N+k<=163753`. Оба целых операнда
меньше `2^(N+1)`. Показатель каждой нетривиальной нечётной
степени и двоичный сдвиг имеют до 18 бит. При основании
коэффициента 1 возведение в степень пропускается.
Грубые оценки ширины дают 20 084 положительных и 17 995
отрицательных показателей, для которых проверка размера
достаточна при любых основании и середине. Это счёт
арифметики и охват по ширине.

## Проверки

На хосте проверены 2 030 модульных сведений, 2 005 коротких
произведений со сложением, 60 восстановлений знака, 644 границы
`pow` включая точные ничьи, и пять принудительных границ.
При ширине 147 456 бит компаратор возвращает отказ.

| Принудительный вход | Инструкции ARMv6-M |
| --- | ---: |
| 88 415 бит, положительный показатель | 136 855 520 |
| 88 416 бит, отрицательный показатель | 138 816 383 |
| 147 455 бит, положительный показатель | 368 277 377 |
| 147 455 бит, отрицательный показатель | 370 658 409 |
| 147 456 бит, отказ | 3 707 |

Максимальная наблюдавшаяся глубина записи относительно SP
составила 18 900 байт. Принудительные входы используют
ослабленный порог `g` с отдельно проверенным зазором.
Счётчик эмулятора измеряет инструкции этого компаратора.
Для верхней границы времени полного вызова ещё нужны
задержки памяти, время предыдущих ступеней и общая гарантия
перехода в ограниченный компаратор. Прототип существует
отдельно от штатной цепочки.

Перепроверка контрольной точки с новой шириной и существующей
интервальной оценкой `N` дала **0** целиком покрытых областей
из оставшихся **1 423 473**. Для дальнейшего охвата нужно
строго исключать близость к середине сразу на больших блоках,
где оценки ширины ещё превосходят 147 455 бит.
[Контрольная точка](m0-pow-mixed-coverage-20261119.md#повторный-проход-по-исходным-листьям).

python3 -B tests/m0_pow_coprime_residue_self_test.py \
