# Runner: первый проход ускорения

28.10.2026. Сравнивались исходный пакет из коммита `7a01beb48` и новая
калькуляторная программа на одном Classic V3 / UC1609, STM32F411 96 МГц,
public ID `AEB505B6E0067623`. В обоих случаях прошивка `770D2ADF`.
Новые команды и изменение ядра для этого прохода не требуются.

## Замер на Classic

Один и тот же `tests/hil_runner_classic.py` отправлял обычные события
USB Screen и считывал состояние. Регистры и код игры не подменялись.
Файлы каждой установленной версии прочитаны обратно и проверены.

| Действие | До | После |
| --- | ---: | ---: |
| Шаг вправо, медиана четырёх последовательных нажатий | 3,059 с | 1,146 с |
| Прожиг справа от начальной позиции | 4,138 с | 1,555 с |
| Восстановление прожига на видимом этаже, без движения | 38,246 с | 8,661 с |
| Три секунды удержания вправо, путь после отпускания | 2 клетки | 4 клетки |

Ходьба и прожиг ускорились примерно в 2,7 раза, ожидание восстановления —
в 4,4 раза. В обоих замерах на начало ожидания оставалось 18 кадров.
Время включает опрос регистров и одинаковый запас 150 мс на доставку
framebuffer; оно не привязано к различающимся маркерам кадров двух версий.
Четыре нажатия — один маршрут, не многократная статистика разных запусков.
Путь после отпускания включает завершение уже начатого шага.

Ускоренная версия прошла 23 аппаратные проверки: движение, удержание и
остановка, обе пары лестниц, все этажи, прожиг, падение, восстановление,
перезапуск, памятка с возвратом и выход. Журнал аварий пуст.
Кадры приняты с настоящего устройства. Новая игра установлена в `/games/Runner`.

## Что сокращено

- Покой сохраняет опубликованный экран. При активной дырке идёт таймер;
  перерисовка требуется при движении или восстановлении пола.
- RA/RC передают подписанный адрес обработчика плюс один. После ABS
  косвенный вызов через R0 использует его напрямую с предекрементом.
- RE хранит готовую базу записей этажа. Она меняется только при смене этажа
  и перезапуске; RF сохраняет адрес палитры.
- На каждую клетку есть запись из 28 байтов: переход к картинке, два
  перехода для прожига и короткая очистка с проверкой этажа. Допустимость
  прожига рассчитана сборщиком по карте лестниц. RB хранит адрес очистки;
  деление, поиск колонки и проверки лестниц во время прожига исключены.
- Только шлюз паузы исполняет шаг 111. Проверка раскладки подтверждает
  отсутствие других достижимых команд на этом шаге; RE=9999 больше не нужен.
- Нулевой код палитры обозначает пол, сокращая ввод чисел заготовок.
  Переходы используют существующую форму `1F`, `age_hole` встроен в цикл.

Игра по-прежнему исполняет калькуляторные команды. M61 загружает пакет,
принимает клавиши и делает паузу 120 мс. Рисунок и управление сохранены.
Цена таблиц: 2184 занятых байта вместо 1482 из 3584, BIN 911 вместо 711 байтов.
