# RP2040 sin/cos: bounded residual products (2026-11-04)

Status: the first complete BASE/NEXT Pico matrix, the targeted cache-fix rerun, and final working-image/files/clock acceptance passed. The physical cache regression was removed; zero owned rounding mismatches were observed. Instruction counts are not CPU cycles or measured microseconds.

The RP2040 checked Q70 table path now reuses owned bounded partial-product kernels. Qfplib's short residual correction and narrow limb products motivate the approach; its CORDIC implementation is not substituted for the checked result. The existing table, reduction and independent ambiguous-rounding refinement remain. No tables or static RAM are added. Cortex-M4, generic M0 and pow source paths are unchanged.

The ordinary-cell cube uses the existing six-MULS Q70 kernel (with an explicit endpoint shift), the even correction uses the Q54 kernel, and the odd correction uses the bounded Q62 kernel. The rational evaluation enclosure is less than 10.848 Q70 units, within the existing 12-unit guard; argument error remains separate. For residual magnitude below 2^32 Q70, one high32 coefficient product and a six-unit guard replace the nonlinear evaluation.

## Cache placement fix

The RP2040 XIP cache is two-way, 16 KiB, with eight-byte lines. Argument code, one coefficient row and the shared product occupied the same cache indices. A private, byte-identical 204-byte product entry at `0x10171c01` uses an unused part of the fixed sin/cos span. The original shared entry, its callers and the coefficient tables retain their addresses and bodies. BIN extent and static RAM are unchanged. [RP2040 datasheet](https://pip-assets.raspberrypi.com/categories/814-rp2040/documents/RP-008371-DS-1-rp2040-datasheet.pdf)

All 1,606 frozen cases were traced again through the actual fixed SDK ELF and captured ROM v3. Their results match MPFR; a repeated-call two-way LRU model reports zero steady misses for this corpus. That model excludes prefetch, interrupts and the other core, and is not a physical timing result.

The native relink moves generated inter-memory veneers. Mechanical normalization checks 108 math symbols: 79 are byte-identical and 29 have only 92 direct BL relocations to equivalent veneers in the same memory class with the same terminal addresses. Nonrelocation bytes, symbol addresses and sizes are unchanged. The 91 pow and 133 atan existing control cases have identical ARM results and instruction counts before and after this relink, with no MPFR mismatch. Whole-image or raw pow byte identity is not claimed. Another 742 sin/cos boundary calls match directed MPFR.

Fixed diagnostic: `37FBAC76 / 99097DFB`. Fixed production: `37FBAC76 / 7DB95A79`. The targeted rerun keeps the original APP and all 57 original input files, and selects 16 groups (1,060 cases), including the mandatory outlier, ordinary/reduced/wide/short residual groups, focused controls, and 36 new table-centre/outlier-neighbour inputs. This is a targeted follow-up, not another complete 57-group matrix.
