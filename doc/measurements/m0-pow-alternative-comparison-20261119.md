# Два способа точного сравнения для `pow`

Проверены сокращение общих множителей в целых степенях и
сравнение знака рационального приближения логарифмов по малым
модулям. Второй способ даёт универсальное точное сравнение с
фиксированной памятью и доказанной границей числа операций.
Эта граница остаётся слишком большой для требуемого времени
вызова на RP2040. Экспериментальные реализации работают на хосте.

## Сокращение общих множителей

При положительном $y=p/q$ можно поделить обе выровненные целые
степени на их общий нечётный делитель. Для каждой пары факторов
$a^p$ и $b^q$ с $g=\gcd(a,b)>1$ алгоритм заменяет основания на
$a/g$ и $b/g$ и оставляет $g^{|p-q|}$ только на нужной стороне.
Произведение хранимых оснований уменьшается хотя бы втрое за
каждое разбиение. Оно начинается ниже $2^{107}$, поэтому нужно
не больше 67 разбиений, без факторизации 54-битных чисел.
Когда интервалы ширины разделены, сравнение заканчивается до
построения целых. Остальные принятые случаи вычисляются точно
в пределах указанной ёмкости. При отрицательном показателе
нечётные факторы входят в один операнд.

Для `x=3feffffffc000000` и середины после `3feffffff8000000`
сама середина равна $x^2$. При двух показателях, соседних с 2,
верхняя оценка ширины падает с $1{,}22\cdot10^{17}$ и
$2{,}43\cdot10^{17}$ до **28 бит**. Знак определяется без
возведения в столь длинные степени. Для взаимно простых
нечётных частей `7fd0000000000001` и середины после
`7fe00000000007f5` при `y=3ff0040201008043` исходная оценка
остаётся $2{,}43\cdot10^{17}$, и прямая ветка возвращает отказ.

## Рациональная сумма с точным знаком

При нормализации основания и середины к виду $2^e(1-u/D)$
достаточно одной степени двойки $D\le2^{54}$. Для сравнения
середины со степенью берём подписанный числитель $p$ и
знаменатель $q$ показателя. Тогда

$$
q\,(y\ln x-\ln m)=\sum_{i=0}^2 c_i \sum_{j\ge1}\frac{(u_i/D)^j}{j},
\qquad 0\le u_i\le D/2.
$$

Одна из трёх сумм представляет $\ln 2$. После $n$ членов
погрешность меньше $2^{-n}\sum_i|c_i|$. При умножении на
положительное $D^n n!$ получается целочисленный интервал.
Числитель $R_j$ с текущим знаменателем $D^j j!$ вычисляется
по рекурсии

$$
R_j=jD R_{j-1}+(j-1)!\sum_i c_i u_i^j.
$$

Рекурсия применима по любому модулю, включая делители $j$.
Точные ничьи обрабатываются отдельно по двоичным масштабам и
нечётным частям. При положительном $y$ и нетривиальной ничьей
сокращённость $p/q$ заставляет нечётные части иметь вид $a^q$ и
$a^p$ при нечётном $a\ge3$. Поэтому $p\le34$ и $q\le32$, а
равенство проверяется тем же сокращением. Для отрицательного
$y$ обе нечётные части должны равняться единице.

Для целого конца интервала $R$ берётся префикс попарно взаимно
простых степеней простых из $\operatorname{lcm}(1,\ldots,L)$.
Их произведение $M$ строго больше $2|R|$. Центральный
биномиальный коэффициент делит это НОК, что даёт нижнюю оценку
на $M$. Двоичные оценки ширины модулей позволяют выбирать
префикс без материализации произведения. Верхняя оценка
$\log_2 M<2L$ следует суммированием по степеням двух
неравенства $\operatorname{lcm}(1,\ldots,2v)/\operatorname{lcm}(1,\ldots,v)\le\binom{2v}{v}$.

Дробная часть китайской суммы даёт $R/M$ по модулю единицы.
При первом блоке алгоритм либо определяет её половину, либо
сохраняет целое расстояние до единственной возможной границы.
При следующем блоке это расстояние умножается на основание
разряда и к нему прибавляются цифры слагаемых. Если сравнение
ещё неоднозначно, расстояние остаётся меньше числа модулей
по модулю. Вычисления держат фиксированное число целых до
128 бит. Записи модулей можно пересчитывать, а для эксперимента
на хосте можно кэшировать. Если остатки все нулевые, конец
интервала равен нулю. Иначе расстояние до границы половины не
меньше $1/(2M)$, что даёт конечный предел числа блоков.

## Граница работы и проверки

Существующая оценка Лорана даёт для ненулевого зазора
нижнюю границу $2^{-80840269429}$. С учётом
$\sum_i|c_i|/q<2^{74}$ достаточно **80 840 269 504 членов**.
Проверка целых ограждений даёт модули не выше $2^{44}$ и меньше
$2^{154}$ операций фиксированной ширины на оба конца интервала
при полном пересчёте. Это счёт арифметических операций.
Один проход ряда по одному модулю при одном такте на член
занял бы **647 секунд на 125 МГц**. Для этого алгоритма с
доказанным числом членов практической границы времени нет.
Меньший фактически достаточный ряд потребовал бы нового
общего доказательства разделения.
[Следствие 2 Лорана](https://www.impan.pl/shop/en/publication/transaction/download/product/82485),
[расчёт разделения](m0-pow-power-bounds-20261117.md#проверка-универсальной-границы-точности).

Тесты сверили 2 519 знаков со всеми знаковыми представителями
малого произведения модулей, 2 401 разложение с прямым НОД
больших степеней и 64 сравнения с точными дробями. Отдельно
девять сравнений совпали с направленным MPFR 4.2.2. В том числе
проверены оба знака при $q=2^{116}$, числитель в 63 бита,
граница переполнения и две точные ничьи. До 256 членов хватило
во всех девяти прямых вызовах. Их результаты характеризуют
компаратор, а достижимость при штатном зазоре $2^{-16300}$
остаётся открытой.
[Прототип](../../research/m0-pow-comparison-20261117/modular_log_compare.py).

```sh
tool=research/m0-pow-comparison-20261117/modular_log_compare.py
python3 -B -S "$tool"
python3 -B -S "$tool" --point 000fffffffffffff bbffffffffffffff 3ff0000000000000 --terms 256 --cache
python3 -B -S "$tool" --point 3feffffffc000000 4000000000000001 3feffffff8000000 --cancel 88415
python3 -B -S tests/m0_pow_modular_log_compare_self_test.py
```
