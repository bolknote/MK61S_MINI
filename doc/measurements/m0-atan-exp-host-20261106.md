# RP2040 atan/exp: сокращение поправок округления, 2026-11-06

Кандидат продолжает аппаратный [отчёт 2026-11-05](m0-atan-exp-pico-20261105.md):
один оставшийся случай `atan` и четыре `exp`. В этом отчёте приведены результаты
HOST-проверок ARM-кода. Новых физических замеров на Pico для кандидата пока нет;
пять ранее измеренных отставаний нельзя считать закрытыми по числу инструкций.

База: `fcf5db6e9c72ebabb334d865656bafdf992bc9b4`, GNU Arm GCC 14.2.1,
`-Os`, Cortex-M0+, soft ABI. Код M4 и алгоритм `pow` не изменены. RNE,
постепенное исчезновение порядка, знаковые нули и quiet NaN сохранены;
требования точности не ослаблены. Конечные тесты не являются доказательством
корректного округления на всех binary64.

## Изменения

* `atan_ratio_adjust` передаёт ограниченный знаковый остаток непосредственно
  в SIO SDIV вместо взятия модуля, UDIV и восстановления знака. Положительный
  знаменатель и граница остатка гарантируют тот же результат с усечением к нулю.
  Новый RP2040-only помощник сохраняет DIRTY/PENDING-контекст через обычный EABI
  путь и выдерживает четыре перехода / восемь тактов до чтения результата.
* `exp_round_decide` вычисляет только необходимые переносы и бит округления
  цепочкой Thumb-1 SBC/ADC. Сначала проверяет прежнюю равномерную границу ошибки.
  Для оставшейся узкой полосы достаточное неравенство
  `uint32_t(n*exp_step_low) < 0xAFF7FFFC` разрешает пропустить чтение Q94-строки.
  Условия `n <= 2^20`, чётность `exp_step_low` и расстояние дробной части
  таблицы не больше `2^31` делают этот пропуск эквивалентным прежней полной
  проверке. За пределами достаточного условия выполняется прежняя проверка.
  При неоднозначности сохраняется независимый точный refinement.

Идея узкой целочисленной поправки сопоставлена с Qfplib-M0-full. Код Qfplib
в runtime не копировался; прежние оценки погрешности и таблицы не менялись.
Эталон: upstream `ec814ad1f17934ac777f9e042efacfae5b15210d`,
SHA256 исходного ассемблера
`c9db54280a92c30e7c3b55adda24a8a540d33d52b7cba6185f9735c5efdd4654`.

## Инструкции на оставшихся точках

Это исполненные инструкции standalone ELF в Unicorn, с функциональной моделью
SIO. Они не учитывают физические такты, Flash cache, размещение SDK и veneer.
Для `atan` эталон включает настоящую Thumb-обёртку `qfp_datan2(x,1)`;
для `exp` используется `qfp_dexp`. Все ответы в этой таблице совпадают с MPFR.

`ef07d54bdd259c7858483606118a3c704976801823c38ac5a2fcdffacd2d83fe`.
В этом запуске исполнялись действительные ROM-подпрограммы CLZ и памяти,
вместе с SDK lookup-инициализаторами; SIO остаётся функциональной моделью.
Каждый ARM-вызов контролирует R4–R11, SP и допустимую область записи.

Новых таблиц и статической RAM нет. Суммарный размер выделяемых секций двух
изменённых RP2040-объектов вырос на 16 байт (C++ −20, ASM +36).

размер BIN остался 1537056 байт, static RAM — 125004 байта.
Неизменность тел pow в объектных файлах не означает побайтовую неизменность
его финальных адресов, relocations или cache-поведения.
