# Логарифмическое сравнение границы `pow` на RP2040

Если 8192-битное ограждение степеней пересекает середину `m` между
двумя соседними результатами, новая ступень определяет знак
`y*ln(x)-ln(m)` двумя логарифмами с 16 384 дробными битами.
`x` — модуль основания. Ступень возвращает сторону только когда
погрешность позволяет установить знак. При пересечении нуля
за логарифмами следует точное сравнение.
[Сравнение по остатку](m0-pow-residue-20261118.md)

## Ограждение и граница работы

Нормализованная мантисса сводится к единице множителями
`1-c*2^-i`. Сначала берутся одиночные множители с `c=1`, затем
восьмибитные `c`, отбрасывающие не меньше семи старших битов
остатка за шаг. Для малых `i` используются округлённые вниз табличные
логарифмы. Остальные слагаемые сгруппированы по общему делителю
в ряде логарифма. После редукции вклад остатка отличается от линейного
члена менее чем на одну единицу Q16384.

С учётом всех округлений и хвостов рядов абсолютная погрешность
каждого логарифма не превосходит **364 835 единиц Q16384**.
После умножения на точное `y` и вычитания логарифма середины
погрешность меньше `2^83` единиц. Отказ новой ступени возможен
только при `abs(y*ln(x)-ln(m)) < 2^-16300`.

На один логарифм допускается до 510 одиночных и 1 134 восьмибитных
множителей. В основных арифметических циклах для одного логарифма
сертификат ограничивает число обновлений 16-битных слов редукции
числом 1 683 456, число 32-битных делений числом 492 544,
число вставок одиночных слагаемых числом 44 850 и число разрядных
произведений для `c^n` числом 420 350.

## Доказанная область оснований около единицы

Для всех **100 663 297** положительных кодировок с
`abs(x-1)<=2^-27` и всех `abs(y)<=1/2` округление устанавливается
до потокового сравнения. Дальние середины исключаются оценкой
модуля логарифма. Для оставшихся независимых оснований теорема
о двух логарифмах даёт зазор больше `2^-15977`. Зависимые
ненулевые границы и точные ничьи покрывает предыдущая оценка,
включая точное сравнение на 8192 битах. [Теорема 2 Лорана, стр. 327](https://www.impan.pl/shop/en/publication/transaction/download/product/82485), [Предыдущие оценки](m0-pow-residual-domain-20261117.md)

Для всех binary64 практическая граница времени остаётся открытой.
Для этого требуется исключить ненулевой зазор меньше `2^-16300`
в оставшейся области или ограничить время точного сравнения там.

Последующий сертификат расширяет окрестность единицы до
`abs(x-1)<=2^-23` при `abs(y)<=16` и добавляет семейства около
степеней двойки. [Расширенные области](m0-pow-determinant-20261118.md)

## Проверки

- MPFR 4.2.2 с направленным округлением подтвердил 521 ограждение
  логарифма, 1 026 сравнений с ненулевым зазором и отказ на двух
  точных ничьих.
- На связанном ELF `22BF1BEC/5672DAB8` с заводской BootROM RP2040
  проверены пять прямых сравнений. В двух проверках цепочки
  имитирован отказ 8192-битной ступени. Обычный случай разрешился
  по логарифмам, ничья между нулём и минимальным субнормальным —
  в потоковой ступени. Максимальный наблюдавшийся расход стека
  на этих проверках — 15 508 байт.
- ARM-регрессия прошла 80 395 случаев `pow` и 80 196 случаев `exp`
  без расхождений с MPFR. Таблица размером 32 768 байт заняла
  свободный интервал Flash `0x10158000..0x1015ffff`, не добавив
  к длине образа байтов. `Scratch Y` занимает 4 096 байт.

## Верхняя граница числа инструкций компаратора

Один вызов 16 384-битного сравнения выполняет не более **169 182 485**
инструкций в проверенном связанном ELF. Граница включает два логарифма,
сравнение, SDK-делитель, очистку в BootROM и максимум 222 вызова
обслуживания watchdog. Для обслуживания взят штатный источник времени.
Допускается одно переполнение младшего слова за последовательность
чтений таймера. Время прерываний считается отдельно.
[Расчёт и хеши проверенных образов](../../dev/tools/certify_m0_pow_log_side_work.py).

В `absolute_log` внутренний цикл `0x1016b568` занимает 22 инструкции
на обновление слова. Один логарифм выполняет до 1 683 456 обновлений.
Деление включает до 492 544 проходов по словам и 963 вычислений длины
группы. Для каждого ненулевого делителя ветвь SDK
`0x100db768..0x100db7b0`, включая сохранение состояния, вместе с телом
вызывающего цикла ограничена 40 инструкциями. BootROM `MS` в `0x26b8`
очищает 16 байт за три инструкции повторяющейся части.

Для `add_power` число слов после $n$ умножений на цифру не больше
$\lceil n/2\rceil$. По возможным сдвигам фактора суммируются вызовы,
возведения, внутренние произведения и запись выходных слов. Для общей
суммы внутри группы перенос после первого шага равен единице. Каждый
промежуточный шаг поглощает слово `0xffff`. Такое слово может
возникнуть при прямой записи либо на последнем шаге переноса.
При $C$ вставках и $D$ прямых записях достаточно $3C+D$ шагов
переноса. В `accumulate` в сумме обходятся не более 1029 слов за
вызов, включая продолжение переноса. На слово приходится не более 16
инструкций. Верхняя граница работы вне двух логарифмов равна 118 377
инструкциям, каждый логарифм отдельно ограничен 84 532 054.

Граница относится к отдельному сравнению. Для времени полного `pow`
нужны границы других ступеней, такты команд с задержками памяти и
покрытие всех входов. [Таблица тактов Cortex-M0+](https://documentation-service.arm.com/static/60411750ee937942ba301773?token=).

```sh
python3 -B dev/tools/certify_m0_pow_log_side_work.py --elf "$elf" --bootrom "$bootrom"
```

## Замер на PicoCalc при 125 МГц

`POWLOG.APP` напрямую вызывало оба компаратора из SRAM.
Для каждой пары выполнено по одному вызову в фазе A–B–B–A.
A — ограждение степеней на 8192 битах, B — логарифмическое
сравнение на 16 384 битах. Ниже среднее двух вызовов каждой
ступени. Все стороны совпали с MPFR.

| `x`, `y` в битовом представлении | A, мс | B, мс |
| --- | ---: | ---: |
| `000fffffffffffff`, `bbffffffffffffff` | 2 388,143 | 1 662,951 |
| `3ff2345678abcdef`, `3fda123456789abc` | 1 350,672 | 1 927,469 |
| `3ff2345678abcdef`, `3fe0000000000000` | 0,313 | 1 923,471 |
| `3feffffffc000000`, `3fd1659e4b40566e` | 1 351,091 | 1 924,427 |
| `0000000000000003`, `3fefffeb074a771d` | 1 265,022 | 1 928,437 |

Первый вход имеет знаменатель показателя `2^116`. Логарифмический
компаратор на нём быстрее примерно на 30%, а в остальных четырёх
замерах быстрее степенное ограждение. Обе версии исполнялись
из SRAM на установленном образе `546F415E/F89D238E`.
Измерено время отдельного компаратора вместе с проверкой его
ответа в APP. Для изменения цепочки в образе `22BF1BEC/5672DAB8`
использовалась проверка связанного кода в ARM-эмуляторе.
APP и входные данные считаны обратно целиком. Временный каталог
удалён, CDC закрыт. Перезагрузок, сбросов watchdog, изменений
регистров калькулятора и записей настроек не было.
