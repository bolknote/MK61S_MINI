# Аппаратная прокрутка цветного чата МК-61

Цветной Renderer харнесса использует GRAM контроллера как кольцо для строк
22–271. Заголовок 0–21 и редактор 272–319 остаются неподвижными. Полного
цветного кадра в SRAM нет: сохраняется прежняя полоса INDEX4 320×8,
добавлена временная полоса индикатора прокрутки размером 250 байт на стеке.
Монохромный холст сохраняет свою page-major раскладку и точные пиксели.

Необязательные операции `MK61_COLOR_SCROLL_BEGIN` / `MK61_COLOR_SCROLL_END`
добавлены в конец существующего списка операций. Размер и формат прежнего
дескриптора кадра не изменены. Старый хост отвечает 0 на BEGIN, и Renderer
отправляет прежние 40 полос полного кадра.

BEGIN задаёт область, ожидаемое прежнее смещение и новое абсолютное
смещение. PRESENT передаёт полосы в обычных экранных координатах; драйвер
разрезает окна на границах кольца и переводит их в физические адреса GRAM.
END ждёт завершения полос и только затем публикует VSCRDEF/VSCSAD
(`0x33` / `0x37`) через ядро I/O. При ошибке полосы END возвращает 0,
Renderer полностью перерисовывает кадр при том же ожидающем смещении и
повторяет END. Отмена не публикует ожидающее смещение.

Ускорение включается для прокрутки неизменившегося содержимого. Изменение
истории, программы, результата, метрик или раскрытых разделов вызывает полную
отрисовку. Редактор и подсказка учитываются отдельно: их изменение не
запрещает сдвиг уже нарисованного тела. При выходе из графики и после сбоя
повторное использование изображения отменяется. Обычные цветные APP могут
продолжать писать в логических координатах; полный монохромный кадр возвращает
свою область и начало сканирования.

## Проверка на хосте

`picocalc_ai_color_scroll_self_test.cpp` моделирует физическую RGB565 GRAM,
независимое начало сканирования и отложенную передачу с копированием полосы.
145 результатов совпали с новым независимым полным рендером каждого кадра
по всем 102400 пикселям и по всем байтам монохромного холста. Проверены оба
направления, сдвиги не кратные восьми, переход через конец GRAM, границы
переписки, изменение редактора/содержимого, старый хост, частичная ошибка DMA,
отклонённая передача, плотная программа из 105 команд и выход/повторный вход.
При исчерпании списка команд рисования повторное использование отключается.
Целевая проверка также прошла
с ASan/UBSan. Общий `tests/run_picocalc_tests.sh` прошёл.

Пиксельные данные RGB565, подсчитанные принятыми PRESENT в тесте:

| Случай | Байты |
| --- | ---: |
| Полный кадр | 204800 |
| Сдвиг на 18 пикселей, неподвижный редактор | 12520 |
| Сдвиг на 1 пиксель, неподвижный редактор | 1640 |
| Неизменившийся кадр | 0 |
| Только изменение редактора/подсказки | 44800 |

Сдвиг на 18 пикселей уменьшает объём пиксельных данных в 16,36 раза;
в число включена перерисовка двух столбцов индикатора прокрутки. Команды
контроллера и задержки SPI не включены. Это проверка трафика и корректности
на хосте, а не аппаратный замер времени или проверка видимого tearing.

Код отрисовки помещён в существующий холодный Flash-слот AI. Адреса
фиксированных математических слотов не менялись. Алгоритмы инференса,
арифметика, веса и KV-кеш этой доработкой не изменяются.
