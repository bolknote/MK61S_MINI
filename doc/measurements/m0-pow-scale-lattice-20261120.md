# Блочный сертификат `pow` для всех двоичных масштабов

Один прямоугольник из **256×256 мантисс основания и середины**
закрыт для всех допустимых показателей binary64 обоих знаков и всех
двоичных масштабов. Для этих сравнений доказано
$\left|y\ln(|x|)-\ln m\right|\ge 2^{-16300}$, поэтому штатная логарифмическая
ступень выбирает сторону середины. Сертификат действует на
$A=\mathtt{0x18000000000000}\ldots\mathtt{0x180000000000ff}$ и на
256 нечётных $B$ от `0x28000000000001` до `0x280000000001ff`.
[Сертификат](../../research/m0-pow-comparison-20261117/midpoint-scale-lattice-control-w8.json.gz),
[проверяющий код](../../research/m0-pow-comparison-20261117/midpoint_scale_lattice.py).

## Исключение масштабов

Представим $|x|=2^e X$, $m=2^f M$ с $X=A/2^{52}$ и $M=B/2^{53}$.
Пусть $y=p/q$, $p$ знаковый и $q=2^k$. Для любого опасного
зазора существует целое $z=qf-pe$, для которого

$$
\big|p\log_2 X-q\log_2 M-z\big|<2^{k+1-16300}.
$$

Эта форма допускает произвольное целое $z$. Один сертификат
обрабатывает весь прямоугольник и целый диапазон $p$ без внешнего
цикла по $e,f$ или по парам мантисс. После выбора целых центров
координаты $A-A_c$, $(B-B_c)/2$, $p-p_c$ и $z-z_c$ целые.
Для вещественной поверхности последняя координата заменяется на
$z_*=p\log_2 X-q\log_2 M-z_c$. Она отличается от целой
координаты кандидата не больше чем на допустимый зазор.

Целочисленные линейные комбинации этих координат подставляются
в произведения биномиальных полиномов. Разложение по двум
мантиссам вычисляется направленной целой арифметикой. Степень
по $p$ конечна, эту координату проверка переводит в базис
Чебышёва без усечения. Для обоих комплексных радиусов
остаток проверяется по геометрическим суммам коэффициентов
Коши. Дополнительная погрешность от $z-z_*$ ограничена
производной биномиальных полиномов. Редукция решётки ищет
полиномы. Проверка либо получает интервал без целых, либо
исключает совместное выполнение интервалов по конечным классам
остатков. Для проверки редукция решётки не требуется.

План покрытия пересчитывает интервалы логарифмов на границах
прямоугольника и счётчики возможных показателей двумя суммами
целых частей. Из 127 активных бинад исключены 103. На каждой
оставшейся бинаде проверка требует покрытие всего диапазона
числителей отдельно для каждого знака. Пропуски и повторные
записи о бинадах дают ошибку. Случаи вне активной области
разрешаются правилами исходной цепочки.
[Границы активной области](m0-pow-binary64-proof-20261119.md).

## Размер проверенной области

Для стороны $2^8$ проверены 48 сертификатов шестой степени.
В 34 случаях достаточно одного интервала без целых, в пяти
применён модуль 2, в девяти модуль 11. Вместе они исключают
зазор для **65 536 пар мантисс**. Поиск шёл на Xeon 6740P.
Самая долгая из 48 задач генерации заняла 24,809 с. Отдельный
прогон на восьми процессах с точным умножением FLINT занял
89,830 с. Целые числа Python без FLINT на 47 процессах Xeon
дали `VERIFIED_RECTANGLE` за 62,400 с. SHA-256 архива
`326dd48ee5ad48e4f207750e4cfb0a22271a54ab2c7846d7b045d6e588d726d9`.

Прямоугольник со стороной $2^{12}$ проверен в окне из $2^{20}$
числителей одной бинады $|y|\in[2^{-12},2^{-11})$. Расширение
на всю бинаду этим сертификатом открыто. В основном прогоне из
165 конфигураций 17 дали сертификат, 120 оставили область
открытой, 28 дошли до предела времени. Дополнительные 50
конфигураций с повышенной точностью дали 15 сертификатов,
31 открытый случай и 4 таймаута. Поиск для контрольного
прямоугольника $2^{43}\times2^{43}$ оставил его открытым во всех
испытанных конфигурациях.

Линейный приём с постоянным целым множителем $D$ у $z_*$ и
вычитанием целозначного полинома по мантиссам имеет отдельное
ограничение. На фиксированных $A,p$ зависимость от $B$ равна
константе минус $Dq\log_2(B/2^{53})$. На широком контрольном
ряду для $q\ge2^{41}$ проверка конечными разностями исключает
интервал без целых для степеней полинома от 0 до $2^{38}-1$.
[Доказательство для логарифмического ряда](m0-pow-entire-surface-20261119.md#ограничение-для-линейной-зависимости-от-числителя).

При разбиении полной нормализованной сетки на блоки $2^8\times2^8$
потребовалось бы порядка $2^{89}$ блоков. Для доказательства
по всей области нужен способ, охватывающий гораздо большую
долю сетки за одну проверку. Практическая верхняя граница
времени `pow` на RP2040 для всех binary64 остаётся открытой.

```sh
src=research/m0-pow-comparison-20261117
python3 -B -S "$src/midpoint_scale_lattice.py" \
  --verify-cover "$src/midpoint-scale-lattice-control-w8.json.gz" --workers 8
```

Для точного умножения FLINT в проверке используется флаг
`--flint-products` в Python с установленным `python-flint`.
Журналы опытов сохранены на сервере в
`/home/user/m0-pow-all-scales-20261120.mB5hUU`.

Для поиска отдельного сертификата нужны `python-flint` и,
при передаче `--flatter`, соответствующий бинарный файл.
Аргументы блока задают включённые концы диапазонов $A,B$,
двоичный показатель знаменателя $k$ и включённые концы
знакового диапазона числителей $p$.

```sh
python3 -B "$src/midpoint_scale_lattice.py" \
  --block 0x18000000000000 0x180000000000ff 0x28000000000001 0x280000000001ff \
  64 0x10000000000000 0x1fffffffffffff --degree 6 --work-bits 256 --flatter /path/to/flatter
```
