# F401 APP pool and evictable inode cache, 2026-10-31

The combined Linux build at `e2150a38c27897f2a6a0ebd1f6610693c6779e67`
passed strict HOST checks but failed the original Classic V2 APP gate:
20,064 bytes available versus the unchanged 20,480-byte requirement.
A separate GNU 14.2.1 native build of owner checkpoint `0c234e3` reproduced it.

On F401 the 512-byte inode-table cache now borrows an evictable APP lease.
Its capacity remains 512 bytes. A loading, running, pinned **or idle loaded
APP** prevents acquisition; metadata reads then use NOR directly. A new APP
can reclaim the cache through the existing allocator callback. Failed cache
fills invalidate the previous line before I/O. The reader keeps its page
bounds and handles empty pages and inodes crossing 512-byte/4-KiB boundaries.
No public API, wire format, APP capacity or build option changes.

F401-only row packing and bit spreading replace the pixel loops for 5x8 row
conversion and 2x built-in glyph enlargement. The output pixels, dimensions
and buffer capacities remain the same. This provides Flash space for the
cache fallback. `write_byte` also delegates to the existing `write_bytes`,
matching the synchronous delegation already used by `SpiNorFlash::writeByte`.
The complete emulator core, Ms/BBS and graphics primitives are unchanged.
The three modified product files preprocess identically to the checkpoint in
all eight checked non-F401 shared/scoped/USB settings (24 file/configuration
comparisons).

Before placing a new F401 lifetime buffer, the allocator reclaims an APP
arena owned by the opportunistic read cache. Otherwise a later cache eviction
can leave an unusable 512-byte gap above script/graphics buffers. A cache
callback returning KEEP postpones placement; no partial buffer is published.
An actual `LOADABLE_MODULE` owner remains untouched by this rule.

| Native measurement | Classic V2 before | Classic V2 after | Classic V3 after |
|---|---:|---:|---:|
| BIN bytes | 257,996 | 257,988 | 258,028 |
| Free Flash; required 4,096 | 4,148 | 4,156 | 4,116 |
| Globals; contract limit 52,428 | 29,844 | 29,348 | 29,356 |
| Largest frame; limit 2,048 | 1,304 | 1,304 | 1,304 |
| Raw dynamic range | 25,192 | 25,688 | 25,672 |
| Effective APP pool; required 20,480 | 20,064 | 20,576 | 20,544 |

The effective pool still subtracts graphics 3,412, M61 runtime 1,472 and
placement slack 224 bytes, then aligns down to 32 bytes. The stack/guard top
remains `0x2000D700`. All original limits and reserves are retained.

The cache change has a cost. An independent before/after fixture measured
these NOR operations/bytes on both 512-KiB and 16-MiB simulated devices:

| Scenario | Previous fixed cache | Evictable cache |
|---|---:|---:|
| Cold inode lookup | 1 / 512 | 1 / 512 |
| 32 warm lookups without an APP | 0 / 0 | 0 / 0 |
| 32 lookups while an APP remains loaded | 0 / 0 | 32 / 832 |
| Two inodes crossing cache/page boundaries, after that warm sequence | 3 / 1,536 | 4 / 52 |

In particular, Explorer and USBDISK also lose metadata warm hits while
loaded. Lower transferred byte counts are not a speed measurement. F401
hardware latency for this tradeoff has not been measured.

Local checks passed with ASan/UBSan and Clang 18: complete C9 suites with
ordinary and shared temporary storage; cache eviction by the real APP
loader, live-APP preservation, I/O retry and boundary regressions; built-in
font suites for legacy/F401xC/F401xE, including all 16,384 width/height/row-mask
cases against an independent pixel oracle, canaries and unchanged source
rasters. The pinned APP/stage/MSC test begins with an empty APP arena; its
original sizes, 20 mutation cycles, heap check and exact final-capacity and
payload assertions remain intact.

The cold placement regression failed before the lifetime fix and passes
after it with a 25,672-byte dynamic range, M61 runtime 1,472, graphics 3,412
and a full 20,480-byte APP. It refills the cache between placements and checks
all three payloads. Separate allocator-protocol cases cover KEEP and an idle
evictable module lease. Both scoped variants are mandatory in `run_all_tests.sh`.
