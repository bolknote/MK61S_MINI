# F401 DCW fields, 2026-10-31

F401 extracts DCW from bits 15..16 of the microinstruction already loaded by each Tick. All 204 literal table values are checked at compile time; independently changing the first entry of any of the three tables causes the corresponding assertion to reject the build. DCWA, the hot-table interface, ROM values and public/context formats are retained. Removing only the declared qualification/proof code and three argument substitutions reproduces the previous source byte for byte, including Ms and BBS. F411 and actual Pico preprocessing retain their previous tokens.

The unchanged Classic V3 native build shrinks from 259016 to 258792 bytes, saving 224 bytes. With the separate Cyrillic index commit, BIN is 258696 bytes and free Flash 3448; the original 4096-byte reserve is still short by 648 bytes. Global RAM is 29844/52428 and the largest per-function frame is 1304/2048. This is a source checkpoint, not a qualified release.

ASAN/UBSAN pass for eight native configurations: legacy/shared execution, Flash/RAM hot tables, and old/field DCW decoding. Field decoding tests use PREDECODED 0, matching production. The existing native/F401-like/mini Runner campaigns pass. Eighteen valid F401 native/predecoded/packed/cache/merged combinations pass syntax checks, including PREDECODED 1, whose constant ROM branch remains unchanged.

The Cortex-M4 microtick probe compares 96 cases across PACKED 0/1, all-three/pair ticks, Flash/RAM tables, and 12 seeds covering every initial L-latch combination. All 896 context bytes match before and after. Instruction totals at PACKED 0 fall 2.84% for all-three ticks and 2.53% for pair ticks; PACKED 1 falls 1.95% and 1.49%. On the eight seeds shared with the earlier unshared e151 probe, cumulative differences are -0.12%/-1.78% at PACKED 0 and +0.50%/+0.44% at PACKED 1. These are instruction counts, not hardware cycles.

Local disassembly nesting falls from 52 to 44 bytes for PACKED 0 all-three ticks; pair ticks remain 28. PACKED 1 remains 68/48 bytes. The original unshared PACKED 0 all-three leaf used 24 bytes; the combined shared/field path therefore still adds 20 bytes locally. Balanced return SP and these local frames do not establish the complete runtime peak. No hardware was accessed.
