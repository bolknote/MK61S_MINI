# Разделение середин `pow` для общего нечётного корня

Для `x=d^u·2^s` и середины `m=d^v·2^t`, где `d` нечётное,
`3<=d<2^27` и `u,v>=0`, доказано следующее. При любом активном
показателе binary64 обоих знаков либо имеет место точная ничья,
либо `abs(y ln(x)-ln(m))>2^-266`. Ненулевой зазор достаточен
для штатного 512-битного интервала. Для точной ничьей применяется
целочисленная проверка с округлением к чётному.
[Ограждение `pow`](../../dev/tools/certify_m0_pow_interval.py),
[разбор точных ничьих](m0-pow-power-bounds-20261117.md).

## Конечная задача о цепной дроби

Пишем `y=p/q` в сокращённом виде, включая знак `p`. Тогда

```text
q( y ln(x) - ln(m) )/ln(2) = C log2(d) + J
C = p u - q v
J = p s - q t
```

В активной области `2^-64<=abs(y)<2^63` имеем `q<=2^116`
и `abs(p)<2^63`. Нечётные части содержат максимум 53 и 54 бита,
поэтому `u<=33`, `v<=34` и `abs(C)<2^122`. При `C=0` сравнение
сводится к целому `J`. Ненулевой зазор в этом случае больше
`2^-117`.

При `C!=0` один проход цепной дроби для каждого `d` исключает
все значения `C,J` сразу. MPFR ограждает `2^320 log2(d)` целыми
`L,U`. Разность `U-L` не превышает двух. Пусть `B=2^122-1`.
Алгоритм Евклида на дробной части `L/2^320` находит последний
сходящийся знаменатель `q_i<=B`, чей следующий `q_(i+1)>B`.
Целый остаток в этой точке равен минимальному расстоянию от
`C L` до кратного `2^320` при `1<=C<=B`.

Для доказательства соседние сходящиеся образуют целочисленный
базис, а их ошибки чередуются по знаку, пока не обращаются в ноль.
Любая пара
`(n,C)` с `0<C<q_(i+1)` в этом базисе либо кратна первой строке,
либо имеет ненулевые коэффициенты разных знаков. В обоих случаях
её абсолютная ошибка не меньше ошибки первой строки. Если дробь
оканчивается до превышения `B`, проверка получает нулевой остаток
и сообщает об открытом случае.

Из этого остатка вычитается `(U-L)B`. Минимум по всем `d`
равен `3402064321835540746749819051209513861000323323710605`
единиц Q320, больше `2^171`. Поэтому
`abs(C log2(d)+J)>2^-149`. Умножение на `ln(2)/q>2^-117`
даёт заявленное разделение. У штатной 512-битной ступени
проверена относительная ширина меньше `2^-433`. Логарифмический
диаметр её интервала меньше `2^-432`, включая восстановление
масштаба. Два конца поэтому округляются в одну кодировку для
ненулевого зазора в этой области.

## Покрытие и проверка

У нормальной середины `m>=2^-1022` нечётная часть имеет 54 бита.
Если обе нечётные части больше единицы и являются степенями
одного числа, степень середины строго больше степени основания.
В частности, степень не меньше двух и `d<2^27` автоматически.
Сюда входят все **19 712 361** различные пары нечётных частей
этого вида для нормальных середин, включая границу переполнения.
У каждой пары покрыты все допустимые двоичные масштабы и показатели.
Для субнормальной середины тот же вывод о размере `d` следует,
если хотя бы одна степень больше единицы. Сертификат также
принимает нулевую степень с одной стороны, когда оставшаяся
нечётная часть представима через допустимый `d`.

Для подсчёта нормальных пар записываем нечётную часть середины
как `b=d^v` с примитивным `d`, который сам не является степенью.
Имеется ровно `v-1` допустимых нечётных частей основания больше
единицы. Чтобы пересчитать их без факторизации `b`, для каждого
`k=2,...,34` считаем нечётные корни `a` с
`2^53<=a^k<2^54`. Вклад равен этому числу, умноженному на
`phi(k)`. Сумма по делителям восстанавливает `v-1`.

Два полных прогона MPFR 4.2.2 проверили **67 108 863** нечётных
корня. На 10 локальных потоках потребовалось 80,71 с, на 64
серверных — 16,73 с. Отчёты совпали побайтно. Минимум дал
`d=60178921` со сходящимся знаменателем
`1183367959682454080769663893716456795`. Этот минимум отдельно
перепроверен рациональным рядом для логарифма и двумя евклидовыми
суммами целых частей, без поиска сходящихся знаменателей.
SHA-256 вывода полных проходов
`ffcfc3be53e29c66ac00b048de880f1e34d4a8e59d6bf5ebeff5f408454c0c33`.
[Отчёт](../../research/m0-pow-comparison-20261117/common-odd-root-20261119.json).

```sh
src=research/m0-pow-comparison-20261117
c++ -O3 -std=c++17 -pthread "$src/certify_common_odd_root.cpp" \
    $(pkg-config --cflags --libs mpfr gmpxx) -o /tmp/certify-common-odd-root
/tmp/certify-common-odd-root 10
python3 -B -S "$src/check_common_odd_root.py"
```

## Связь с общей диофантовой оценкой

В общем случае требуется разделить `p/q` и
`xi=ln(m)/ln(abs(x))`. Например, равномерная оценка
`abs(xi-p/q)>=2^-15783/q^4` уже дала бы нужный зазор
строго больше `2^-16300`, поскольку `q<=2^116` и
`abs(ln(abs(x)))>2^-53` для положительного модуля вне единицы.

Теорема об иррациональности отношения двух логарифмов из §11
препринта Чудновского оставляет константу зависимой от оснований
и без такого численного порога. Более того, для одной пары
оснований среди знаменателей до `2^116` может быть лишь один
сокращённый показатель в полосе `abs(xi-p/q)<2^-16247`.
Расстояние между двумя различными дробями там не меньше
`2^-232`. Аргумент через неограниченную последовательность
хороших приближений сам по себе не проверяет это одиночное
приближение. Для независимых нечётных частей общий сертификат
с требуемой границей и практическое время RP2040 пока не получены.
[Теорема 11.1 и следствие 11.5](https://arxiv.org/html/2610.28079v1#S11).
