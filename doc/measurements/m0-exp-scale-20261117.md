# RP2040 exp compact scale lookup, 2026-11-17

The RP2040 fast path now reads two aligned words per scale lookup. The
existing Q94 table supplies the seven discarded fractional bits only if
the first interval reaches a rounding midpoint. The rational bounds are
below 95 Q69 units with the two-word lookup and below 31 after the
fractional bits are restored. The initial midpoint guard also ensures
that restoring those bits keeps the high mantissa and normalization
fixed. The 16-bit partial products for argument reduction and the residual
square return the same integer values as the previous full products.

The 512-row Q62 table takes 4,096 Flash bytes in its own section at
`0x10195f00`. Both measured images had 119,896 bytes of static RAM and a
1,805,072-byte Flash image. The selected version uses the top two words
directly. The first candidate packed two fractional bits into those words.
Removing that unpacking cut a further 19.45 and 19.57 ARM instructions
per call on the two wide groups. [Rational certificate](../../dev/tools/certify_m0_exp_center.py)

The Pico H ran at 125 MHz. Each series used 12 rounds with alternating
order and subtracted the calibrated empty-call batches. The estimator is
the median of six means from opposite orders. The final build reached
the 5.50 µs target on both wide groups. Its XIP misses per call were 0.488
and 0.373. The 13 previously slow individual inputs took 4.953–5.246 µs.
All six paired differences in every one of the 27 groups favored the
project over factory ROM. All 2,510 values in the 27 groups matched directed MPFR
4.2.2. The ARM ELF qualification separately agreed with MPFR on
200,196 `exp` calls. A separate ARM regression verifies that three
midpoint inputs read exactly one Q94 word and an ordinary input reads
none. [ARM regression](../../tests/m0_rounding_decisions_arm_self_test.py),
[Complete measurements](m0-exp-scale-20261117.csv),
[Earlier main](m0-math-20261116.md#pico-h-at-125-mhz)

## Replay on the combined math image

The installed Pico H image `3FA1B158 / B541AD9A` includes the final
`pow` implementation. Its earlier full Flash readback matched the
production BIN. The replay matched the native CRC, build ID and boot
counter before and after the test. It ran from SD at 125 MHz using the
same inputs, calibrated batches, 12 alternating rounds and factory ROM
v3 reference. [Combined math image](m0-pow-final-20261117.md#picocalc-at-125-mhz)
