# F401 shared microtick prefix, 2026-10-31

The F401-only merged executor shares the 1302/1303 prefix of ordinary and native-shortcut ticks. AMK lanes are selected before either chip changes L, and chip order stays 1302, 1303, 1306. F411 and actual Pico preprocessing preserve their previous token stream. The Ms exchange and all code outside the Tick block are unchanged.

Classic V3 native BIN shrinks from 261224 to 259464 bytes at unchanged build flags. It has 2680 bytes free; the required 4096-byte reserve is still short by 1416 bytes. This checkpoint is not a qualified release. Global RAM is 29860/52428 and the largest per-function frame is 1304/2048 bytes.

The 64 Cortex-M4 emulation cases preserve all 896 context bytes, across PACKED 0/1, all-three/pair ticks, Flash/RAM tables and eight seeds. At PACKED 0 the instruction totals grow 626526 → 642813 (all-three, +2.60%) and 473311 → 475999 (pair, +0.57%); at PACKED 1 they grow 767863 → 786135 (+2.38%) and 611247 → 622399 (+1.82%). This is instruction counting, not measured hardware latency.

Independent disassembly review found a local nested stack increase for all-three ticks: PACKED 0 changes 24 → 52 bytes (+28), PACKED 1 changes 56 → 68 (+12). Pair ticks stay 28 and 48 bytes respectively through tail branches. Balanced return SP does not establish the complete runtime peak.

ASAN/UBSAN native equivalence runs cover legacy/shared paths with both Flash and RAM hot tables. Each configuration checks 786432 body cases, 1216 steps and 1996923 display frames. Runner tests include an explicit F401-like profile (native 1, packed 0, predecoded 0, 64-byte read cache) alongside native and mini full campaigns. Final strict tests, all F401 package/APP gates and the separate legacy Arduino configuration remain outstanding. No device was accessed.
