# Проверка `pow` для оснований $2^s$ и малых показателей

Пусть $x=2^s$, где $-1074\le s\le1023$, и $m$ — середина
округления. Для $|y|=p/2^k$ разность логарифмов равна

$$
y\ln x-\ln m=\ln 2\,(s y-\log_2 m), \qquad s y\in 2^{-k}\mathbb Z.
$$

Эта формула заменяет отдельные проверки 2 098 оснований одной
проверкой сетки середин. Отрицательные показатели входят в ту же
сетку. Середины меньше единицы можно умножить на два, поскольку
это прибавляет целое число к их двоичному логарифму.

## Покрытие

При $65\le k\le89$ и зазоре не больше $2^{-900}$ имеем

$$
|\ln m| \le u_k=\frac{1074(2^{53}-1)}{2^k}\ln 2+2^{-900}<\tfrac12.
$$

Снизу это даёт $1-m\le u_k$, сверху $m-1\le u_k/(1-u_k)$.
Проверка вычисляет целые границы для индексов $j$ в
`m=1−(2j+1)/2^54` и `m=1+(2j+1)/2^53`. Для каждого интервала
индексов она использует самый большой допустимый $k$. Все сетки
меньших знаменателей входят в соответствующую сетку $2^{-k}$.
Полная перепроверка требует каждый интервал от вычисленного
начала до конца без пропусков и повторов.

В каждом блоке цель имеет вид $F(j)=2^k\log_2(m)$. Из неё
вычитается целая аффинная функция, затем к двум целым
координатам применяется обратимая целочисленная замена. Поиск
использует FLINT, чтобы предложить целочисленные комбинации
биномиальных полиномов. Проверяющая программа пересчитывает
Taylor-коэффициенты целыми направленными интервалами и ограничивает
хвост по оценке Коши. Она отдельно учитывает сдвиг до целой
координаты, который из исходного зазора строго меньше
$2^{k+1-900}$. Если интервал полинома не содержит целого, блок
исключён. Иначе полиномы с единственным целым значением сводятся
к нулю и проверяются на отсутствие общей точки по модулю два.
[Генератор и проверка](../../research/m0-pow-comparison-20261117/power_two_midpoints.py).

## Произвольные основания

Проба с переменными основанием и серединой использовала два места
в бинадах основания $2^{1022}$ и середины $2^{1023}$.
На стороне $2^{22}$ проверка приняла один из двух блоков. На
сторонах $2^{24},2^{26},2^{28},2^{30},2^{32}$ поиск не выдал
сертификаты в этих местах при степенях от 6 до 9. Если бы
принимались все блоки со стороной $2^{22}$, полное разбиение
только одной пары бинад содержало бы $2^{60}$ блоков.
Для всех оснований остаётся исключить ненулевой зазор меньше
$2^{-16300}$ в случаях, где расчётная ширина остатка больше
88 415 бит. Общий контрпример и верхняя граница времени на
RP2040 пока не получены.
[Проверка общего условия](m0-pow-mixed-coverage-20261119.md).

## Воспроизведение

```sh
tool=research/m0-pow-comparison-20261117/power_two_midpoints.py
python_with_flint -B "$tool" generate "$run_dir/k70.jsonl.gz" \
    --from-shift 70 --width 25 --workers 128
python3 -B -S "$tool" verify "$run_dir/k70.jsonl.gz" --workers 128
python3 -B -S tests/m0_pow_power_two_midpoints_self_test.py
```

Ключ `--to-shift` позволяет проверять слои отдельными файлами.
Для $54\le k\le64$ имеем $|sy|<537$, так что при малом зазоре
результат находится в нормальном диапазоне. В слое 64 план
добавляет середины с нормализованной мантиссой ниже
$\sqrt2$. Для оставшихся нормализованных мантисс применима
опубликованная проверка $2^t$ на сетке $2^{-64}$ в $[1/2,1)$.
Полный проход слоёв 64–69 ещё предстоит. Его план при ширине блока $2^{25}$
содержит 102 091 161 начальный блок.
[Проверка расширенной точности INRIA, §6.2](https://rex-radar.inria.fr/rapportsactivite/RA2005/spaces/spaces.pdf).
