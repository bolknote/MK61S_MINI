# Проверка зазора `pow` на широкой целочисленной сетке

Проверяется строгое неравенство $|y\ln x-\ln m|>2^{-16300}$,
где $m$ представляет середину округления к ближайшему. Этот
порог пригоден для текущей логарифмической ступени и для
уточнения квадратными корнями на 16 384 битах. Общее доказательство
для всех binary64 и практическая граница времени RP2040 открыты.
[Логарифмическая ступень](m0-pow-log-side-20261118.md),
[уточнение квадратными корнями](m0-pow-radical-comparison-20261119.md).

## Проход для одного слоя показателей

Для $2^{-63}\le |y|<2^{-62}$ пишем $|y|=p/2^{115}$,
$2^{52}\le p<2^{53}$. Из $|\ln x|\le 1074\ln2$ следуют только
две возможные середины в полосе $2^{-16300}$, $1-2^{-54}$
и $1+2^{-53}$. Следующие середины с каждой стороны от единицы
лежат как минимум на логарифмическом расстоянии
$3\cdot2^{-54}$ и $3/(2^{53}+3)$ соответственно. Знак $y$
задаётся знаками $\ln x$ и $\ln m$. Проверяющая программа
пересчитывает эти неравенства, перебирает все поля показателя
основания и исключает начальные и конечные отрезки по
монотонности $|\ln x|$.

Для фиксированной середины и блока оснований неизвестные
целые координаты — смещение $I$ от центра и числитель $p$.
Проекция имеет вид $F=2^{115}|\ln m|/|\ln x|$. Редукция
решётки ранга два поворачивает целые координаты вдоль касательной
к $F$. Многочлены в базисе $\binom{L_1}{i}\binom{L_2}{j}$
целочисленны в каждой точке новой решётки. Проверяющий код
пересчитывает коэффициенты ряда с направленным округлением,
расстояние от полосы до графика и остаток по оценке Коши.
Интервал многочлена либо не содержит целого, либо заставляет
его обратиться в ноль. Во втором случае проверяются общие
корни по модулю 2 или одного из малых нечётных простых. Если
поиск не закрыл блок, он делится. В мелком блоке возможные
целые $p$ исключаются прямыми направленными интервалами.

План слоя содержит 1 362 пары «бинада основания, середина»
после аналитического отсечения. При ширине $2^{38}$ в нём
21 435 788 корневых блоков, при $2^{42}$ — 1 339 778.
Поиск проверен на Intel Xeon 6740P через FLINT 0.9.0 и
fpylll 0.6.4. Отдельный проверяющий код работает на целых
числах без fpylll. Ранг и время редукции быстро растут
при увеличении ширины блока.

бинадах число делений блоков и цена генерации могут отличаться.

## Переменная середина

Двумерная проверка использует независимые радиусы комплексных
дисков $R_x,R_m$ и прямоугольное усечение ряда. Если мономиал
ограничен на бидиске числом $C$, вклад коэффициентов за пределами
прямоугольника не превосходит
$4C(R_x^{-n_x}+R_m^{-n_m})$. Проверка заново считает
этот остаток и сдвиг от полосы. Старые сертификаты с усечением
по суммарной степени также воспроизводятся.

Серверная проба принимала отдельные прямоугольники в
`[3,3.25) × [5,5.5)` при `1 <= abs(y) < 2`. Для ширин
$2^{20}\times2^{20}$ найден и независимо подтверждён один
сертификат на 1 099 511 627 776 пар «основание, середина».
Более крупные варианты дошли до отказа или лимита поиска.
Разбиение всего этого контрольного прямоугольника на
подтверждённые размеры потребовало бы $2^{58}$ блоков.
Поиск принятого прямоугольника занял 12,99 CPU-с, повторная
проверка 0,46 CPU-с. При такой цене и 140 ядрах на неделю
даже для одного контрольного прямоугольника понадобилась бы
ширина не меньше $2^{38}$ по обеим осям. Это расчёт для
испытанной схемы разбиения.
[Метод поиска точек у графика](https://perso.ens-lyon.fr/damien.stehle/downloads/randombits.pdf),
[предыдущая двумерная проверка](m0-pow-surface-20261119.md).

## Воспроизведение

```sh
src=research/m0-pow-comparison-20261117
python3 -B -S "$src/midpoint_band_layer.py" plan --width 38
python3 -B "$src/midpoint_band_layer.py" generate below.jsonl.gz \
    --width 38 --first 0 --stop 12028 --workers 104 --flint-products
python3 -B "$src/midpoint_band_layer.py" verify below.jsonl.gz \
    --width 38 --first 0 --stop 12028 --workers 104 --flint-products
python3 -B "$src/midpoint_band_layer.py" generate above.jsonl.gz \
    --width 38 --first 16755108 --stop 16759465 --workers 104 --flint-products
python3 -B "$src/midpoint_band_layer.py" verify above.jsonl.gz \
    --width 38 --first 16755108 --stop 16759465 --workers 104 --flint-products
python3 -B "$src/midpoint_band_layer.py" verify-bundle below.jsonl.gz above.jsonl.gz \
    --width 38 --binade -739 --workers 104 --flint-products
python3 -B -S tests/m0_pow_band_layer_self_test.py
python3 -B -S tests/m0_pow_surface_proof_self_test.py
```

`VERIFIED_RANGE` подтверждает только диапазон в заголовке файла.
`VERIFIED_BINADES` сверяет объединение файлов с обоими списками
середин для каждой явно выбранной бинады основания.
`VERIFIED_Q115` требует перепроверки всего плана без пропусков и
открытых листьев. Наличие открытого листа даёт `INCOMPLETE`.
