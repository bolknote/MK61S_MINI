# Runner: физический прогон Window4

Состояние: **кампания не завершена; возврат Classic прошёл проверку**.
Дата — 31 октября 2026 года по Москве. Прошивка `28FBFF7A`, неизменённые
восемь файлов игры, обычные события клавиш USB Screen; регистры и позиции
для прохождения не подменялись.

Первый уровень пройден целиком с движущимся охранником. Замеры второго:

| Проверка | Физический результат | Порог |
| --- | --- | --- |
| Медиана шага | 0,701985 с | ≤0,75 с |
| Максимум шага | 0,786406 с | Сохраняется отдельно |
| Удержание | 4 клетки за 3,004 с | ≥4 за 3 с |
| Видимое восстановление пола | 4,704462 с | ≤5 с |

На третьем действии маршрута L2 клиент зафиксировал поражение. Этот **FAIL
сохранён**; L3, финальная победа/повтор и длинный Cx не достигнуты.

Разбор сохранённых RX/TX установил причину. После первого шага L2 регистры
уже показывали готовое состояние: герой18, враги1/34, R3=1. Соответствующий
кадр пришёл через 3,24 мс. Вместо ожидания кадра клиент снова запросил
регистры. Ответы захватили ещё два хода врагов; подтверждение первого шага
задержалось на 1,480524 с, враги оказались14/32. Далее герой пришёл в19,
враг с31 вошёл в19; DOWN/UP прожига отправлены уже после R4=-1. Это ошибка
временной модели теста, а не пропавшее нажатие прожига.

Клиент теперь до150 мс принимает кадр для уже готового снимка без нового
блокирующего запроса. Предикат позиции, R3=1 и полное совпадение масок
остались обязательными. Отсутствующий кадр не считается успехом; свежий
снимок поражения запрещает отправку действия. Маршруты, пороги и игра
не изменились.

Целевой HOST-контроль воспроизводит старое ожидание на сохранённых данных:
5 запросов, возврат на84,977376 с, враги14/32. Исправленный клиент делает
2 запроса и возвращает на83,496852 с, враги1/34. На существующем исполнителе
настоящего ПЗУ проверены только соответствующие три действия L2: с двумя
лишними ходами получено то же поражение; без них — герой19, прожиг20,
враги14/32. Новых сборок не было. **Это HOST-контроль, а не физический PASS**.

После единственного прогона Classic возвращён: 32 файла/137771 байт
сверены в трёх аудитах, strictzero105/регистры/стек/IP0/cwd восстановлены,
boot9→10 через один предусмотренный `rst now`, CRC valid, crash none.
RTC unset, будильники выключены; максимальная ошибка концов локального
интервала0,087964 с при неизменном пределе0,5 с. Все процессы и дескрипторы
закрыты; координатор независимо принял возврат. Исторические FAIL не менялись.

Источник физической трассы: SHA256
`a44b2fbc9a9a17824cbe8008df30d9a820c4a8c009179049911bdfd4f4ccfa65`.
Для завершения нужен новый аппаратный прогон полного маршрута L1→L2→L3,
замеров L2/L3, победы/повтора и длинного Cx с исправленным клиентом.
