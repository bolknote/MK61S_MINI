# RP2040 nonpow: проверенные изменения и аппаратный итог

Изменения двенадцати файлов математики побайтно совпадают с кандидатом NEXT,
испытанным на Pico H. В отдельной ветке от main
`37ea649377b717f47e06c80234be5fd56a27377c` все53 математических файла совпали
с испытанным SDK source. Прямые исходники `pow` и целевые настройки M4
не изменены. Нового алгоритма `pow` и нового аппаратного прогона здесь нет.

Это подготовка проверенного улучшения, а не заявление об устранении всего
отставания. На реальном RP2040 остаются37 медианных проигрышей корректному
эталону, несмотря на отсутствие проигрышей в прежнем HOST instruction replay.

## Что изменилось

- Короткие точные ветки преобразований целых и double→uint32; точное сложение
  разных знаков при разнице порядков2..54 с сохранением IEEE fallback.
- `exp` и `atan` используют уже вычисленные остатки для решения трудных ячеек
  округления. Неопределённый интервал сохраняет независимое уточнение.
- `sin/cos` сразу проходят существующий Q70 kernel. Для `ln` около1 прежняя
  таблица4КиБ упакована с Q77 логарифмами и точно восстанавливаемым reciprocal;
  сохранены старые Q70 значения для `log10` и отключённых RP2040 режимов.

На полной сопоставимой SDK-паре от `eaaff37349149f86ebe7c25275a09da3f6ae906d`:
GNU text+224Б, BIN+48Б, статическая RAM+0, новых таблиц0. Это измеренные дельты
той SDK-пары; полный образ актуального объединённого main здесь не пересобирался.

## Аппаратные результаты

Единица времени — микросекунда TIMERAWL. Это не такты и не число инструкций.
BASE и NEXT запускались отдельно. Каждая группа сохраняет результаты обеих
библиотек, парные контрольные измерения и эмпирический диапазон разности;
этот диапазон не является доверительным интервалом.

| Показатель | BASE | NEXT |
|---|---:|---:|
| Пакетов / проверок с фокусными повторами |505 /22065|505 /22065|
| Ошибок нашей библиотеки |0|0|
| Расхождений Qfplib/явных композиций с точным ответом |1827|1827|
| Групп для основного сравнения правильных ответов |463|464|
| Медиан быстрее / медленнее Qfplib |143 /320|427 /37|
| Групп с диапазоном разности через ноль |10|4|

Исходная матрица содержит21699 входов;366 дополнительных фокусных проверок
не следует выдавать за новые уникальные значения. В NEXT выполнено50318716
публичных вызовов обеих библиотек и23301912 контрольных вызовов.41 группа
с неверными ответами эталона сохранена как диагностическая. `asin`, `acos`
и `log10` сравниваются с явно отмеченными композициями Qfplib. Прямого
сравнения FMA с Qfplib нет; его точная HOST-проверка описана отдельно.

| Остаточное отставание NEXT | Медиан медленнее / пригодных групп |
|---|---:|
|sin|17 /34|
|cos|14 /26|
|exp|4 /7|
|atan|2 /4|

Неопределённая разница:46 (`f2d`),169/171 (`exp`) и307 (`dsub`). Две из этих
групп `exp` входят в37 медианных проигрышей;46/307 имеют более быструю медиану.
В остальных пригодных группах медианы быстрее Qfplib на этом наборе входов.

BASE144 исключена из основного сравнения времени из-за физического нажатия
SHIFT; её данные и причина сохранены. Для неё NEXT/BASE остаётся пустым,
а не вычисляется из исключённого времени. NEXT144 измерена отдельно без
такого нарушения. Всего78 медиан NEXT ухудшились относительно собственной BASE;
эта карта целиком сохранена, включая диагностические результаты.

Характерные ухудшения: reduced sin/cos313..318 примерно+39,4–40,4% к BASE;
ln336..342 примерно+24,3–25,4%. Диагностический tan333:
73,05005→150,12830мкс (+105,51%); Qfplib15,36768мкс даёт неверный результат.
Такие случаи не удалены ради благоприятного итогового числа.

477 результатов NEXT происходят из обычных закрытых PASS-сегментов,28
(004..031) — из явно принятого завершённого префикса сохранённого HOLD.
Сам HOLD не переименован в PASS. Нарушение срока входа раннего original-C5
на25,92974с также оставлено FAIL; последующие clock/verify получили новые
отдельные своевременные разрешения. Эти исключения не скрыты в отчёте.

Все505 строк и хэши сырых математических отчётов опубликованы в
[hardware-groups.csv](m0-nonpow-20261031/hardware-groups.csv).
[hardware-summary.json](m0-nonpow-20261031/hardware-summary.json) содержит
полные списки37 проигрышей,4 неопределённых групп,78 ухудшений и разбивку
по операциям. Приватные копии Flash, SD и исходных данных в Git не включены;
локальные аппаратные пакеты и резервные копии сохранены.

## Точность и проверки

Для неизменённых итоговых исходников ранее выполнены:220461 научный ARM-вызов
с направленными MPFR-интервалами;349657 runtime-вызовов;73990 FMA-троек
в трёх состояниях делителя (221970 вызовов),8030 независимых сверок oracle
с MPFR;129 дополнительных научных контекстных вызовов. Ошибок0. Все эти
длительные наборы повторно ради коммита не запускались.

В новой отдельной ветке заново проверены53 исходных файла, синтаксис10
Python-файлов, целочисленный FMA oracle, генератор таблицы и три рациональных
сертификата. Повторная компиляция runtime RP2040 и пяти контрольных режимов
genericM0/M4soft/M4hard дала побайтно те же квалифицированные объекты.
Новая полная M4-прошивка этим не объявляется.

Численные пределы: near-ln<5 Q77, exp<4 либо<3 Q62, исправленный atan<12 Q70,
основная ln<8 Q70, существующий sin/cos<12 Q70. Таблица содержит256 near-ln
ячеек; проверены все806 строк Q94 trig и512 строк Q94 exp. Сертификаты
доказывают заявленные рациональные неравенства и ширины, а не всю реализацию
C++/компилятор. Конечные HOST/аппаратные наборы не доказывают правильное
округление на всех binary64-входах. Контракт значений — RNE, gradual underflow,
signed zero и quiet NaN; errno/fenv исключения не реализуются.

[source-and-validation.json](m0-nonpow-20261031/source-and-validation.json)
связывает исходники, объекты и сохранённые предыдущие проверки по SHA256.
Воспроизведение рациональных свидетельств из корня репозитория:

```sh
python3 -B tools/generate_m0_log_table.py --check
python3 -B tools/certify_m0_near77.py --source-root . --json /tmp/m0-near77.json
python3 -B tools/certify_m0_rounding_corrections.py --source-root . --json /tmp/m0-rounding.json
python3 -B tools/certify_m0_trig_table70.py --source-root . --json /tmp/m0-trig70.json
```

Полученные JSON должны совпасть с
[сохранёнными сертификатами](m0-nonpow-20261031/certificates/near77.json),
[rounding-corrections.json](m0-nonpow-20261031/certificates/rounding-corrections.json)
и [trig70.json](m0-nonpow-20261031/certificates/trig70.json).

## Возврат устройства

Исходные2МиБ Flash восстановлены и побайтно проверены чтением, собственная
временная SD-нагрузка удалена. Полные данные, настройки и UI возвращены;
одна DATE восстановила исходную временную шкалу, а отдельная финальная
проверка без записи подтвердила RTC_SET1/PPM0 и ход часов. Финальный возврат
независимо принят координатором (`85ba1b59…`), все аппаратные этапы закрыты.
Порт закрыт; дальнейших аппаратных операций в подготовке коммитов нет.
