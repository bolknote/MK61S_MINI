# Spectrum: открытие файлов из проводника, 7 ноября 2026

Состояние: HOST-проверки и сборка прошли. Аппаратная проверка этой пары
ещё не выполнена: PicoCalc занят общим M0-прогоном, окно поставлено в очередь.

## Поведение

Проводник распознаёт `.z80`, `.sna`, `.trd`, `.scl` без учёта регистра
и выбирает APP с идентификатором обработчика `Z1`. Поиск сначала идёт
в каталоге файла и его родителях, затем в стандартных папках приложений
с ограниченным обходом подпапок. Путь к APP возвращается до запуска,
поэтому рекурсивные буферы поиска не остаются на стеке эмулятора.

Снимки загружаются и продолжаются; диск подключается к Beta Disk для чтения,
после чего стартует машина. Программу внутри диска выбирают средствами TR-DOS.
Обычное открытие APP показывает прежнее меню. Esc ставит игру на паузу,
F10 завершает APP. Удержанный Enter проводника блокируется на входе в гостя.

`FILE_BYTES/PATH` возвращает абсолютный M8-путь по ID файла. Относительные
пути ПЗУ остаются привязаны к каталогу самого APP. Физические двоичные файлы
помечаются `EXTERNAL_BINARY=254` и не декодируются как текст. Этот маркер
не имеет magic C6/C9 и не принимается внутренними операциями записи.
Формат хранилища, существующие типы и ABI6 не меняются.

## Проверки

- Полный Pico HOST с ASan/UBSan: путь с кириллицей, двоичный файл70000 байт,
  чтение после смещения65534, границы буфера, неверный ID, запрет текстового
  редактирования внешнего бинарного файла, прежние контракты оболочки.
- Настоящий Spectrum APP: SNA48/SNA128/Z80/TRD/SCL из другого каталога,
  удержанный Enter, F10, штатное освобождение SRAM/PSRAM/audio; отсутствие
  PATH, неподдерживаемое расширение и повреждённый Z80. Обычное меню,
  варианты ROM-кэша и старый сервис LCD также проходят.
- Настоящий production lookup в HOST с Pico-флагами и реальным декодером
  заголовка: локальный/родительский/вложенный APP, регистр расширения,
  CRC и magic, отсутствие обработчика, ограничение обхода4096 записей.
- Полный program_store с ASan/UBSan в трёх backend: новый внешний тип
  не сохраняется и не заменяет существующий файл; прежние C6/C9 проверки,
  квоты, remount и прерванные транзакции проходят.

Первый новый тест попытался создать TEXT из двоичных байтов с NUL; исправлена
фикстура контрольного текста. Отдельные неудачи замороженной сборки были
неполнотой копии зависимостей и отсутствием executable bit у Python packer;
после добавления Ryu, Spectrum ROM/иконок и сохранения режимов файлов сборки
прошли. Все эти ошибки возникли до аппаратных действий.

## Комплект

База исходников: main `663bd2108`; экспериментальные M0-варианты выключены.
Основная прошивка `F0E86C32`/`5009F89E`,1538304 байта. Статическая SRAM
118408, куча110968 при минимуме108544. APP:34325 байт, память47880 из49152,
ABI6, обработчик `Z1`. Базовый LCD12 МГц; Spectrum запрашивает24 МГц.
Существующий автоматический аудиорежим200/125 МГц сохранён.

Артефакты: `.build/spectrum-file-open-20261107/qualification.json`,
`source-provenance.json`, `source/`, `firmware/`, `app-final/`,
логи HOST и `HIL_PLAN.md`. У qualification статус `HOST_PASS_HIL_PENDING`,
`hardware_verified=false`, `hardware_io=0`. Перед аппаратным окном нужно
сопоставить комплект со свежими принятыми изменениями runtime и handoff ROOT.

Миниатюры игр этим изменением не добавляются. Обычные SNA/Z80 не имеют
отдельной стандартной иконки; для будущих миниатюр можно извлекать сохранённый
экран, который может оказаться заставкой, меню или игровым кадром.
