# Частоты132/138 в настройках Classic — 2026-11-08

Добавлены штатные offline-профили F411. Список:96/108/120/132/138МГц. Последние два явно подписаны «без USB»; на узком символьном экране используется «USB-». При крупном UI-шрифте подпись сокращается целиком, чтобы признак выключенного USB не исчезал при обрезке строки. OK/shifted arrows меняют значение прямо в общем списке настроек. Отдельное подменю частоты не требуется.

Настройка применяется после перезапуска. В132/138 USB выключен на весь выбранный профиль, включая ожидание и обычный калькулятор. Чтобы вернуть CDC, USB Screen и USB-диск, нужно выбрать96/108/120 и перезапустить прибор. Уже установленное соединение сохраняется, пока новое значение только выбрано и перезапуск не выполнен.144МГц исключены после воспроизведённых ошибок вычислений; см. [исследование CRC](compute-clock-crc-isolation-20261108.md).

## Реализация

Профиль выбирает PLL до инициализации USB и таймеров.132/138 используют HSE25,M25,N264/276,P2,Q6,VOS1,Flash latency5. Вычислительный запрос переключает только делители:66↔132 и69↔138; PLL не перезапускается. APB и таймеры сохраняют частоты между этими состояниями. SPI выбирает делитель по реальному PCLK.

Общая граница USBD_LL_Init отклоняет offline-профиль до включения PHY, IRQ и тактирования USB. Это действует для CDC, MSC и повторного запуска после сна. Start после отклонённой инициализации возвращает ошибку, Stop безопасно завершается. Пункт USB-диска сообщает, что USB выключен, и предлагает выбрать96–120МГц.

Для пяти значений использованы младшие2бита профиля в SoundSettings и ещё1бит в SettingsFlags. Режим скорости калькулятора имеет два значения и занимает1бит; соседний бит теперь явно относится к частоте. Оба байта и16-байтная запись журнала сохранили размер. Чтение при загрузке и сохранение меню используют общие функции упаковки. F401 сохраняет84/96/108, PicoCalc125/200/250.

## Программные проверки

- ASan/UBSan: политика запросов нагрузки, вложенные ожидания, токены APP, границы, все пять сохранённых значений, независимость громкости/строк/скорости; стертые настройки дают штатный профиль.
- Подписи RU/EN: все пять частот,16-колоночный LCD и крупный UI-шрифт сохраняют видимый маркер USB.
- UI contracts и журнал настроек: PASS.
- Реальный ARM-код F411: все PLL, делители, стабильные APB/таймеры, монотонное время, IRQ mask и STOP restore: PASS.
- F401: те же проверки для его штатного состава; STOP в этой сборке отсутствует, что явно учтено параметром модели.
- Реальный ARM USB F411: offline Init/Start отклонены без обращений к регистрам USB; остальные USB-регрессии прошли. Обычный USB на F401 также PASS.
- Реальный SETUP.APP на F401/F411 по трём адресам: все пять вариантов F411,132/138 и подписи, сохранение только запроса без изменения активной частоты: PASS. Селектор аппаратного теста проверен отдельно, включая3/4 и отказы5/7.

## Аппаратная проверка сохранённых профилей

Classic AEB505B6E0067623, USB2068336B4731, только выделенное окно этой платы. Временная диагностическая копия209CC822 имеет единственный дополнительный загрузочный пробник: после загрузки offline-профиля запускает конечный CLKTEST.APP, записывает состояние USB, сохраняет0 и перезапускается. Это даёт хосту прочитать результат уже при96/USB48. Пробник отсутствует в рабочей076CC619. Сохранены обе пары ELF/BIN и точный boot-probe.patch.

Каждый запуск: три фазы по4 194 304шага xorshift, checksum3289793925 во всех фазах, END принят, повторный END отклонён. В offline-профилях непосредственно до/после APP прочитаны аппаратные USB gate=0 и IRQ enable=0. Устройство исчезает из ОС при offline-загрузке и вновь доступно после возврата96. Интервалы между соседними вызовами service() конечного RAM-пробника≤30мс; это не отдельный профиль физических строк клавиатуры во время полной загрузки APP. Предыдущие полные шахматные проверки этих частот с отключённым USB: [отчёт](compute-clock-offline-132-138-20261108.md). Повторный шахматный A/B/A именно нового штатного пути в этой серии не выполнялся; новых чисел ускорения не заявляется.

Первая попытка загрузочного пробника вызвала только разбор script OPEN и не исполнила возвращённое намерение. Пробник исправлен на обычный OpenStoredFile, результат открытия дополнительно проверяется. Этот дефект касался только временного HIL-кода; ошибочная попытка не включена в успешную матрицу.
