# Промежуточный результат M0+: стенд R55 в RAM

Сохранено состояние после `77b128bf3`: исходники автономного USB-стенда для `pow`, рецепты сборки, закреплённые результаты проверки новой RAM-компоновки и два завершённых чтения состояния PicoCalc. Математический кандидат остаётся R55 из предыдущего checkpoint. Производственный runtime и M4 этим коммитом не изменяются.

| Работа | Состояние |
| --- | --- |
| Образ стенда | Собран SDK `no_flash` ELF с загрузочным кодом, USB-протоколом и исходными математическими объектами R55. Первые 4 КиБ SRAM и банк core1 исключены из загрузки. |
| Проверка RAM-компоновки | Сохранены 274008 публичных ARM-вызовов в эмуляторе, 68502 состояния. Кандидат совпадает с закреплёнными эталонными значениями. Все корректные результаты Qfplib сравниваются, ошибочные результаты и их стоимость сохранены. |
| Известные отставания `pow` | В RAM-корпусе осталось 1435 пар. Они входят в прежние 1452; уменьшение связано с размещением кода и не объявляется новым улучшением алгоритма. Метрика — исполненные инструкции Thumb. |
| Код стенда | Сохранены 147 проверок / 148 ARM-вызовов его служебных функций и результаты инертных проверок протокола. Полная инициализация периферии SDK и USB на плате ещё не проверена. |
| Чтение PicoCalc | Первый запуск остановился из-за неверного требования нулевого накопительного счётчика клавиш. Его журнал сохранён. R2 проверяет заданную исходную величину 25 и успешно прочитал нулевые регистры, стек и программу; процесс завершён, порт закрыт. |
| Последующие аппаратные этапы | Переход в ROM, загрузка RAM, замеры и возврат ещё не выполнены. Новые operator-скрипты сохранены как незавершённые: `ENVELOPE-FROZEN.json` отсутствует, окончательное закрепление и проверка координатором открыты. |
| Часы | Наблюдался `RTC_SET=0`. Принято возвращение с явным HOLD часов; установки времени или внедрения снимка часов не было. |

Два чтения устройства не выполняли переходов, загрузок, записи Flash, установки времени или открытия APP. Сохранённые разрешения уже закрыты; архив не даёт разрешения на новый доступ к устройству. Аппаратные такты не измерены. Универсальное корректное округление всей библиотеки, завершимость общего `pow`, приёмка FMA, универсальная граница стека, независимая приёмка и внедрение остаются открытыми.

Проверка сохранённых данных без устройства, ARM, MPFR и запуска производителей:

```sh
python3 -B verify_checkpoint.py --records
```

`provenance.json` связывает исходные пути с файлами `payloads/`, адресованными SHA-256. Исходные байты и три завершённых FROZEN сохранены. Скомпилированные образы и объектные файлы опущены с сохранением размеров и хэшей; сырые журналы чтения устройства сохранены полностью. Незапечатанные operator-скрипты не приравниваются к этим трём завершённым пакетам. Для пересборки математических объектов нужны исходники R55 из предыдущего checkpoint и указанные в рецептах SDK и инструменты. Временные незакреплённые файлы каталога сборки SDK не архивируются.
