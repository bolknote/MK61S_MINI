# dadd/dsub: малые normal-порядки и быстрые Inf/NaN

Прямая работа по пользовательской цели: скорость Qfplib или лучше,
правильное округление, M4 сохранить. Отдельный private WIP поверх принятого
top-normal кандидата; родитель и прежние reviewed targets не менялись.

Нормальные входы с max exponent1..54 теперь используют assembly. При
разных знаках нормализация точной разности останавливается на exponent1;
малый коэффициент упаковывается как subnormal без потери битов. При gap≥2
повторная far-проверка исключена по доказанной границе gap≤53. Одинаковые
знаки используют прежний unsigned kernel. Inf/NaN с ненулевыми полями
порядка получают отдельный быстрый возврат с прежним payload/sign policy.

На всех762 прежних медленных low-normal входах Qfplib правилен; новый
кандидат теперь не медленнее его. Среднее: **67.93 инструкции** против
307.25 у родителя и77.99 у Qfplib. Это число инструкций, не физические такты.

44 455 целевых случаев /133 365 ARM-вызовов: exact integer RNE и directed
MPFR4.2.2 без ошибок у кандидата и родителя. Проверены все бюджеты1..54 и
ширины разности, signed/alignment ветви, normal/subnormal результаты,
каждый NaN payload bit и правило выбора NaN. Знак/payload NaN сохранён
побайтно относительно родителя. Raw ошибочные10667 результатов Qfplib
сохранены; это доля специально подобранного набора, не частота в приложении.

Инструкции измерены на9527 из этих случаев:9286 быстрее родителя,241 равны,
0 медленнее;6738 прежних проигрышей правильному Qfplib устранены, новых нет.
Непрофилированные строки не участвуют в утверждении о скорости.
Ещё2416 контрольных обычных/top случаев /7248 ARM-вызовов совпали с
родителем по результатам и числу инструкций. Все17 ранее исправленных
входов и overflow-midpoint controls также сохраняют прежнюю стоимость.

На каждом вызове проверены R4–R11, восстановленный SP, ограниченные записи
стека, сохранение READY/DIRTY SIO; исполнены реальные ELF и captured ROM.
Новый fast path занимает20 байт кадра, прежний fallback для E0 —24 байта
перед старым C++ helper. Новых helper/MMIO/IRQ/global RAM не добавлено.

Контрольные объекты: блок880→1204 байта (**+324 байта**, включая8 байт
IEEE literal constants). Новых таблиц нет. Остальные allocated sections,
весь следующий multiply/divide код и undefined dependencies побайтно/
пономерно прежние. M4 soft/hard и generic M0 compile controls совпали.
Это object isolation, не новый полный M4 build или итоговый размер firmware.

`body-equivalence.json` связывает все1204 байта public object с реально
исполненным diagnostic ELF, кроме одного BL90..94 на прежний
`mk61_m0_dadd_slow`0x100e6e44. Entry offsets совпали. Source SHA
`cff70bd3559412879c421a06f7ec16dd75726aa2a964ed3062f9936a58737de2`;
diagnostic ELF `a3479749d5f9764b1987eac1ba1dda9cbcb4df19005978eed5d97d027c0d850a`.

Дельта для review: `cold-normal-only.patch`; full private source:
`native_eabi_m0_rp2040.S`. `PROOF.md` содержит предусловия и границы
аргумента; `qualification.json` и `controls.json` — текущие результаты.
`initial-smoke-before-gap-shortcut.json` — исторический первый trial,
не финальный speed report; его46 отставаний устранены в текущем ELF.

Независимый GO этого WIP ещё не заявлен. Номерная firmware, canonical/Git,
USB/Flash и general qualification pipeline не создавались/не менялись.
18 профилированных проигрышей правильному Qfplib на subnormal-input ветвях
остаются через прежний E0 fallback. Именно subnormal входы/нули — следующий
остаток этой операции; subnormal результат из normal входов уже ускорен.
Прочие исходные отставания, general pow с UDF, интеграция на принятую базу
и физическая приёмка всей библиотеки остаются открытыми.
