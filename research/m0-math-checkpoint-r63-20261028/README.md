# M0+: промежуточный результат R63 и аппаратные замеры

Сохранены исходники и исследования R56–R63 после checkpoint `fafce31ed`, завершённые проверки и две партии физических замеров R63 на RP2040. Выбранный частный кандидат — R63. Исходники производственной библиотеки этим checkpoint не заменяются; M4 не меняется.

| Результат | Состояние |
| --- | --- |
| R63, `pow` для положительных субнормальных степеней двойки | Предикат округления к нулю расширен на все 53 бита мантиссы показателя. В расширенном конечном корпусе 152937 пар / 324446 состояний отставания R62 → R63: 1692 → 1400; исправлены 292 пары, новых отстающих состояний нет. |
| Размер R63 относительно R62 | +32 байта кода, новых таблиц, глобальной RAM и libgcc нет. Остальные объекты и проверки отключённой специализации для M4/обычного M0 сохранены. |
| Физические замеры текущей матрицы | Проверены 48 из 84 различных пар, 144 состояния делителя: 5880 вызовов вместе с эталонами и калибровкой; все 1440 вызовов нашей математической функции совпали с закреплённым эталоном. |
| Исправленные целевые случаи на устройстве | 26 пар быстрее корректных результатов Qfplib в 2,44–3,36 раза. Все три варианта Qfplib, ошибочные выходы и их стоимость сохранены. |
| Отставания на устройстве | Сохранены пять медленных контрольных пар из первой партии; во второй новых медленных пар нет. Инструкции эмулятора и физические такты различаются: один из пяти контролей отстаёт только в физических тактах. |
| Остаток инструкционного корпуса `pow` | 1400 известных отстающих пар: 721 для обратного квадратного корня, 483 с нормальным результатом, 196 с нулём/бесконечностью. Это конечный корпус, не универсальная гарантия. |
| Возврат устройства | Первая партия полностью закрыта с точным возвратом данных. После второй Flash и штатная 249 возвращены; проверка текущих данных остановилась на изменившемся счётчике клавиш. Последующее чтение сохранило IP158 и четыре нажатия; сброс временной памяти ещё не выполнялся. RTC_SET=0, точное продолжение хода часов не утверждается. |
| Близкие к степени двойки основания и отрицательный целый показатель | Сохранены точные математические доказательства и отдельный неприменённый `guard.patch`. Нового скомпилированного кандидата и измерений этого патча нет. |

Остаются 36 пар аппаратной матрицы, известные отставания `pow`, универсальное корректное округление и завершимость общего `pow`, приёмка FMA, универсальная граница стека и внедрение в production. Наблюдавшийся на устройстве максимум стека 2276 байт не является универсальной границей. Предыдущие исследования, неудачные прототипы, увеличения числа инструкций и исторические `pending` сохранены; актуальные утверждения задаёт `scope.json`, а принятие R63 подтверждает сохранённый `ROOT-ACCEPTANCE.json`.

Проверка архива и пересчёт сохранённых записей без устройства, ARM, MPFR, SDK и запуска производителей:

```sh
python3 -I -B verify_checkpoint.py --records
```

`provenance.json` связывает исходные пути с адресованными SHA-256 файлами `payloads/`. Исходные байты сохранены, имена архива совместимы с Windows. Скомпилированные образы, объектные файлы и полные копии Flash опущены с сохранением размеров и хэшей; сырые журналы обмена сохранены. Незапечатанные журналы и рабочие сведения — снимки, а не новые разрешения на выполнение. Для восстановления исходного текстового пакета можно использовать `--extract-packet r63 ПУСТОЙ_КАТАЛОГ`; это лишь распаковка файлов. Рецепты пересборки сохраняют ссылки на исходный SDK и инструменты, которые не включены в архив.
