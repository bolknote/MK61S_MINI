# Промежуточный результат математики M0+: R47, R48, exp Q73

В этом checkpoint сохранены исходники, доказательства, журналы и полные записи измерений частной экспериментальной ветки. Рабочая реализация продукта не изменяется. M4 и обычный M0 не изменены.

| Работа | Сохранённый результат | Статус |
| --- | --- | --- |
| R47: нормализация деления | Полная авторская проверка: 2 371 465 публичных ARM-вызовов. На объединении 79 846 проверенных пар нет деления медленнее корректного результата Qfplib. | Выбранный частный кандидат; независимая и аппаратная приёмка открыты. |
| R48: ранний выбор пути деления | Обычные полные мантиссы: −1 инструкция; нормальный результат при делителе — степени двойки: −10. Пограничные пути: +3 / +12; малый делитель: +2 / +5 относительно R47. Сохранены все увеличения стоимости. | Диагностический эксперимент, не выбран. Полная проверка подготовлена, ещё не выполнялась. |
| exp Q73 | Модель на компьютере однозначно округлила 482 из 512 ранее отстающих входов; 30 требуют уточнения. Ошибок среди принятых результатов нет. Используются существующие таблицы. | Реализации на ARM и замеров скорости нет; полный корпус ещё не проверен. |

В проверенном конечном наборе R47 остаются отставания: `pow` — 2045 пар, `exp` — 512 входов. Это не исчерпывающий перечень функций или всего пространства binary64. Метрика — исполненные инструкции Thumb, не аппаратные такты.

Универсальное корректное округление всех функций, завершимость общего `pow`, приёмка FMA, универсальные границы стека, физические замеры, независимая проверка и внедрение остаются открытыми. Исторические допуски не распространяются на новый кандидат.

`scope.json` задаёт актуальную область утверждений. Снимок исторического журнала сохранён без исправления старых полей. Приоритет имеют `scope.json` и авторский результат R47.

## Проверка архива

Из этого каталога выполните:

```sh
python3 verify_checkpoint.py --records
```

Проверка читает только этот архив, сверяет SHA-256, исходные манифесты FROZEN и заново подсчитывает сохранённые записи. Исторические производители, ARM, MPFR и устройства не запускаются.

`provenance.json` явно сопоставляет каждый исходный путь с файлом в `payloads/`. Оригинальные байты FROZEN, исходников и результатов сохранены. Локальный `.gitattributes` сохраняет исходные окончания строк на всех платформах. Имена файлов архива адресованы хэшем: зарезервированные имена Windows и совпадения регистра исключены. Исходные имена, включая возможные `aux.log`, остаются только ключами JSON и не используются как пути назначения.

Скомпилированные ELF/объекты сознательно не включены; их исходные хэши, размеры, рецепты сборки и отпечатки секций сохранены. Этот checkpoint продолжает исторический коммит `45b77a1e1120080538831ea333f9174bc5af7679`; точная ссылка на предыдущий коммит записана в `checkpoint.json`.
