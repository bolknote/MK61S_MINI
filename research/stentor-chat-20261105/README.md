# Stentor 12M: проверка 5 ноября 2026

[StentorLabs/Stentor-12M-Instruct](https://huggingface.co/StentorLabs/Stentor-12M-Instruct),
ревизия `6d44a6ffc689a021365eb97ea66d795929a1b646`, **12 047 040** параметров.
Веса и config подтверждают 12 слоёв, хотя в таблице model card указано 9.
Используется штатный LlamaForCausalLM без remote code.

Выполнены те же семь реплик, что для TinyTalk/Brandon, на CPU в FP32.
Использован опубликованный chat template и короткий system prompt из Quick
Start автора. В greedy все семь ответов — варианты «I can't help ...».
С настройками примера автора (T=1,1, top-p=0,6, repetition penalty=1,3;
top-k=50) три ответа пустые, остальные отказоподобные или бессвязные.
Длинный обучающий system prompt не испытывался. Модель не выбрана для чата.
Сырые результаты: `smoke-greedy.json`, `smoke-sampled.json`.

Расчёт памяти находится в `memory-budget.json`, общий скрипт — в соседнем
`brandon-chat-20261105/memory_budget.py`. Для проекта компактного BPE словаря
нужно 817 730 байт (включая 58 980 правил слияния). Q4 с группами по 32 веса
и FP16 scales, FP16 KV и резерв 256 КиБ не помещаются даже при контексте 64.
С группами по 64 веса контекст 64 арифметически помещается; контекст 128
уже превышает бюджет. Квантование этой модели не выполнялось, нативный
порт и его фактическая память/скорость не проверены.

```sh
bash research/stentor-chat-20261105/chat.sh
```
