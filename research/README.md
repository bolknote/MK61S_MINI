# Архив исследований МК-61

Снимок исходников и результатов из прежнего локального `tmp/`, сохранённый
14 октября 2026 года после консультации с авторами. Это история исследований,
а не новые возможности прошивки. Файлы в `*-sources.json` проверены по SHA-256
при копировании; программные исходники сохранены без изменений.

`ms-rom-reachability/` содержит анализ настоящего ПЗУ, независимую пятичиповую
модель и поиск сохраняющей записи в Ms. Полный сохраняющий писатель ещё не
найден. В `experiments/` есть ранние опыты с подстановкой внутреннего состояния:
они не доказывают достижимость с клавиатуры. Снимки нативных доказательств,
которые ранее жили только в `/private/tmp`, находятся в `evidence/`.
`reference-emulator/` сохраняет использованные исходники эталона; старые
скрипты по-прежнему ссылаются на внешний репозиторий `MK-61`.

Каталоги `elite-k1-options-*`, `ms-selfextract-*`, `ms-compression-*` и
`ms-decompressor*` содержат генераторы, входные данные, ручные опыты и итоговые
проверки распаковщиков. Финальный комплект — `ms-decompressor-auto-init-2026-10-07/`:
19-байтный распаковщик, программа в 105 ячейках и интерактивное демо.
Его эталон игры хранится в `ms-compression-search-2026-10-01/catalog.json`.
Старые HTML статьи не содержат последних несохранённых правок из редактора;
снимки экрана также не являются полной текстовой копией этих правок.

Для скриптов с историческими абсолютными путями можно восстановить ссылки
из `tmp/`, не меняя исходники:

```sh
python3 research/restore_legacy_paths.py
```

Некоторые опыты требуют прежних версий прошивки, эталонного эмулятора и Z3.
Не включать их в штатный CI без отдельной адаптации. Отрицательные результаты
сохранены, чтобы не повторять уже исключённые варианты.

Полный прежний `tmp/`, включая промежуточные сборки, HIL, кадры, frozen snapshots
и резервные копии, сохранён локально в
`.build/uncommitted-cleanup-20261014/tmp.tar.zst`; рядом находятся манифест и
отчёт проверки каждого файла. Этот локальный архив не входит в Git.
