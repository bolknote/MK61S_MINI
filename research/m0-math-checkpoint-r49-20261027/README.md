# Промежуточный результат M0+: exp incremental r2 и сборка R49

Сохранены исходники, рецепты, доказательства и полные записи выполненных проверок после checkpoint `bb27657c`. Выбранный частный авторский кандидат библиотеки — R48. Новый `exp` встроен в частную сборку R49; общая проверка этой сборки ещё не запущена.

| Работа | Результат | Что осталось |
| --- | --- | --- |
| Полный прототип `exp` incremental r2 | 568856 уникальных входов, 1224907 состояний. Найдено 0 ошибок и 0 отставаний от корректных результатов Qfplib; раньше у R48 было 512 отстающих входов. Сложный вход — 634 инструкции, столько же у Qfplib. | Общая проверка R49 и независимая приёмка. Конечный корпус не доказывает весь binary64. |
| Реальная сборка R49 | Новый публичный вход и внутренний alias совпадают. Контрольный прогон: 171 публичный ARM-вызов, 19 эталонов MPFR, 0 ошибок / отставаний. Пройдены обязательные проверки связей, загрузки, отрицательных контролей и разделения архитектур. | Полные связанные прогоны публичных операций и легальных состояний вызывающего кода. |
| M4 и обычный M0 | 18 исходных контрольных объектов точны по выделенным байтам, символам и смысловым релокациям. Новый ассемблер `exp` для этих сборок пуст. | Подтверждённая область — сохранённые объекты и проверки. |
| Q85 small | На полном корпусе оставался один отстающий вход. | Заменён экспериментом incremental r2; не выбран. |
| Q83 и incremental v1 | Q83 достиг 629 против 634 на сложном входе, но создал пять новых отстающих входов; v1 требовал 649. | Оба отклонены; отрицательные результаты сохранены. |

Сравниваются все корректные результаты Qfplib. Сохранены и ошибочные результаты Qfplib с их стоимостью, и все увеличения стоимости относительно родителей, включая уже медленные случаи. У incremental r2 относительно R48 таких строк 809101, относительно Q85 — 402182. Это совместимо с отсутствием отставаний от корректного Qfplib на проверенном корпусе.

Метрика — исполненные инструкции Thumb, не аппаратные такты. На полном корпусе значения и стоимость эталонов взяты из закреплённых предыдущих результатов; новые исполнения и свежие MPFR-проверки отмечены отдельно. Прототип имеет 1233088 диагностических публичных ARM-вызовов, 19 новых MPFR-входов; они не являются квалификацией R49. Новых таблиц, глобальной RAM и libgcc не добавлено. Используются существующие таблицы; прибавка кода прототипа относительно R48 — 3168 байт.

Остаются универсальное корректное округление, завершимость общего `pow`, приёмка FMA, универсальная оценка стека, физические такты, независимая проверка и внедрение. У выбранного R48 в известном конечном объединении `pow` отстаёт на 2045 парах, `exp` на 512 входах; это не перечень всех оставшихся функций. `scope.json` задаёт актуальную область утверждений, исторические журналы её не расширяют.

Проверка архива:

```sh
python3 verify_checkpoint.py --records
```

Потребитель использует только стандартную библиотеку Python: сверяет SHA-256, исходные FROZEN и пересчитывает сохранённые записи. Он не запускает производителей, ARM, MPFR или устройства. Проверка самого архива автономна. Повторное выполнение исторических производителей требует указанных в них инструментов и исходных зависимостей.

`provenance.json` сопоставляет исходные пути с содержимым `payloads/`. Байты исходных документов не переписаны. Имена адресованы хэшем, совместимы с Windows и уникальны без учёта регистра; `.gitattributes` сохраняет байты. Объектные файлы, ELF и другие скомпилированные двоичные файлы опущены; их размеры и хэши сохранены. Пакет — промежуточный исследовательский checkpoint; производственный runtime и оборудование этим коммитом не меняются.
