Эталонный код и все положительные учебные DONE проверены настоящим ROM эмулятором. Учитель во время экзамена не вызывается.

После продолжения HEX решает 356/479, SPEC — 386/479. Навигация RUN 00/01 стала надёжнее, однако проблема проверки смысла не решена: в raw остаётся 48 ложных DONE у HEX и 45 у SPEC. Отдельная перестановка таблицы констант выявила существенную хрупкость, особенно у HEX; высокую точность при обычном порядке таблицы нельзя переносить на произвольный порядок.

## Выбор RUN и завершение

В навигационных пробах исходный код гарантированно правилен. Реальный WRITE оставляет проверенным только текущий случай. Модель должна выбрать недостающий RUN 00 либо RUN 01 и затем DONE; все действия свободные. На цикл отводится до пяти ответов. RUN не подставляется кодом оценки.

| Q4 | Следующий RUN 00 | Следующий RUN 01 | Полный корректный цикл |
|---|---:|---:|---:|
| HEX родитель | 32/32 | 32/32 | 2/64 |
| HEX продолжение | 32/32 | 32/32 | 60/64 |
| SPEC родитель | 2/32 | 32/32 | 0/64 |
| SPEC продолжение | 32/32 | 32/32 | 58/64 |

Полная отладка: 128 новых условий × правильное/ошибочное начальное решение, до 12 действий. Успех требует правильного кода на отдельных аудиторских входах, допустимого DONE и обоих публичных запусков текущей редакции. Ложный DONE ниже означает завершение с неверным кодом. Верный код с DONE без необходимых запусков указан отдельно.

| Q4 | Режим | Успешно | DONE | Ложных DONE | Верный код, непроверенный DONE | Исправлено ошибочных стартов |
|---|---|---:|---:|---:|---:|---:|
| HEX родитель | raw | 84/256 | 181 | 78 | 19 | 24/128 |
| HEX родитель | self | 10/256 | 13 | 3 | 0 | 5/128 |
| HEX продолжение | raw | 202/256 | 250 | 48 | 0 | 84/128 |
| HEX продолжение | self | 173/256 | 176 | 3 | 0 | 82/128 |
| SPEC родитель | raw | 6/256 | 35 | 19 | 10 | 0/128 |
| SPEC родитель | self | 0/256 | 0 | 0 | 0 | 0/128 |
| SPEC продолжение | raw | 209/256 | 254 | 45 | 0 | 101/128 |
| SPEC продолжение | self | 198/256 | 211 | 13 | 0 | 98/128 |

raw оставляет решение о DONE модели. self проверяет код относительно её собственной одношаговой спецификации, поэтому ошибочное понимание условия может пройти такую проверку. Совпадение со своей формулой не доказывает верное понимание запроса. Низкое число ложных DONE нужно читать вместе с числом завершений и правильных решений.

У SPEC абсолютное число ложных DONE выросло с 19 до 45, одновременно число всех DONE выросло с 35 до 254: доля ошибочных завершений снизилась с 54.3% до 17.7%. Это существенное улучшение покрытия, но не решение проблемы безопасности завершения. У HEX ложных DONE стало 48 вместо 78, доля снизилась с 43.1% до 19.2%.

Примеры оставшихся ошибок в raw:

- **hex:** Вычислите значение выражения: R5 в степени 8. Углы заданы в радианах. Результат оставь в X. Тот же результат запиши в R8. Остальные регистры памяти сохрани; после вычисления остановись.
  Требуется: `X=(R5pow8); R8=(R5pow8); остальные регистры сохранить; RAD`. Финальный код: `X=(8powR5); R8=(8powR5); остальные регистры сохранить; RAD`. Сеть заявила DONE.

- **hex:** Вычисли косинус от результата деления целой части числа -22 на значение регистра R4; углы заданы в градах. Результат оставь в X. Остальные регистры памяти сохрани; после вычисления остановись.
  Требуется: `X=cos((int(-22)/R4)); остальные регистры сохранить; GRAD`. Финальный код: `X=cos((int(0)/R4)); остальные регистры сохранить; GRAD`. Сеть заявила DONE.

- **spec:** Вычисли косинус от результата деления целой части числа -22 на значение регистра R4; углы заданы в градах. Результат оставь в X. Остальные регистры памяти сохрани; после вычисления остановись.
  Требуется: `X=cos((int(-22)/R4)); остальные регистры сохранить; GRAD`. Финальный код: `X=cos(((R4/R4)/R4)); остальные регистры сохранить; GRAD`. Сеть заявила DONE.

- **spec:** Найди дробную часть от экспоненты дробной части значения регистра R5; углы заданы в радианах. Результат оставь в X. Остальные регистры памяти сохрани; после вычисления остановись.
  Требуется: `X=frac(exp(frac(R5))); остальные регистры сохранить; RAD`. Финальный код: `X=frac(exp(int(R5))); остальные регистры сохранить; RAD`. Сеть заявила DONE.

Дополнительная проверка перестановки новых констант и добавления отвлекающих чисел использует часть тех же AST; это проверка устойчивости, а не ещё один независимый тест.

Перестановка затрагивает только дополнительные константы и добавляет отвлекающие значения; базовые 12 позиций сохраняются. Она не меняет математическое задание.
