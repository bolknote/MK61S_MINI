# Контекст и символьное наблюдение без дообучения

Статус: завершено. Все пять диагностических вариантов и два закрытых
прогона закончены; рабочие веса и основной профиль не заменены.
Результаты: [HARNESS_SYMBOLIC_CONTEXT_RESULTS.md](HARNESS_SYMBOLIC_CONTEXT_RESULTS.md).

Причина опыта: в предыдущем закрытом наборе длинный рабочий профиль
прервал 161 из 512 обычных эпизодов из-за контекста. Новый курс SFT
улучшил диагностическое исправление при заданной верной SPEC, но ухудшил
автономное завершение. Поэтому проверяем ограничения harness отдельно от весов.

| Вариант | Контекст | Хранение KV | Наблюдение программы |
|---|---:|---|---|
| baseline | 1024 | FP32 | прежний HEX |
| half1024 | 1024 | FP16 | прежний HEX |
| context1536 | 1536 | FP16 | прежний HEX |
| symbolic1024 | 1024 | FP32 | формула и MATCH/MISMATCH/UNKNOWN |
| combined1536 | 1536 | FP16 | формула и MATCH/MISMATCH/UNKNOWN |

Численные операции attention остаются FP32. В FP16 хранятся именно K и V.
Исходный Q4-пакет и словарь неизменны, обновлений оптимизатора — ноль.

Формула выводится детерминированно из текущего кода консервативным
декодером прямолинейных программ. Статус относится к 16 числовым проверкам
по **заявленной моделью SPEC**, а не к скрытой эталонной интерпретации
русского условия. Неподдержанный код сохраняет HEX и статус UNKNOWN
для формулы. Исходный численный шлюз DONE, RUN, откат незавершённых правок
и предел в 12 действий сохраняются. MATCH не является доказательством.

Диагностика: 64 уже открытые задачи предыдущего опыта. Каждый вариант
получает 128 обычных эпизодов, 32 с ошибочной внедрённой SPEC и 32 с верной
внедрённой SPEC. Последние два режима — диагностические контроли.
Выбор по диагностике защищает успешные завершения, исправления,
завершение верного кода и перевод условия; увеличение ложных DONE,
порчи кода и ложных заявлений недопустимо. Равенство сохраняет baseline.
Если безопасного кандидата нет, лучший диагностический кандидат
проверяется отдельно как исследовательский, без автоматического принятия.

Новый закрытый набор: 256 задач, в том числе 160 составных. Новые числа
и шесть новых троек операций исключены из известных целей и наблюдавшихся
гипотез прошлых опытов. Эталоны и ошибочные начальные программы проверены
ROM-эмулятором. Выбор и список вариантов записываются до первого
модельного ответа на закрытом наборе. На вариант: 512 обычных эпизодов,
64 с неверной SPEC и 64 с верной SPEC.

Сервер: один inference-процесс на GPU 1, лимит CUDA allocator 1536 МиБ,
паузы до 50% доли активного времени, остановка ожиданием при свободной
памяти меньше 8192 МиБ. Работающий Qwen не меняется.

Дополнительно: частная копия C++-движка с преобразованием FP32↔IEEE FP16
на вводе/выводе кеша; проверка округления, совпадения потоков токенов
CPU/B200/C++, измерения памяти и времени на компьютере. Физический
PicoCalc этим опытом не измеряется. Код продукта не изменяется.

Артефакты: `.build/mk61-agent-20261106/harness-symbolic-context-v1`.
Замороженные данные, политика и код: `frozen.json`, `data-frozen.json`,
`policy.json`. Новый тест не используется для перенастройки протокола.
