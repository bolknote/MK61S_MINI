# Дистилляция промпта исполнителя Kon-Tiki 3M

Дали DeepSeek-V4.1-Flash полные инструкции и публичное состояние после пересмотра SPEC, включая символьную расшифровку текущей программы. Учитель выбирал следующее действие. Проверку прошли 142 из 400 ответов: 70 WRITE, 31 RUN, 14 DONE и 27 UNSURE. Разметку WRITE сверяли с исходным условием и исполнением в эмуляторе. В обучении также использовали 3384 проверенных состояния для повтора.

На B200 выполнили 900 обновлений rank-16 адаптера исполнителя с квантованием в Q4 на обучающих проходах. Из снимков на 300 и 900 обновлениях для аудита выбрали второй по отдельной валидации. DeepSeek использовался при подготовке уроков. На тестах исходные и обученные Q4-веса использовались только по назначению каждого вызова. Обученные веса обслуживали первый запрос исполнителя после пересмотра SPEC, когда полному промпту не хватало места. Первый перевод, повторный перевод и остальные шаги исполнителя использовали прежние веса.

Короткий промпт сохраняет русское условие, таблицу констант, пересмотренную SPEC, текущую программу и публичные результаты. Медианное сокращение на обоих закрытых наборах составило 352 токена на изменённый запрос. Из 24 таких эпизодов на повторном тесте исходные веса с коротким промптом выдали 2 полных WRITE, после дистилляции — 9. На новом тесте изменений было 21, число полных WRITE выросло с 0 до 5. Все эти команды уложились в 1024 токена вместе с промптом, заголовком и концом WRITE. Максимум составил 707 токенов.

Чистая дистилляция сохранила все 84 исходных исправления на повторном наборе и все 32 на новом. На известной задаче со знаком степени оба обученных снимка выдали UNSURE. На каждом закрытом наборе появилось по одному принятому ложному DONE, когда проверка программы опиралась на ошибочную SPEC.

Дополнительный прогон использовал существующий независимый разбор условия. При явно обнаруженном расхождении он блокирует WRITE и DONE после пересмотра SPEC. Если разбор совпадает с гипотезой, публичные запуски состоялись, а эмулятор опроверг текущую программу, после UNSURE или DONE запрашивается одна новая попытка WRITE. Она проходит прежний цикл проверки программы. При неподдерживаемом условии остаётся исходное поведение. Политику сформулировали после разбора диагностических ошибок. Сравнение этой ветки показывает поведение на тех же наборах.

Целевая задача вернулась с этой проверкой. Промпт сократился с 1008 до 656 токенов. Вместе с WRITE использовано 675 позиций. Затем прошли RUN и DONE. На закрытых наборах остались исходные 1 и 2 принятых ложных DONE. Отказов в новом наборе стало 33 вместо исходных 16. Итоговый Q4-снимок исполнителя занимает 1 725 730 байт, размер контекста 1024. Замеры получены на B200 с эмулятором МК-61. Рабочий профиль установки остался прежним.
