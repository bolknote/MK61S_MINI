# Независимая проверка SPEC в харнессе Kon-Tiki

Разбор степеней читает всё русское условие, включая оба порядка основания и показателя, знаки, десятичные запятые и регистр назначения. Явная формулировка с пропущенным операндом или неподдерживаемым продолжением вызывает запрос подтверждения. Для остальных неподдерживаемых задач используется прежний цикл.

Когда независимый разбор удался, харнесс сверяет программу с полученной формулой на открытых и дополнительных входах эмулятора. Уже проверенную программу он сохраняет и завершает после обязательных RUN. При правке он проверяет предложение до записи. Оценочный эталон и отложенные входы используются только для выставления результата.

Три режима на каждой панели использовали одни веса Q4, одно окно в 1024 токена и одни стартовые программы. На новом закрытом наборе использован рабочий компактный исполнитель со снимка 900. Для воспроизведения прежних ошибок использован снимок на шаге 46221. Переводчик заморожен, выполнено ноль обновлений весов. Замеры проведены на B200 с эмулятором МК-61.

Новый набор содержит 64 задачи на степень в 32 парах и 64 композиции. На задачу приходится по правильному и ошибочному старту. Независимый разбор дал верную SPEC на 64/64 задачах со степенью и на 30/64 композициях. Остальные 34 композиции вышли за пределы его грамматики.

| Новый закрытый тест Q4 | Текущий цикл | Ранняя проверка SPEC | Проверка и сокращение |
|---|---:|---:|---:|
| Успешные исправления /128 | 39 | 39 | 49 |
| Сохранены прежние исправления /39 | 39 | 36 | 36 |
| Правильные завершения /256 | 93 | 155 | 166 |
| Принятые ложные DONE | 9 | 0 | 0 |
| Ложные заявки DONE, включая отклонённые | 215 | 106 | 727 |
| Порча правильного кода /128 | 5 | 0 | 0 |
| Отказы UNSURE /256 | 39 | 15 | 84 |
| Отказы UNSURE при верной SPEC | 15 | 13 | 81 |
| Эпизоды с переполнением контекста | 97 | 77 | 0 |
| Оборванные WRITE | 11 | 7 | 0 |

Совместный режим дал 13 новых исправлений и потерял три из прежних 39. Все 113 WRITE с коротким промптом завершили генерацию. Максимум составил 875 позиций с промптом, заголовком и концом команды. Среди 69 дополнительных отказов относительно режима одной проверки 67 пришлись на эпизоды, которые раньше оборвались по длине, и два пришлись на ранее успешные эпизоды. Увеличилось число повторов отклонённого DONE.

На диагностическом повторе ранняя проверка снизила принятые ложные DONE с 17 до 1 и порчу с 8 до 1. Сокращение увеличило число исправлений с 28 до 51 и убрало все 17 исходных обрывов WRITE. В совместном режиме остались два принятых ложных DONE и одна порча. Оба ложных завершения пришлись на два старта одной композиции за пределами независимой грамматики.

Журналы каждого эпизода, метрики и контрольные суммы сохранены в каталоге .build/mk61-agent-20261106/kon-tiki-independent-spec-v1. Локальная проверка test_cq_harness.py покрывает неоднозначные условия, сохранение текущего кода, проверку перед записью, обязательные RUN и сокращение 17 прежних оборванных запросов.
