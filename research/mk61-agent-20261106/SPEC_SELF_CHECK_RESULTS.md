# SPEC Q4: обучение на 19 ложных DONE самопроверки

На новом закрытом наборе ложных DONE в режиме self: **19 → 18** из 256 эпизодов. Правильных принятых завершений: **199 → 212**. Обычная точность программ: 334/398 → 356/398. Все числа до/после относятся к одному новому экзамену, а не к сравнению разных наборов прошлых этапов. У сбалансированного варианта снижение ложных DONE статистически не подтверждено: интервал парной разности пересекает ноль.

Выполнены два продолжения по 4000 обновлений на двух B200. Выбрано **seed-a, шаг 4000**, только по новому development. Родитель был допустимым вариантом шага 0. Основное сравнение — один заранее выбранный кандидат и неизменённый родитель.

Полные адаптеры после обучения не прошли контроль сохранения навыков. До открытия closed дополнительно зафиксирована проверка сил 25%,50%,75%: параметры факторов rank16 и строк действий интерполируются между исходным и дообученным состоянием, затем заново вычисляется настоящий Q4. Правило выбора не менялось, дополнительных обновлений SGD нет. Выбранная сила адаптации: 0.25. Это отдельная настройка на development после первоначального плана; закрытый экзамен при ней не вызывался.

## Что произошло в исходных 19 эпизодах

Это 11 разных условий. Во всех 19 финальный код соответствовал неверной первоначальной гипотезе. В 8 эпизодах начальный код уже был правильным, затем сеть испортила его. Отказ самопроверки наблюдался в 6 эпизодах; в 4 проверка отклоняла действительно правильный код. Причины: `{"literal_or_sign": 9, "register": 2, "operation_or_composition": 8}`.

Покомпонентный разбор с условиями и гипотезами: SELF_CHECK_19_ANALYSIS.md. Он получен воспроизведением всех 19 историй в настоящем эмуляторе с проверкой каждого входного промпта.

## Что изменилось в обучении

Добавлены реальные ошибочные состояния, исходные формулировки 11 задач и новые перефразировки, задачи по неверным гипотезам как правильным запросам и 200 близких примеров с другими числами и регистрами. DeepSeek независимо переводила русские формулировки обратно в формулы; исходный AST в обратный запрос не передавался. Численные цели и переходы проверены ROM.

В самопроверке сохранён прежний протокол: первоначальная гипотеза фиксирована и отдельного действия для её замены нет. Если правильный код конфликтует с этой гипотезой, принятый корректный DONE может быть недостижим. Учебный ответ после наблюдаемого конфликта — сохранить правильную программу и UNSURE. UNSURE не считается успешным DONE. Обоснованный отказ проверки на неправильном коде учит WRITE → RUN → DONE.

До появления обратной связи скрытая правильность гипотезы не меняет метку действия: одинаковые видимые состояния с правильным кодом получают одинаковый DONE. Таким образом, конфликт не угадывается по скрытому полю или искусственному счётчику бюджета.

Учебных состояний 72207, допустимых по длине 71842. Статистика курса: `{"plausible_stopped_errors": 3208, "legitimate_repair_cycles": 1614, "preserve_correct_code_conflicts": 1614, "exact_retired_states": 114, "exact_retired_goal_prompts": 11, "parent_self_mined_states": 983}`.

Каждый batch содержит 10 строк перевода,4 обычных исправления,6 исправлений с обратной связью самопроверки, 4 RUN,4 DONE,3 UNSURE для наблюдаемого конфликта и 1 UNSURE для исчерпанного бюджета. Сохраняются парные перестановки таблиц констант и вспомогательные задания копирования числа.
