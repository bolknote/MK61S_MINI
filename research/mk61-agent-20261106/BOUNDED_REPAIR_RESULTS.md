# Одна попытка WRITE после отклонённого DONE

Сравнение Kon-Tiki 3M прошло на новом закрытом наборе из 128 русских задач. В наборе 32 пары задач на степени и 64 новые композиции. Каждая задача запущена с правильной и заведомо ошибочной программой. Во всех трёх режимах использованы те же веса Q4 и окно 1024 токена. Исполнитель и переводчик запускались на B200. Для допуска к завершению использовались два открытых и 16 проверочных входов, для итоговой оценки — ещё 32 входа.

При контрпримере харнесс запоминает пару кода и SPEC. Для независимо разобранного условия он запрашивает один `WRITE` и проверяет предложенный код в эмуляторе перед заменой. В режиме с компилятором при отклонении `WRITE` харнесс компилирует независимо полученную SPEC и применяет ту же проверку. Оба режима выполняют необходимые `RUN` для новой ревизии. Когда условие выходит за пределы грамматики и составленная моделью SPEC расходится с кодом, харнесс выносит формулу на подтверждение. В тесте подтверждения от пользователя не подставлялись.

| Метрика | Прежний цикл | Один WRITE | WRITE с резервной компиляцией |
|---|---:|---:|---:|
| Успешные исправления из 128 | 51 | 67 | 112 |
| Правильные завершения из 256 | 169 | 185 | 230 |
| Правильные завершения с правильного старта из 128 | 118 | 118 | 118 |
| Принятые ложные `DONE` | 0 | 0 | 0 |
| Итоговая порча правильной программы | 0 | 0 | 0 |
| Отклонённые заявки `DONE` | 759 | 94 | 94 |
| Повторные `DONE` после числового контрпримера на той же ревизии и SPEC | 636 | 0 | 0 |
| `UNSURE` | 80 | 48 | 3 |

| Максимум токенов для принудительного `WRITE` | — | 889 | 889 |

Начальный перевод дал 91 правильную программу из 128 во всех режимах. Из 71 принудительного `WRITE` все завершили генерацию, 26 прошли проверку. Компилятор исправил остальные 45 без дополнительных вызовов модели. Он сохранил все 67 исправлений режима с одной попыткой `WRITE`. По сравнению с прежним циклом сохранились 49 из 51 исправления и появились 63 новых. Два прежних исправления сменились запросом подтверждения на формулировках с вложенными `ln(sin(abs(RA)))` и `atan(1/sin(RE))`.

Независимый разбор покрыл 98 задач. С компилятором исправлены все 98 ошибочных стартов на них и 14 из 30 ошибочных стартов вне грамматики. В каждом режиме откат восстановил исходную программу в семи эпизодах с неверным черновиком на выходе из цикла. Шесть эпизодов общие для всех режимов. Запросы подтверждения в новых режимах пришлись на 9 правильных и 14 ошибочных стартов вне грамматики.

На диагностическом повторе старого набора успешных исправлений было 49, 65 и 109 соответственно. Проверки переходов и прежнего харнесса прошли 10 локальных тестов. Время и память PicoCalc в этом опыте не измерялись.
