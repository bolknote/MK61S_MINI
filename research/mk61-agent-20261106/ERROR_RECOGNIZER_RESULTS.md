# Отдельное распознавание ошибок МК-61: Q4

**Критик пока недостаточно надёжен для практического завершения задач.** Выбранные веса не прошли пороги качества.

Проведены два независимых варианта одного опыта: `head` обучает только 512 коэффициентов четырёх выходных строк; `adapt` дополнительно обучает 317 440 коэффициентов адаптеров внимания и MLP. Оба получают одни и те же учебные группы, с одинаковым порядком и балансом классов. Начальные веса — экспорт AN direct-research; основной генератор и его режим исполнения не заменялись.

Обучение: 4800 примеров, по одному из четырёх классов для каждого из 1200 условий. По 1500 шагов на двух B200, всего 3000 обновлений. Все прямые проходы обучения и все экзамены используют реальную сетку Q4; математика обучения FP32.

Классы: замена операции, ошибка аргумента, ошибка порядка команд, правильная программа. Ошибочный порядок сохраняет весь набор байтов команд и меняет их последовательность. Это отдельная проверка, а не подмена X² на X⁴. Все четыре кандидата успешно останавливаются; каждый неверный имеет контрпример среди трёх публичных исполнений ROM. Сверяются X и R0–RE. Остановка сама по себе не означает правильность.

Вход — русское условие, HEX, константы, публичные входы и фактические результаты эмулятора. Эталон, ожидаемые значения и скрытые тесты во вход не подаются. Выход — один из четырёх классов; этот опыт не обучает свободные рассуждения или исправление программы.

Ветка `adapt` и её шаг выбраны только по основной контрольной панели до открытия экзамена. Новые комбинации операций контролируются отдельно; их пары не встречались в обучении. На основном экзамене новые русские формулировки, регистры и константы знакомых семейств. Обе панели имеют точный баланс четырёх классов; постоянный ответ даёт 25% точности.

Отдельный расчёт постоянных инструкций

На 4800 учебных входах удаление повторяемых инструкций при сохранении динамического режима освобождает 268 токенов: медиана 724 → 456. FP32 KV занимает 5120 байт на позицию; при уменьшении выделяемого окна это 1,372,160 байт. При прежнем окне 1024 память не меняется, но появляется больше места для полезного состояния.

Для удаления инструкций нужен отдельный опыт с дистилляцией контекста и проверкой Q4. Предварительное вычисление KV не освобождает хранилище KV. В этом обучении формат не сокращался. [Первичное описание context distillation](https://arxiv.org/html/2112.00861v3#S2.SS1).
