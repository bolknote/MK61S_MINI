# Дообучение 3M Q4 на оставшихся 40 ложных DONE

Продолжены существующие LoRA rank16-факторы выбранного replay-адаптера finish-debug-v1, блок 4. Основание и компилятор сохранены. Архитектура, русский входной словарь, команды и HEX/FF-протокол не расширялись. После слияния каждый профиль по-прежнему содержит 3 022 080 параметров Q4.

Полный разбор сорока исходных эпизодов: [FORTY_FALSE_DONE_ANALYSIS.md](/Users/bolk/Projects/MK61S_MINI/research/mk61-agent-20261106/FORTY_FALSE_DONE_ANALYSIS.md).

| Причина | Эпизодов |
|---|---:|
| Неверная константа | 14 |
| Пропущенные команды | 6 |
| Заменённая операция | 5 |
| Порядок и структура выражения | 5 |
| Неверный регистр | 9 |
| Остановка и ветвление | 1 |

Всего 40 эпизодов и 39 разных задач. В 3 случаях сеть испортила верный старт. В 12 не пыталась переписать код. Все 40 провалов воспроизведены уже на публичных входах при офлайн-сравнении с эталоном; скрытых-only ошибок 0. Эталонные значения сами агенты не получают.

Обучение: 26,765 новых шагов, 576 адресных состояний сорока ошибок и их верных соответствий, 92,094 прежних шагов для сохранения навыков. Сгенерированы 1200 новых учебных задач по семействам ошибок с другими числами и регистрами. В каждой паре совпадают расписание запусков/ревизий и таблица констант; правильность кода различается. Часть таблиц переставлена согласованно со ссылками.

Balanced и focused получают одинаковые выборки: 16 из 64 строк каждого обновления посвящены сорока ошибкам и их положительным соответствиям. Остальные строки включают новые варианты, старые навыки и текущие ошибки учеников. У обеих веток вес потерь HEX-тела увеличен до 2. У focused дополнительно вес адресных строк равен 2, а исправляемых байтов и границ удаления в HEX-ответе — 4. Служебные части запроса не усиливаются. Для исправлений используется весь правильный ответ, а не отдельный правильный параметр. Дополнительного парного прямого прохода нет.

На последнем доступном действии учитель даёт DONE для уже верной проверенной программы и UNSURE для неустранённой ошибки. Это 80 сопоставленных состояний; ещё 128 обучающих состояний поддерживают отказ при неполном условии. Новых вызовов большой LLM не было: учитель — авторские программы и ROM-проверка, включая память и явные требования.

Выполнены 3 × 1200 обновлений каждой ветки, всего **7200**. Текущие ошибки обеих веток проверяются и объединяются между блоками. Q4 присутствует в каждом прямом проходе; перед SGD побитово сверены исходный пакет и все адаптируемые матрицы. Предварительная проверка выполнила 0 обновлений оптимизатора. Русские входные строки не обучались.

Новый контроль и экзамен зафиксированы до SGD и исключают точные тексты ранее использованных задач. Это новые формулировки/экземпляры знакомых семейств, а не неизвестные классы алгоритмов. Основной экзамен: 240 задач × верный/ошибочный старт = 480 эпизодов. Отдельно: 96 новых задач по семействам сорока ошибок (192 эпизода), 48 задач X²/X⁴ (192 эпизода) и 64 задачи с исходным компилятором. Старые сорок проверяются отдельно и не участвуют в выборе весов.

Это raw-решения самой сети. Успех требует правильного кода, DONE и всех успешных публичных запусков. Ни отказы, ни правильный код без завершения успехом не считаются. Семантический порог не запрещает DONE в основном экзамене; полный диагностический прогон с этим непригодным ранее фильтром не повторялся.

Два незавершённых старых эпизода отдельно воспроизведены нативным Q4:

- Построй вычисление для величины: ((R4) умножить на (R3)) минус (квадрат от (R4)). Регистры памяти оставь без изменений. Код верен, но сеть повторяет WRITE/RUN и не завершает задачу.
- Реши на обычном МК-61 следующее задание. Ограничь значение R4 интервалом от 0.1 до 1.1: ниже верни 0.1, выше верни 1.1, внутри верни само значение. Итог в X; память сохрани. Код не исправлен: повторяются определения метки, затем ответ обрывается на лимите генерации.
