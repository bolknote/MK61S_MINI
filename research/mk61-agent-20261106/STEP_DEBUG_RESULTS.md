# Пошаговая отладка и сокращение промпта: 3M Q4

По контролю знакомых и незнакомых сочетаний выбрана ветка **short**. Она пока не прошла объявленные исследовательские пороги нового экзамена.
Основной профиль генератора и прошивка не заменялись.

Подготовлено 30,000 учебных шагов на 1200 новых условиях; 29,998 шагов помещаются в оба формата. Из обеих веток исключены 2 слишком длинных примера. На каждой B200 выполнено по 2500 шагов, всего 5000 обновлений.

Обе ветки начинают с одного сохранённого чекпойнта выпущенной AJ lr10-terminal 3M HEX. Совпадают случайные выборки, оптимизатор, расписание, число обновлений и учитель; меняется только формат входа. Свежие адаптеры rank16 обучают внимание и MLP, а также строки действий и корректности. Всего 318,464 обучаемых коэффициентов; после слияния остаётся 3 022 080 параметров. Во всех прямых проходах используется реальная сетка Q4, обучение ведётся в FP32.

Учебные цели: составить HEX по условию; выдать локализованный диагноз; исправить программу после диагноза; продолжить после неудачной правки или ложного прежнего диагноза; запустить недостающие публичные случаи; завершить правильный проверенный код. Исправление неверного кода получает больший вес на изменённых токенах. Правильные программы включены как самостоятельные положительные примеры.

DIAG имеет пять байтов `TT HH LL AA BB`: тип ошибки, индекс в текущем HEX, текущий и предлагаемый байты. 00 означает правильный код, 01 — операцию, 02 — аргумент, 03 — порядок; правильный диагноз имеет вид `00 FF FF 00 00`. Диагноз является гипотезой сети. Harness показывает только реальный текущий байт и факты эмулятора. Он не сообщает, верен ли предложенный байт, и не блокирует DONE по скрытой проверке.

Учитель целей и диагнозов — генератор задач, компилятор эталонов и настоящий ROM. Большая LLM не вызывалась. Дополнительно замороженная исходная сеть получает полный вход; её распределения копируются только там, где предсказанное действие или токен совпадают с проверенной учебной целью. Это сочетание обучения по эталону и ограниченной дистилляции контекста, а не чистое копирование текущей слабой сети.

Новый экзамен: 640 состояний знакомых семейств и 320 состояний с удержанными сочетаниями операций. Все русские условия исключены из прежнего AO набора и не пересекаются между новыми частями. Незнакомые пары исключены из текущего обучения; это не утверждение об отсутствии их во всей истории предобучения. Для половины групп в исходном состоянии имеется заведомо неверный прежний диагноз, одинаковый у обеих веток. Экзамен содержит по одному правильному кандидату и по три вида ошибки на каждое условие.

Успех — правильный итоговый код на трёх публичных и трёх скрытых случаях, все публичные исполнения для последней версии и собственный DONE модели в бюджете 12 действий. Начальные факты трёх запусков предоставляются одинаково для всех готовых кандидатов. После WRITE прежние результаты аннулируются. Эталон и ожидаемые состояния используются только офлайн.
