# Свежий чекпойнт harness-debug-v3: качество трёх режимов

Заменяет использование старой модели из v7 для актуального вывода. Проверен последний завершённый выбранный снимок из чата «Harness на PicoCalc»: selected-budget, active-best, шаг 1500. Новый цикл обучения с другим action-протоколом в момент заморозки не завершён. Чекпойнты не смешивались.

3 022 080 параметров, Q4, 1024 токена, 8224 входных и 40 разрешённых выходных токенов. Родной prompt и инструменты взяты из harness-debug-v3. Новые native-генерации совпали с 13 контрольными генерациями проверенного экспорта как без KV-префикса, так и с повторным использованием префикса: 26/26.

Результат — по **1101/1175** у LUT_FLOAT32, INT8 и SWAR+INT8. Среди новых задач у каждого режима 256/282; у INT8 две потери и два выигрыша относительно LUT. На командах 648/648, на прежних формулах 69/98, на пользовательских примерах 27/27, на отладке 55/72, с пустого листа 46/48. Ложных DONE по 19 в 120 инструментальных сценариях. Не все случаи являются независимыми задачами: отдельные панели проверяют разные старты и способы выполнения одних условий.

SWAR и INT8 дали идентичные функциональные записи во всех 1175 случаях. Суммарное качество INT8 не снизилось; строгий критерий сохранения каждого базового решения не пройден. Default и LUT не менялись. Отдельных аппаратных обращений и обучения нет.

[Подробный отчёт](../../../doc/measurements/picocalc-ai-int8-fresh-20261107.md). `paired-report.json` содержит итог и идентификаторы потерь/выигрышей; `changed-cases.json` — соответствующие prompts, ответы, токены и программы; отдельные каталоги `run-*` — сводки. `manifest.json` фиксирует модель, исходники и наборы, `compatibility.json` — совпадение с проверенным native/B200 экспортом.

В `.build/mk61ai/int8-quality-v8/` сохранены полные JSONL всех трёх прогонов, истории инструментов, замороженные runtime и эмулятор, MKA и ниббловый MKA. Источник весов: `.build/mk61-agent-20261106/harness-debug-v3/server-results/export/selected-budget/`. Их SHA указаны в манифесте; повторного квантования не было.

Скрипты здесь — точные копии выполненного эксперимента. Они рассчитаны на отдельный рабочий каталог `.build/mk61ai/int8-quality-v8`, фиксированные источники и однократное создание выходных файлов. Это не установщик для запуска из research-каталога; для нового прогона используйте отдельную копию рабочего каталога с новым манифестом, не перезаписывая исходные результаты.
