# Промежуточный результат M0+: квалифицированная R55

Сохранено состояние после checkpoint `2fdfa81f9`: исходники R53/R54/R55, завершённая авторская квалификация R55, доказательства новых сокращённых веток `pow`, все результаты и стоимость эталонов. Выбранный частный кандидат — R55. R53 и R54 отвергнуты из-за новых отставаний от корректного Qfplib; их результаты сохранены.

| Изменение | Подтверждённый результат |
| --- | --- |
| R55: раннее насыщение `pow` | На расширенном конечном объединении отставаний 1886 → 1452: исправлены 434 пары. На прежнем корпусе R52 — 1778 → 1410, исправлены 368 пар. |
| Дополнительные проверки | 522 свежие пары диагностики источников, из них 504 новые пары / 1512 состояний добавлены в admission. Новые эталоны и стоимость R52 получены отдельной диагностикой, а не из результатов самой R55. |
| Точность и сравнение | В сохранённых проверках нет новых ошибочных результатов кандидата и новых отставаний от корректных результатов Qfplib. Все корректные эталоны сравниваются; ошибочные выходы Qfplib и их стоимость сохранены. |
| Увеличения относительно R52 | Все сохранены: full `pow` — 11850 строк, admission — 213, primary original507 — 38 для кандидата и 38 для нулевого контроля, broad — 1084 и 1084. Это увеличения на отдельных путях; они не скрыты результатом общего улучшения. |
| `exp` и `ln` | Выходы и число инструкций точны относительно R52, на сохранённых конечных корпусах отставаний нет. |
| M4 и обычный M0 | Выделенные байты, символы и смысловые релокации сохранённых объектов точны. В двух изменённых объектах неизменённые секции проверены отдельно. |
| Размер | `.text` +32 байта, код `.scratch_y` −8, суммарно +24. Новых таблиц, глобальной RAM и libgcc нет. |

Квалификация R55 выполнила 2123149 свежих публичных ARM-вызовов: 1987721 кандидата, 61286 нулевого контроля и 74142 Qfplib в первичной матрице. Первичная матрица использует 30643 свежие оценки эталона. Большие корпуса используют закреплённые значения и стоимость Qfplib из R52; добавленные края — свежую диагностику источников. 17631 вызов диагностики источников не добавлен к числу вызовов квалификации. Доказаны новые предикаты насыщения, проверены 64 новых и 68 прежних отрицательных ELF-контролей. Это не универсальное доказательство корректности всей библиотеки.

В конечном объединении осталось 1452 известных отстающих пары `pow`: 721 для обратного квадратного корня, 236 с результатом ноль/бесконечность, 495 с нормальным результатом. Это не универсальный перечень проблем. Метрика — исполненные инструкции Thumb; физические такты не измерены. Замеченный максимум стека — 2284 байта, универсальная граница открыта.

Сохранён незавершённый HOST-черновик стенда: отдельные математический и Qfplib ELF перелинкованы в SRAM. Это только математические блоки, ещё без загрузочного кода и USB-протокола. Адресные области linker script требуют уточнения; выходы, ABI, релокации и число инструкций новой RAM-компоновки ещё не проверены. Запускаемого на плате стенда и аппаратных результатов в checkpoint нет.

Открыты универсальное корректное округление, завершимость общего `pow`, приёмка FMA, универсальный стек, физические такты, независимая приёмка и внедрение. `scope.json` задаёт текущие утверждения. Исторические `pending` в документах источников сохранены дословно и уточняются завершённой квалификацией.

Проверка архива:

```sh
python3 verify_checkpoint.py --records
```

Потребитель использует стандартную библиотеку Python: сверяет SHA-256, исходные FROZEN и пересчитывает сохранённые записи. Он не импортирует и не запускает производителей, ARM, MPFR или устройства. Для проверки связи с родителем сохранена квалификация R52; данные её предыдущего checkpoint повторно не объявляются новыми проверками.

`provenance.json` связывает исходные пути с адресованными хэшем файлами `payloads/`. Байты сохранены; имена совместимы с Windows и уникальны без учёта регистра. Скомпилированные двоичные файлы опущены с сохранением размеров и хэшей. Производственный runtime этим коммитом не изменяется.
