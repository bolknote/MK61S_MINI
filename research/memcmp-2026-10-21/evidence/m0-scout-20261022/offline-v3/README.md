# V3: только офлайн, скорость не измерена

1032 байта. Короткий путь v2 дополнен выровненным четырёхбайтным случаем
и ранней проверкой перед обработкой одинаково невыровненных входов.
Проверенные байты исключаются из следующего цикла. M4 остаётся прежним.

source.patch применяется к изолированному checkout после
m0-prepared/prototype.patch. Патч меняет candidates.S и сгенерированный
memcmp_m0.inc. Самостоятельная ARM-проверка own64: 53357 случаев PASS.
Точный Flash payload дополнительно исполнялся для baseline/own4/own16/
own64/memcmp, memcpy и memmove. Хеши, ELF и четыре APP сохранены рядом.

Ни одна V3 APP или Flash payload не запускались на устройстве. Положение
0x101E0000 ещё не проверено как свободное на принятой базе. Имя prepared
не означает выбор алгоритма или аппаратное подтверждение его скорости.
Для следующего опыта использовать актуальный run.py: он заранее сохраняет
private before-снимок и пишет результат/транскрипт даже при отказе cleanup.
