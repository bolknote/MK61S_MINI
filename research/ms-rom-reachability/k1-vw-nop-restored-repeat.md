# Два непрерывных вызова восстановленной перестановки: отрицательный контроль

2026-09-26. Запуск:

```sh
node tmp/ms-rom-reachability/k1-vw-nop-restored-repeat-check.cjs
```

Драйвер `k1-vw-nop-restored-repeat.cjs` делает ровно два вызова
`k1-vw-nop-restored.finish` на одном калькуляторе. Между вызовами нет
сброса, загрузки состояния, синхронизирующих getters, выравнивания или
добавленных кадров ожидания. Демонстрационные ручной расчёт и программа
отключены (`verifyExit:false`). Снимки границ пассивные. ПЗУ и оба ядра
не изменены.

## Результат

Первый вызов успешно возвращает все 23 исходных числа в хранимые слова:

```
ordinary P0 = w
Ms U/V/W/Q = u/q/v/p
upper = a/b/c/d
extra markers = none
native frame phase at exit = 168
```

Фиксированная перестановка первого вызова совпала с ожидаемой. Второй
вызов завершился, но её квадрат не получился: числовые данные повреждены,
в Ms U остался дополнительный маркер.

Первая наблюдаемая граница отсутствия исходных слов:

```
repeat/1/entry/after-0     physical phase 0
```

Ей предшествовало действие `repeat/1/entry/tail-1`: второй `F ,` раннего
`k1-visible-marker-repack`-префикса. До него все исходные слова ещё
находились среди хранимых и видимых регистров. После него одновременно
не найдены:

| Исходное место | Raw 12 тетрад | Значение | Место непосредственно перед действием |
|---|---|---|---|
| Ms V | 983998765432 | -9.8765432E-17 | Y |
| Ms W | 977976543210 | -7.654321E-23 | X1 |
| Ms Q | 958912345678 | -1.2345678E-42 | X |

На следующей границе X и X1 равны `002020100000` (201), а Y равно
`252020100000`. Программа и служебные тетрады не менялись ни на одной
из 368 наблюдаемых границ. Исключений клавиатурного протокола не было.

## Что это устанавливает

Нельзя считать найденную одноразовую перестановку непосредственно
повторяемой: данный фиксированный непрерывный повтор не сохраняет
данные уже в раннем префиксе, до нового K0/K×-участка.

Первый выход меняет одновременно числовое содержимое входных мест и
аппаратную фазу следующего входа. Этот опыт не разделяет их вклад и не
доказывает, что никакая согласованная композиция невозможна. Фазовые
варианты после отказа не исследовались.

Граница отсутствия — кадровая, а не точная микрокоманда записи.
Проверялись 23 хранимых слова и X1/X/Y/Z/T; наличие копий в иных
внутренних регистрах микросхем не исключено. Это не доказательство
глобальной необратимости или невозможности К1.
