# ENTER из W: флаги не позволяют убрать видимый подъём

26 сентября 2026. Структурная проверка исходного ПЗУ ИК1302;
клавиатурного перебора или подстановки состояния в живой эмулятор нет.

## Вопрос

В новой раскладке после NOP и RCL0:

```
П0=w; U=v,V=m,W=a,Q=p; верхние w/b/c/d;
X=w,Y=1,Z=u,T=q; X1=INV0.
```

W содержит теперь **единственный хранимый a**, П0 дублируется верхним
P7, а q остаётся единственно в T. Можно ли ENTER прочитать a из W,
изменив внутренние флаги так, чтобы не вытолкнуть q?

## Ответ для настоящего пути ENTER: нет

Прежний `k1-v-q-backup-path-check.py` ограничивал ENTER условиями
R23=R26=R29=0. **Эти ограничения оказались избыточны**, а не скрывали
подтверждённую альтернативную ветвь.

Новая проверка сначала устанавливает более сильный факт об отдельной
команде E0: при любых остальных регистрах, S1, адресном стеке и сигналах
клавиш она **всегда переходит в A7**, удерживает все 12 тетрад A и не
пишет кольцо. Это не только свойство состояния, произведённого EE.

Затем полностью проверен связанный реальный суффикс:

```
EE(W) -> E0(Q) -> A7(P7)
-> E5(P8) -> E5(P9) -> E5(P10) -> E5(marker)
-> E6(control) -> E8(X1)
-> E7(X) -> A8(Y) -> A8(Z) -> A8(T) -> A9(U) -> E1(V)
```

Предпосылки: EE на физической W, S1=13, адресные возвраты
`[E0,8E,9A]`; P8/P9/P10 не являются метками, штатная метка присутствует.
V тоже помечена, но сканер достигает штатной метки раньше и V не читает.
Остальные данные и все R23/R26/R29 свободны. Полные W/X/Y/Z/T —
произвольные 12-тетрадные слова, без ограничения мантисс или порядков.

Результат неизбежен:

```
X <- W=a; Y <- старое X=w; Z <- старое Y=1; T <- старое Z=u.
```

Ровно 48 числовых тетрад записываются в X/Y/Z/T. Остальные тетрады
кольца, включая M1/M3 и служебные, этим первичным суффиксом не меняются.
Старое q из T полностью попадает в A перед A9. Затем A9 оставляет
десять его тетрад, но заменяет два старших поля порядка на свои R32/R35.
Это не готовый полный резерв q для последующего возврата.

## Предел вывода

Для захвата a этим ENTER необходимо сначала сохранить q вне T либо
изменить сам вход/адрес возврата EE. **Подбором только флагов E0/ENTER
ветку без A7 получить нельзя.**

Это не доказательство невозможности полной К1 или любого другого
микропрограммного читателя. Не утверждается невозможность восстановления
q из всей совокупности внутренних полей трёх микросхем. Отдельно остаются
клавиатурное достижение исходного EE(W), действия других микросхем и
поздний форматировщик после E1. Локальный ROM-договор не подменяет
полную нативную трассу этих частей.

Проверка:

```
python3 tmp/ms-rom-reachability/k1-enter-no-push-check.py
```

Все проверки прошли. Эмулятор, ПЗУ и старые проверяющие файлы не менялись.
