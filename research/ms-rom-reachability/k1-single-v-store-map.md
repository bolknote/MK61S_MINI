# Обычный STORE при единственной ложной метке V

26 сентября 2026. Структурная карта исходного ПЗУ ИК1302, без нового
клавиатурного перебора. Настоящая метка сохранена; дополнительные
T/W-метки отсутствуют. V — единственная ложная M22=F.

## Полезный ответ

**Видимый X можно условно записать в настоящий обычный П0 командой
`X→П 7` (47h).** Нужно, чтобы принятое управление 9C находилось в
одной из физических позиций `Z/T/U/V/W/Q/P7`. Тогда ранняя EE читает X,
а адресный поиск 01 отсчитывает обычный регистр от ложной V.

При принятом 9C в остальных восьми позициях ранняя EE читает Ms P7,
а обычный регистр выбирается без смещения. Тогда запись в настоящий
П0 — это код 40h, но он сохраняет **Ms P7**, не видимый X.

Это два разных пути исходного ПЗУ, не изменение эмулятора. В текущем
нативном состоянии после deep→NOP→RCL0 значения X и P7 совпадают (`w`),
поэтому по одному записанному числу источник не различить: нужен
физический адрес EE из трассы.

## Предпосылки принятого 9C

Перед 9C ожидается код 4i: `R30=i`, `R33=4`. Текущее слово должно
удовлетворять настоящему условию приёма:

```
M34 >= (M31 == F ? 1 : 7)
```

Карта классифицирует **уже принятое** слово, а не произвольное место,
на котором сканер только проверяет этот предикат. Какую именно позицию
выберет конкретная кадровая привязка клавиш, локальный договор не
определяет. Для текущих чисел допустимы, в частности, T=q, U=v, V=m,
W=a и P7=w — все относятся к семейству чтения видимого X. Принятые
control, X=w и P8=b относятся к семейству чтения Ms P7.

## Два связанных маршрута в П0

Видимый X, код 47h:

```
9C(T) → 9E(U) → 9F(V) → AA(W)
→ E5(Q/P7/P8/P9/P10/real) → E6(control) → ED(X1) → EE(X)
→ AB(Y) → AD(Z) → A4(T) → 01(U/V)
→ 02(W/Q/P7/P8/P9/P10/real/control)
→ 03(X1) → 04(X) → BA(Y) → CB(Z) → DD(T) → D4(U) → A5(V)
```

Все 32 связанные команды проверены для произвольных 12 тетрад X,
остальных данных и сигналов клавиш. До D4 кольцо не меняется. D4
записывает только 12 числовых тетрад обычного П0 в M1; Ms, программа
и служебные поля не затрагиваются этим суффиксом.

Ms P7, код 40h:

```
9C(control) → 9E(X1) → 9F(X) → AA(Y)
→ E5(Z/T/U/V) → E6(W) → ED(Q) → EE(P7)
→ AB(P8) → AD(P9) → A4(P10) → 01(real) → 02(control)
→ 03(X1) → 04(X) → BA(Y) → CB(Z) → DD(T) → D4(U) → A5(V)
```

## Карта кодов адреса

| Код | При EE(P7): настоящий регистр | При EE(X): настоящий регистр |
|---|---|---|
| 40 | П0 | П8 |
| 41 | П1 | П9 |
| 42 | П2 | A |
| 43 | П3 | B |
| 44 | П4 | C |
| 45 | П5 | D |
| 46 | П6 | E |
| 47 | П7 | П0 |
| 48 | П8 | П1 |
| 49 | П9 | П2 |
| 4A | A | П3 |
| 4B | B | П4 |
| 4C | C | П5 |
| 4D | D | П6 |
| 4E | E | П7 |

Ошибочная семья поэтому не просто читает другое число: код 47 при
EE(P7) перезапишет настоящий П7, а код 40 при EE(X) — настоящий П8.
Нельзя проверять этот выбор только совпадением П0 или дисплея.

## Что это даёт для резерва u/q

Путь пригоден как условный односоставный писатель `X → П0` без подъёма
стека, E9 или запроса A3. Поэтому если u/q уже безопасно доведены до
видимого X, обычное П0, освобождённое дубликатом w в Ms P7, действительно
может принять полный резерв.

Сам STORE не читает Z или T. На текущей раскладке `X/Y/Z/T=w/1/u/q`
он ещё не спасает q/u непосредственно; нужен сохраняющий способ
подать выбранное число в X. Полный клавиатурный вызов также включает
позднее форматирование после доказанного возврата A5. Его безопасность,
выбор кадровой фазы и поведение других микросхем требуют нативной трассы.
