# Кадровая диагностика K0 и K0 → K× после сохраняющего SIGN

2026-09-26. Независимые свежие клавиатурные запуски через
`k1-frame-boundary-probe.cjs`; ПЗУ и эталонный эмулятор не изменялись.
Это запись наблюдаемых состояний, **не проверка полной трассы записей**.

## Исходное состояние после deep SIGN

Использован `k1-repack-deep-clone-probe.cjs` с его defaults.
Обозначения — исходные Ms `u/v/w/q/a/b/c/d` и исходный обычный P0 `p`.

```
p = 002020100000  (201)
u = 007912345678  (-12345678)
v = 983998765432  (-9.8765432E-17)
w = 977976543210  (-7.654321E-23)
q = 958912345678  (-1.2345678E-42)
b = 003090220000  (9022)
c = 003090330000  (9033)
d = 003090440000  (9044)
m = 9990FFFFFFF0
one = 000010000000
INV0 = 00008FFFFFFF
```

После SIGN, перед исследуемым продолжением:

```
ordinary P0 = w; остальные 14 обычных регистров исходные
X1 = INV0; X/Y/Z/T = one/u/q/m
Ms U/V/W/Q = v/m/m/p
Ms P7/P8/P9/P10 = a/b/c/d
physical marker = 000FFFFFFFFF
control = 3F9000000000
```

## Один K0: две серии по трём фазам

Каждый опыт начинался с нового калькулятора и полного клавиатурного
префикса. Вызов:

```js
frame.run(deep, {
  // Для короткого a дополнительно:
  // fullUpper: ['-1E-99', '9022', '9033', '9044'],
  afterClonePhase: phase,
  afterClone: [['K', '0']],
});
```

В первой серии `a=9011`, raw `003090110000`; во второй
`a=-1E-99`, raw `901910000000`.

| a | Дополнительные кадры | Физическая фаза перед K0 | Все итоговые изменения кольца | Исходные слова |
|---|---:|---:|---|---|
| 9011 | 0 | 84 | P8: b → one | b отсутствует |
| 9011 | 1 | 168 | X: one → a | Все 23 найдены |
| 9011 | 2 | 0 | X: one → a | Все 23 найдены |
| -1E-99 | 0 | 84 | P8: b → one | b отсутствует |
| -1E-99 | 1 | 168 | W: m → a | Все 23 найдены |
| -1E-99 | 2 | 0 | W: m → a | Все 23 найдены |

В положительных случаях все 23 исходных слова найдены на каждой
наблюдаемой границе действия, включая немедленный результат и результат
после трёх дополнительных кадров. Во всех шести опытах обычные регистры,
программа и служебные тетрады между границами до/после K0 совпадают.
В отрицательных случаях отсутствие b начинается с границы `immediate`
и сохраняется на `done`.

Короткий a не удаляет видимый T-маркер: он удаляет **Ms W-маркер**.
Подъёма видимого стека на конечной границе нет; это ещё не доказательство
отсутствия промежуточного подъёма или E9 — для этого нужна полная трасса.

## K× после короткого a и сохраняющего K0

Использован `k1-vw-nop-read.cjs`:

```js
frame.run(nop, {
  fullUpper: ['-1E-99', '9022', '9033', '9044'],
  nopLeadPhase: 1,
  afterNop: [['K', '×']],
  afterNopPhases: [phase],
});
```

Все три опыта — свежие независимые запуски. Непосредственно перед K×
состояние такое же, как выше, но W=a.

| Дополнительные кадры | Физическая фаза перед K× | Все итоговые изменения кольца | Исходные слова |
|---:|---:|---|---|
| 0 | 168 | V: m → one; control: 3F9000000000 → 280000000000 | Все 23 найдены |
| 1 | 0 | X1: INV0 → a; U: 983998765432 → 281998765432 | v отсутствует |
| 2 | 84 | V: m → one; control: 3F9000000000 → 280000000000 | Все 23 найдены |

В положительных случаях все 23 слова сохраняются на всех наблюдаемых
границах. Во всех трёх опытах обычные регистры, программа и служебные
тетрады между границами K× совпадают. Отрицательный опыт теряет v на
`immediate` и `done`; это не доказательство его необратимой утраты из
всех внутренних регистров микросхем.

Точная положительная конечная раскладка:

```
ordinary P0 = w; остальные 14 обычных регистров исходные
X1 = INV0; X/Y/Z/T = one/u/q/m
Ms U/V/W/Q = v/one/a/p
Ms P7/P8/P9/P10 = a/b/c/d
physical marker = 000FFFFFFFFF
control = 280000000000
```

Обе Ms-метки сняты. Но T остаётся маркером, u/q существуют только в
видимых Y/Z, а W содержит дубликат a. Обычный 23-словный контракт
хранения не восстановлен; чистый выход и полный К1 не достигнуты.

## Границы свидетельства

- Диагностика сравнивает все 630 тетрад на кадровых границах; она не
  проверяет промежуточные записи между ними.
- Отсутствие слова проверялось среди 23 хранимых слов и X1/X/Y/Z/T,
  а не во всём внутреннем состоянии микросхем.
- Числовая универсальность, отсутствие E9, неизменность полей на каждом
  внутреннем такте и повторяемый нормальный выход здесь не доказаны.
- Смысл фаз — точное число кадров данного драйвера, не готовая методика
  задержек для физического калькулятора.
- Дополнительные команды после этих выбранных ветвей не проверялись.
