# Математика M0+: R64 и завершённое аппаратное сравнение

Сохранён частный математический кандидат R64, его доказательства, удачные и отвергнутые попытки, полные записи HOST и четырёх физических партий. Предыдущий архив R63 не изменён. Этот checkpoint не заменяет производственную библиотеку и не меняет выбранный provider.

| Проверка | Результат |
| --- | --- |
| Прежний HOST-корпус | 152937 пар / 324446 состояний. Отставания R63 → R64: 1400 → 1398, новых отстающих состояний нет. |
| Оставшиеся HOST-отставания `pow` | Обратный корень — 721 пара; нормальный результат — 481; ноль/бесконечность — 196. |
| Ухудшения HOST относительно R63 | Все 7658 состояний сохранены, максимум +14 инструкций. |
| Физическая матрица | 28 пар / 84 состояния каждой версии, 6960 вызовов вместе с Qfplib и калибровкой. Наши 1680 вызовов верны. |
| R64 против R63, такты | 39 состояний быстрее, 18 равны, 27 медленнее. Диапазон разницы −4135…+40 тактов; все ухудшения сохранены. |
| R64 против быстрейшего корректного Qfplib | 24 состояния быстрее, 45 медленнее, в 15 нет корректного Qfplib. У R63 было 12 / 57 / 15. Новых отставаний нет. |
| Эталоны | Все 3060 неверных вызовов Qfplib сохранены с выходами и тактами. Выходы и 252 медианы Qfplib между версиями точны. |
| Размер | R64 +104 байта кода относительно R63; новых таблиц и глобальной RAM нет. Контроли объектов M4/обычного M0 сохранены, полной новой сборки M4 нет. |
| Возврат PicoCalc | 12 полных чтений Flash по 2 МиБ совпали; штатная D6, данные, настройки и UI возвращены. Аппаратное окно закрыто. RTC_SET=0, точное продолжение хода часов не утверждается. |

Инструкции HOST и физические такты — разные метрики. Оба корпуса конечны; универсальное корректное округление всей библиотеки, завершимость общего `pow`, граница стека, приёмка FMA и внедрение остаются открытыми. Наблюдённый стек этой физической матрицы: R64 1096 байт, R63 1088 байт; это не универсальная граница и не замена прежнего максимума 2276 байт в более широких проверках.

Проверка без устройства, ARM, MPFR, SDK и внешних `.build`:

```sh
python3 -I -B verify_checkpoint.py --records
```

Потребитель проверяет архивные SHA-256, исходные FROZEN, заново пересчитывает HOST и физические записи. Сырые wire сохранены побайтово; их отдельная независимая проверка подтверждена архивным Root receipt. Для конечных результатов требуется побитовое совпадение; quiet NaN сравниваются по исходному правилу квалификации без требования одинакового знака и payload, исходные биты сохранены. Исторические скрипты, grants и команды являются данными и не исполняются проверкой.

Исходники можно извлечь в новый каталог командой `python3 -I -B verify_checkpoint.py --extract-candidate НОВЫЙ_КАТАЛОГ`. ELF, объектные файлы, образы и полные Flash исключены из Git с сохранением размеров и SHA-256; точная привязка source/ELF/raw задана исходными FROZEN, `provenance.json` и Root reviews. Рецепты сборки сохранены; SDK и компиляторы не включены. Неудачная опечатка shell до последней проверки и C5-only HOLD сохранены отдельно от успешных аппаратных этапов.
