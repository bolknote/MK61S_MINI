# M4 strchr operator HOST package

This is preparation for the separately queued Classic/M4 window. It is **not
a hardware Go**, a physical timer qualification, a timing result, or an
implementation winner. The original 75-pin HOST package is unchanged. No
recurring automation is created or used.

The coordinator fixed this order on 2026-10-30: the current Bytecode campaign
and its complete accepted return, then the previously promised MK85 Runner
window and return, then strchr. This chat supplies and executes strchr after
fresh exact acceptance. M0+ remains independent, after Math's mandatory return
and the earlier strlen/strcmp/strncmp queue.

## What is ready on HOST

`prepare.py` binds a *template* to a sealed resident ELF/BIN. It verifies the
26-slot runtime table and its real slot18, and extracts nine already qualified
leaf bodies. A guarded 1152-case fixture is a separate raw overlay recipe in
the erased tail of internal512KiB Flash. The sealed resident prefix, footer,
runtime table, unrelated tail and legacy settings remain byte-exact. It does
not change the resident's CRC length. Programming a physical overlay requires
an accepted fresh full snapshot, proof that every destination byte is FF,
accepted programming/reset/RTC suppliers and complete physical readback. An
old physical observation or this synthetic FF-tail example cannot supply any
of those facts.

`build.py` produces four actual SDK APPs: standalone/shared runtime, each
with candidate code in SRAM/Flash. They use ordinary public FILE_RESOLVE,
file_size/file_read and FILE_WRITE services. Every invocation reads the owned
`INPUT.bin` and writes one 3584-byte `RESULT.bin` in the same directory. It
does not draw, reset, mask IRQs, configure clocks, touch USB or relaunch itself.
The maximum loaded image is15148bytes, below the existing20480-byte APP cap.
The production parser/decoder and the pertinent public API/SDK/MPU sources
are byte-exact to the source28 handoff; final actual release must be rebound.

The request includes a fresh nonce, finite batch index and frozen six-word
clock/cache/FPU context. Each of the1152cases retains seven unmodified raw
intervals for11targets: native/SDK/newlib controls, six candidates, actual
public SDK strchr and the actual runtime18 pointer. Operand SRAM/Flash, code
SRAM/Flash and public runtime/standalone routes remain separate. No empty-call
subtraction is used. Timing never includes file transfer or report writes.

Repetitions are deterministic16384/(decisive_offset+16), or length+16 for a
miss, within1..4096. The actual table is frozen only after the timer/context
qualification succeeds under the accepted scenario. It is never enlarged or
repeated after a failed group. Ten rows fit one report:116timed APP invocations
per mode,464total plus four qualification invocations. `WORKFLOW.json`
enumerates all473external jobs including capture/install/cleanup/return.

The APP temporarily enables DWT/DEMCR, never resets CYCCNT, compares it against
the public wall timer for a bounded8ms probe, and restores both configuration
words on every tested error path. An independent iteration bound also stops
when both timers stop. The nominal96MHz compile-time value is not physical
clock evidence; actual RCC/power/IRQ/cache and timer qualification remain
mandatory. A first fault preserves the complete raw report and first faulty
sample, and stops all later searches. Reading that saved result must never
run the APP again.

`model_test.py` uses synthetic ticks only. It executes all four real packed
APPs, including the production decoder, actual INIT/RUN/startup and slot18
forwarding, and injects input/timer/context/result/replay failures.
`placement_test.py` separately qualifies the new Flash addresses/literal
pools and actual native placement against the1152case matrix, with observed
read/control-flow envelopes, read-only inputs and AAPCS preservation. This is
new-placement coverage, not a repeat of the old620640-call campaign.

`workflow.py` creates the finite scenario/argv template and rejects missing,
stale or inconsistent physical bindings *before* lease/process/device access.
`supervisor.py` records actual child PID, session, process group, EXIT, reap,
group disappearance, logs and this process's FD inventory. It attaches only
to a provided existing lock and records its actual inode/FD/release. It never
creates a competing hardware lease. Timeout, nonzero exit, excessive output
or surviving children yield HOLD with no retry. `workflow_test.py` checks the
guards and these real HOST process/lock lifecycles using only local Python
children. Its synthetic receipts are explicitly HOST fixtures, not grants.

## What is deliberately unbound before the release

The physical adapters for capture, ROM programming/full readback, terminal
APP/file flow, cleanup and complete RTC/state/firmware return must be the
source-reviewed qualified suppliers accepted for the *actual* released device.
This package does not replace them with an unqualified port opener, reset,
OFFER bypass, USB probe, retry loop or RTC helper. No physical execution CLI
is enabled while those adapters/argv/lease are unbound. The exact adapter
implementations and all imports must be pinned and negatively tested before
Root accepts the final physical Go. `validate_binding` checks consistency;
it cannot make a locally fabricated JSON into coordinator authority.

Before the first physical action, bind fresh predecessor CLOSED receipts,
actual identity/ELF/BIN/profile/source and full snapshot, clock/power/IRQ/cache,
qualified timer and repetition table, explicit preservation of files/cache/
typed context/RTC, exact supplier argv/dependencies, finite window/lease and
Root Go. If the actual resident has changed, create a separate new template,
APP build and required delta tests; never rewrite this package or the old
frozen evidence. A reset is allowed only by the actual accepted context/return
recipe. Unknown or nonexportable context cannot be assumed disposable.

Execute the accepted jobs once. Save every request, complete raw report and
transport bytes before parsing, including the first failure. A readback error
stops measurement; it does not authorize another APP invocation. Only an
explicitly preaccepted finite return, or fresh coordinator recovery Go, may
follow a fault. Restore the full original image, original files/cache/typed
context and RTC/elapsed state, release all processes/FDs/locks, then request
independent Root CLOSED. The executor cannot certify its own CLOSED.

## Selection and integration after physical results

Keep separate regression maps for all lengths (especially0..16), alignments,
hit/miss/NUL/truncated-int cases, operand banks, code placement, SDK/runtime
route and actual clock/IRQ/cache context. Preserve all seven raw values and
repeats. HOST wall time and synthetic ticks are never device performance.

Choose the fastest feasible implementation from accepted physical groups,
then verify the actual native/SDK/runtime bodies and their real alignment,
complete firmware builds and all affected System APP budgets. F401 Classic's
existing4096-byte Flash reserve floor must not be weakened. A different
production placement or clock cannot inherit a speed claim solely from a
copied aligned leaf. Finish M4/M0+ independently in coordinator order,
integrate only this chat's completed code and clean only its own worktree;
foreign main WIP and protected strlen-hardware-fast remain untouched. No
push or release is part of this task.
