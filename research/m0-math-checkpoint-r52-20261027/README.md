# Промежуточный результат M0+: квалифицированная R52

Сохранено состояние после checkpoint `dda1627de`: полные авторские проверки R49, R50 и R52, исходники R50/R51/R52, доказательства и записи всех результатов. Выбранный частный кандидат — R52. Промежуточная R51 отдельно не проходила полную связанную проверку и не выбиралась.

| Изменение | Подтверждённый результат |
| --- | --- |
| R49: новый `exp` | Полная связанная проверка завершена. На 568856 входах / 1224907 состояниях нет отставаний от корректных результатов Qfplib; раньше было 512. |
| R50: вход `pow(x, -0.5)` | Отставания `pow` в конечном объединении: 2045 → 1960. Все увеличения относительно R49 сохранены: 346 строк полного `pow` и 9 строк admission, по 4 инструкции. |
| R52: частное от центрального коэффициента и произведение с малым знаковым множителем | Отставания `pow`: 1960 → 1778; для `x⁻⁰·⁵`: 903 → 721. На проверенных строках нет новых ошибок, отставаний от корректного Qfplib и увеличений относительно R50. Нормальная ветка быстрее на 1–20 инструкций; остальные показатели и холодные пути не изменились. |
| `exp` и `ln` в R52 | Выходные значения и число инструкций точны относительно R50. Отставаний нет на сохранённых конечных корпусах. |
| M4 и обычный M0 | Сохранённые объекты точны по выделенным байтам, символам и смысловым релокациям. |
| Размер R52 | Группа `pow` меньше на 40 байт относительно R50. Новых таблиц, глобальной RAM и libgcc нет. |

В квалификации R52 выполнено 2121637 свежих публичных ARM-вызовов: 1986209 кандидата, 61286 нулевого контроля и 74142 Qfplib в первичной матрице. Первичная матрица использует свежие проверки MPFR / точных случаев (30643 вычисления эталона). Большие корпуса `pow`, `exp`, `ln` используют закреплённые значения и стоимость эталонов из R50; это явно отмечено в записях. Диагностика исходников не добавлена к числу вызовов квалификации. Максимум стека, замеченный в прогоне, — 2284 байта; универсальная граница не установлена.

Сравниваются все корректные результаты Qfplib. Сохранены также ошибочные результаты эталона с их стоимостью и все увеличения относительно родителей, включая уже медленные строки. У R49 `exp` имеет 809101 строк с увеличением относительно R48; эти результаты не скрыты. Политика возвращаемых значений: binary64 RNE, постепенный underflow, знаковый ноль и согласованный quiet NaN. Метрика — исполненные инструкции Thumb, не аппаратные такты.

Сохраняется и новое исследование целочисленной оценки насыщения `pow`: оценка допускает 410 пар из 16740, включая 317 текущих отстающих. Это только анализ сохранённых эталонов; код не реализован, ускорение не измерено, эти пары ещё не исправлены.

Остаются универсальное корректное округление, завершимость общего `pow`, приёмка FMA, универсальная оценка стека, физические такты, независимая приёмка и внедрение. 1778 — число известных отстающих пар в текущем конечном объединении, а не полный перечень всех проблем библиотеки. `scope.json` задаёт область актуальных утверждений. Исторические `pending` в документах фазы исходников не переписаны; их состояние уточняют завершённые квалификации.

Проверка архива:

```sh
python3 verify_checkpoint.py --records
```

Потребитель использует стандартную библиотеку Python, сверяет SHA-256, исходные FROZEN и пересчитывает сохранённые записи. Он не импортирует и не запускает производителей, ARM, MPFR или устройства. Архивная проверка автономна. Для повторного запуска исторических производителей потребуются указанные в них инструменты и зависимости.

`provenance.json` связывает исходные пути с адресованными хэшем файлами `payloads/`. Исходные байты сохранены. Имена совместимы с Windows и уникальны без учёта регистра; `.gitattributes` сохраняет байты. Скомпилированные двоичные файлы опущены с сохранением размеров и хэшей. Производственный runtime этим checkpoint не изменяется.
