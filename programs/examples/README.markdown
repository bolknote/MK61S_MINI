# Примеры

`Graphics.tbi` — два экрана: отрезок, прямоугольник с XOR, окружность и
парабола с подписями через `PRINT AT`. Любая клавиша перелистывает экран,
`ESC` завершает показ. Для WS0010 предусмотрен компактный экран.
`Graph.tbi` — график параболы с осями. Оба примера используют `GW`/`GH`
и работают на UC1609, USB Screen и WS0010 с включённой графикой.

`Graphics.foc` — аналогичный пример для FOCAL: примитивы, парабола и
компактная компоновка WS0010. Позиционный вывод записывается как
`PRINT AT x,y,список`, ожидание клавиши — `ASK`.

`pacman-120x28.wbmp` — самостоятельная тестовая картинка для просмотрщика
WBMP, а не игра. Она нарисована автором проекта совместно с Codex; внешнее
изображение не копировалось.
