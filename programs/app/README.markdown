# Пользовательские APP

Здесь лежат готовые переносимые приложения, которые копируются в `/app` на
C6. Каталог содержит `ELIZA.APP` и `SHEET.APP`.
Исходники и инструкции по воспроизводимой сборке:
[`ELIZA`](../../examples/portable-apps/ELIZA/) и
[`SHEET`](../../examples/portable-apps/SHEET/).

`SHEET.APP` — электронная таблица с формулами калькулятора, ссылками,
пересчётом, обнаружением циклов и собственными файлами S1 / `.mks`.
Примеры лежат в [`programs/sheets`](../sheets/); для нового типа файлов
нужна прошивка, в которой зарегистрирован S1.

Текущая сборка ELIZA/DOCTOR 1966 для ABI 6: 9006 байт, SHA-256
`171745c999e11e4b24ba9ba31f8d25a897ebd102575d393c0d96f438661fd7c4`.
