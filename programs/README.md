# Готовые программы для C5

Этот каталог в репозитории группирует файлы, которые можно положить на
USB-диск MK61S. Саму папку `programs` на C5 копировать не нужно: её пять
дочерние папки располагаются прямо в корне диска.

| В репозитории | На C5 | Содержимое |
| --- | --- | --- |
| `programs/games` | `/games` | игры и памятки для МК-61 |
| `programs/examples` | `/examples` | отдельные демонстрационные файлы |
| `programs/app` | `/app` | пользовательские переносимые APP |
| `programs/CHIP8` | `/CHIP8` | готовые ROM CHIP-8 |
| `programs/Fonts/*.FMK` | `/Fonts/*.FMK` | выбираемые шрифты интерфейса F411/UC1609; копируются только FMK |

Штатная папка `/System` формируется сборщиком прошивки и остаётся отдельно в
корне C5. Не переносите и не переименовывайте её.

Каталог `programs/Fonts` является готовым содержимым одноимённого каталога C5
и поэтому намеренно содержит только загружаемые файлы `.FMK`. Документация и
лицензии хранятся вне `programs`.
