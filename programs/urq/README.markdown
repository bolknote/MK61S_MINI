# Русские текстовые квесты URQ

* house_that_jack_built — «Дом, который построил Джек», шесть русских переводов.
* trapped_in_time_ru — «В ловушке времени», приключение с двенадцатью концовками.

В папке каждого квеста открывайте game.urq. Части pNNNN.uqd должны лежать
рядом с ним. Игры общие для Classic/MK61S и PicoCalc; APP выбирайте для своей
платформы. Для STM32 нужны URQ.APP и URQUI.APP в одной папке.
На USB-диск Classic копируйте файлы .urq и .uqd. Штатный установщик сам
выбирает подходящие файлы.

OK/Enter выбирает действие и отправляет введённый текст; USER/Tab открывает
меню сохранения. В списке действий можно выбирать цифрами. На Classic
клавиша K меняет РУС/ABC/123, F — регистр. На PicoCalc F8 меняет RU/EN.

Оба квеста распространяются по CC0-1.0 и адаптированы в URQL без JavaScript.
Исходники, авторство и лицензии находятся в tools/urq/sources, отчёт аудита —
в tools/urq/catalog-report.json. В установочных комплектах лицензии лежат
отдельно в licenses/urq.
