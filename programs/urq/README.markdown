# Русские текстовые квесты URQ

* jim_from_outer_space_ru — «Джим из Космоса», юмористическое приключение
  космического полицейского: 83 сюжетные сцены, 42 концовки.
* trapped_in_time_ru — «В ловушке времени», приключение с двенадцатью концовками.
* semion_escape — «Семён: Побег», побег из клетки с котом, колесом и найденными предметами.
* semion_road — «Семён: На дороге», погоня кота и многоступенчатая ловушка из подручных вещей.
* semion_snow — «Семён: В снежном плену», выживание в зимнем лесу и загадки с предметами.

В проводнике откройте **Игры**, выберите квест и нажмите OK на MK61s
или Enter на PicoCalc. В `/Games/<Название>/` лежат `Play.txt`,
`game.urq`, части `pNNNN.uqd` и сохранения после записи.
Штатный установщик подбирает проигрыватель для устройства.
На STM32 обновляйте `URQ.APP` и `URQUI.APP` вместе в `/System/URQ/`.

На Classic текст читается кнопкой OK или →. В конце сцены OK открывает
список действий. ←/→ и ШГ перемещают выделение, OK выбирает действие,
USER открывает меню с отдельной тёмной шапкой; Esc возвращает в игру.
Длинное действие дочитывается кнопкой →. В списке действий работают цифры.
Esc возвращает из списка действий к тексту сцены.
Подсказки внизу экрана напечатаны мелким шрифтом.
На PicoCalc Enter выбирает действие и отправляет текст; Tab открывает меню.
На Classic
клавиша K меняет РУС/ABC/123, F — регистр. На PicoCalc F8 меняет RU/EN.

«Джим из Космоса» распространяется по CC-BY-NC-SA-4.0,
«В ловушке времени» — по CC0-1.0.
Три квеста про Семёна — по MIT из авторского архива devapromix/hamsters.
Все игры адаптированы в URQL без JavaScript; примечания в «Джиме» открываются
отдельными действиями.
Исходники, авторство и лицензии находятся в tools/apps/urq/sources, отчёт аудита —
в tools/apps/urq/catalog-report.json. В установочных комплектах лицензии лежат
отдельно в licenses/urq.
