# ТУРОЧЕМП

Шахматы по алгоритму Алана Тьюринга и Дэвида Чемперноуна.
Нужен графический экран UC1609. Копируйте всю папку игры;
шрифт загрузится при входе.

Выберите белые, чёрные или двух игроков стрелками и OK.
Доска поворачивается к игроку. Уголки отмечают курсор
и выбранную фигуру.

← → — по горизонтали; ШГ← ШГ→ — по вертикали.
OK — выбрать фигуру, затем клетку назначения.
Сх — отменить выбор. USER — помощь. ESC — выйти.
Для рокировки передвиньте короля на две клетки.
Превращение: выберите фигуру стрелками и нажмите OK.

С/П открывает меню: продолжение, заявление или предложение
ничьей, сдача, новая игра. Для заявления после следующего
хода сначала выберите фигуру и клетку, затем откройте меню.
Игра проверит основания и попросит OK.
