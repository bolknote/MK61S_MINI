# ТУРОЧЕМП

Шахматы Тьюринга и Чемперноуна.
UC1609 или PicoCalc. Копируйте всю папку игры.
PicoCalc сам выбирает крупный шрифт и клетки 24×24.

Выберите сторону или двух игроков стрелками и OK.
Доска поворачивается к игроку. Уголки — курсор и выбор.

«Дебютная книга» в начальном меню: OK — вкл/выкл.
Включена по умолчанию. Выбор сохраняется для новых партий.

← → — горизонталь; ШГ← ШГ→ — вертикаль.
OK — выбрать фигуру, затем клетку назначения.
PicoCalc: стрелки и Enter вместо OK.
Сх — отменить выбор. USER — помощь. ESC — выйти.
Рокировка: передвиньте короля на две клетки.
Превращение: стрелками выберите фигуру и нажмите OK.

С/П — меню: продолжить, заявить или предложить ничью,
сдаться, начать новую игру. Для заявления после следующего
хода выделите фигуру и клетку, затем откройте меню.
Подтвердите заявление кнопкой OK.
