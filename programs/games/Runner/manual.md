# Runner

Соберите три клада на каждом из трёх уровней.
Показан этаж героя: кольцо - вы, A - враг,
три черты с точкой - клад, H - лестница, черта - пол.
ESC закрывает памятку и продолжает игру.

## Кнопки

- **4 / 6** - идти влево / вправо, можно удерживать.
- **8 / 2** - подняться / спуститься по лестнице.
- **7 / 9** - прожечь соседний пол слева / справа.
- **5** - уровень и число оставшихся кладов.
- **0** - начать текущий уровень заново.
- **OK** - памятка с паузой.
- **ESC** или долгое **Cx** - выход.

Враги преследуют вас сами, в том числе по лестницам.
Столкновение заканчивает попытку: CAUGHt, затем **0**.
В прожиг герой падает на этаж ниже, а враг застревает.
Через 4 секунды пол восстанавливается, пойманный враг
возвращается к месту старта. Одновременно открыт один
прожиг; лестницы и нижний этаж защищены.

Последний клад открывает следующий уровень.
ALL CLEAr - пройдены все три; **0** начинает новую игру.
Памятка и просмотр счёта приостанавливают часы.
Выберите скорость **MAXIMUM**.
