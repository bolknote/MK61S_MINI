# Готовые программы для C6

Этот каталог в репозитории группирует файлы, которые можно положить на
USB-диск MK61S. Саму папку `programs` на C6 копировать не нужно: её шесть
дочерних папок располагаются прямо в корне диска.

| В репозитории | На C6 | Содержимое |
| --- | --- | --- |
| `programs/games` | `/games` | игры и памятки для МК-61 |
| `programs/library/*.m61` | `/library/*.m61` | штатные программы МК-61, ранее встроенные в прошивку |
| `programs/examples` | `/examples` | отдельные демонстрационные файлы |
| `programs/app` | `/app` | пользовательские переносимые APP |
| `programs/CHIP8` | `/CHIP8` | готовые ROM CHIP-8 |
| `programs/Fonts/*.FMK` | `/Fonts/*.FMK` | выбираемые шрифты интерфейса F401/F411 с UC1609; копируются только FMK |

Штатная папка `/System` формируется сборщиком прошивки и остаётся отдельно в
корне C6. Не переносите и не переименовывайте её.

## Счастливые билеты

`library/Lucky tickets.m61` вычисляет число шестизначных счастливых билетов
без перебора. Перед запуском в `X` вводится только основание системы счисления
`b=10`, а не готовые слагаемые ответа. Для трёх цифр в каждой половине искомое
число — центральный коэффициент

```text
[x^(3(b-1))](1 + x + ... + x^(b-1))^6.
```

Так как сумма в скобках равна `(1-x^b)/(1-x)`, раскрытие числителя и
извлечение коэффициента дают

```text
C(3b+2, 5) - 6*C(2b+2, 5) + 15*C(b+2, 5)
  = b*(11*b^4 + 5*b^2 + 4)/20.
```

Программа вычисляет последнее выражение по схеме Горнера. Для `b=10` множитель
`b/20` сокращается до `1/2`, поэтому калькулятор выполняет
`(b^2*(11*b^2+5)+4)/2`: сам получает `b^2`, сохраняет его в `R1` и повторно
использует в вычислении. Готового ответа и заранее вычисленных промежуточных
значений в программе нет. Листинг занимает 14 кодов, включая `С/П`, и не
использует циклов или трансцендентных функций.

После открытия файла введите `10` и нажмите `С/П`; результат — `55252`.

Каталог `programs/Fonts` является готовым содержимым одноимённого каталога C6
и поэтому намеренно содержит только загружаемые файлы `.FMK`. Документация и
лицензии хранятся вне `programs`.
