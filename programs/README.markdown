# Исходная коллекция программ и игр

Готовый комплект для MK61s и PicoCalc находится в `Disk/` релизного архива.
Пять папок из `Disk/` кладутся прямо в корень диска. Сборщик переносит
только файлы, которые поддерживает выбранная прошивка.

| Источник | Путь на диске |
| --- | --- |
| `games/`, ROM из `CHIP8/` и текстовые квесты из `urq/` | `/Games/<Название игры>/` |
| `library/` | `/Programs/Calculations/` |
| `examples/` и `sheets/` | `/Programs/Examples/` и `/Programs/Examples/Sheets/` |
| ELIZA и SHEET из `app/` | `/Programs/` |
| `Fonts/` | `/Fonts/` |

В `/Documents/` можно хранить свои файлы. В `/System/` находятся модули
прошивки и проигрыватель квестов. Для игр используются имена папок, их
файлы и сохранения лежат вместе.
