# Разработка MK61S

- [`tools/`](tools/README.md) — исследования, измерения, генерация штатных ресурсов и сборка игр.
- [`lib/`](lib/README.md) — общие внутренние модули сборщиков и тестов.
- [`../tests/`](../tests/) — проверки реализации и форматов.
- [`../tools/`](../tools/README.md) — пользовательские команды для калькулятора и авторов APP.

Команды ниже запускаются из корня репозитория. Файлы исследований и исторические
протоколы сохраняют свои исходные пути как часть происхождения результатов;
актуальные исполняемые команды используют новую структуру.
